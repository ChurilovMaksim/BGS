# Arithmetic return laws

**Status: publication candidate scope — not submitted, accepted, or externally refereed.**

This potential paper concerns global laws for explicitly defined arithmetic
return subsequences and their quantum/observable counterparts. The manifest
currently includes [BGS-RET-001](../../mathematics/pell_harmonic_returns.md)
(the actual kicked Pell-propagator harmonic return law) and
[BGS-RET-002](../../mathematics/pell_harmonic_transition.md)
(the harmonic-scale transition). Related authoritative reading includes the
[general hyperbolic return laws](../../mathematics/returns/general_cat_return_laws.md)
and the [short-return spectral obstruction](../../mathematics/returns/return_trace_obstruction.md).

These are not the same statement as a microscopic eigenphase point-process
limit: a law on return subsequences or at logarithmic/arithmetic scales
cannot replace the [Heisenberg-scale signed joint-trace comparison](../../mathematics/open_questions.md).
The fixed-strength deterministic BGS question remains **open**.
The distinction among an observable, the full propagator and its powers
must stay explicit when shaping the article.

The [scope manifest](paper.json) records the included claim IDs and
source paths; the [outline](OUTLINE.md) suggests publication order.
The [complete evolving manuscript](../../manuscript/README.md) remains
separate. Before submission, follow [the review protocol](../../REVIEWING.md)
and set `verification_commit` only to a genuinely checked revision.
