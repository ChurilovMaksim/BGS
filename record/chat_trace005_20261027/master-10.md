**ДОКАЗАНО:** QS1–QS6 в заявленных областях. Особый положительный результат для исходной семьи — (VIIIp.4.7): любая унитарная аппроксимация с ошибкой O(N⁻²) переносит исходный парный тест с исчезающей ошибкой. Слабый процесс устойчив уже при o(N⁻¹). Обе общие шкалы имеют проверенные препятствия к улучшению без дополнительных предпосылок.

**OUTLINE:**

- Контролируемая квантовая параметрикс-матрица могла бы стать подходящим объектом для точного парного вычисления; перенос к исходному U теперь обеспечен конкретной оценкой. Значение теста для такого объекта ещё не вычислено.
- Классический путь через необратимость и смешивание сам по себе недостаточен: QS5 сохраняет то же фиксированное F_tau и перечисленные качественные данные. Это препятствие к конкретной достаточности входов, а не запрет всех полуклассических методов.
- Допустимый следующий аргумент должен либо оценить критическую резольвенту исходного U, либо построить действительно более простой унитарный объект с точностью из QS3 и решить его невзвешенную Heisenberg-сумму. Формальное переименование этой суммы не считается выполнением шага.

**НЕДОКАЗАНО:**

- U-QS1: значение критической парной резольвенты для исходной семьи при фиксированном tau; оценка O(1) и целевой CUE-предел всё ещё отсутствуют.
- U-QS2: конкретная решённая унитарная аппроксимация с точностью O(N⁻²), которая дала бы исходную Y-компенсацию −delta_*.
- U-QS3: все фиксированные высшие порядки и слабый Sine₂ именно для исходного U_N.

Самое трудное место остаётся квантовым: классический предел не фиксирует фазовую организацию на расстояниях 1/N. Новый положительный перенос показывает, с какой точностью можно безопасно менять оператор; новая отрицательная конструкция показывает, почему обычная исчезающая операторная ошибка и совпадение классической карты этой точности не обеспечивают. Ни один из этих двух фактов не подменяет отсутствующее вычисление CUE-асимптотики.

Качественно малое изменение оператора может сохранять исходный фиксированный классический предел и перечисленные входы, одновременно меняя слабую локальную статистику. QS5 объясняет границу этих входов, но меняет точную квантовую матрицу и потому не решает отрицательно исходную задачу. Отсутствие полного решения зафиксировано без замены цели.


## IX. Текущий реестр незакрытых обязательств

### IX.1. Основная задача

**U-LAW.** Доказать слабый локальный закон Sine₂ для исходной семьи либо строго его опровергнуть. Для отрицательного результата проверены два достаточных признака: бесконечная подпоследовательность с $\Delta_{2,N}(b_*)\le-\varepsilon$, либо фиксированный допустимый $b$ с отделённым от нуля отклонением ограниченного функционала $\mathscr G_N(b)-\det(I-T_{N,b})$. Они не найдены. Достаточный моментный путь к положительному результату также остаётся открытым.

**U-PAIR — отдельно поставленная моментная цель.** Получить указанный в I.5 предел $-\delta_*$ для $Y^{\mathrm{nr}}$ исходной семьи при фиксированном $10^{-80}$, по всем нечётным $N$. После части III это всё ещё существенное, а не формальное обязательство.

**U-HIERARCHY — продолжение достаточного моментного маршрута.** Доказать $\Delta_{k,N}(b)\to0$ для каждого фиксированного $k\ge3$, каждого допустимого $b$ и произвольной фиксированной полосы Фурье. Из парного теста это автоматически не следует.

**U-V-DEFINITION.** Только для маршрута VN2-LEMMA: полностью определить конечную величину $\mathcal V_{m,N}$ и проверить её эквивалентность исходному знаковому тесту. Исходная спектральная задача определена независимо от этой вспомогательной величины. Если $\mathcal V$ означает естественную положительную группировку из II или её версию с весами не меньше 1, её нулевой предел запрещён теоремой G1. Это препятствие для вспомогательного моментного условия. Оно не даёт опровержения слабого закона; обратный переход от парного момента разобран в VII.4.

**U-UI — только для обратного вывода из положительного парного отклонения.** Если будет установлена подпоследовательность с $\Delta_{2,N}(b_*)\ge\varepsilon$, для вывода отрицания слабого закона потребуется дополнительный аргумент, например UI парного наблюдаемого. Для отрицательного отклонения UI не требуется. К достаточному критерию из PDF эта оговорка не добавляет новых условий.

**U-GAUSSIAN-REMOVAL — только для маршрута VIIIe.** Точное восстановление всей матрицы и всех степеней выполнено в VIIIf.1–2. Получить контролируемую оценку смешанных следовых вкладов этого восстановления, сохранив все слова и их знаки. Операторная близость как основание перехода исключена CG3; замена смешанных историй положительной суммой одинаковых историй не обоснована. Нулевой предел взвешенной суммы не заменяет исходный $-\delta_*$.

**U-TEMPORAL-TRACE — только для маршрута VIIIg.** OF2 доказывает ненулевую предельную нижнюю границу для другой, временно-интенсивностной наблюдаемой. Для исходных спектральных следов количественный переход не найден. SC1 сохраняет все крюковые произведения; SC3 исключает универсальную замену их корреляций вторыми моментами секулярных коэффициентов при перечисленных общих условиях. Нужна оценка, использующая именно исходный фиксированный символ; существующие статусы U-PAIR и U-LAW не меняются.

**U-ARITHMETIC-MICRO — продолжение VIIIh.** AP6 исключает алгебраические попарные отношения исходного спектра для всех нечётных N, не кратных 7. Получить количественную фазовую оценку на Heisenberg-времени; она не следует из точной ненулевости, а абсолютная оценка (VIIIh.7.4) не может дать нужный предел при времени порядка N. Отдельно разобраться с семью цепочками при N, кратном 7: нулевой граничный Fourier-минор при N=49 исключает дословный перенос доказательства AP4, но не доказывает ложность его полного спектрального вывода.

**Уточнение U-ARITHMETIC-MICRO после VIIIi.** AQ2–AQ4 дают явные равномерные оценки промежутков $A_N$ и всех главных сжатий $M_N$ в его собственном базисе. Поэтому прежняя качественная ненулевость усилена количественно. Промежутки фаз самого $U_N(10^{-80})$ и компенсация смешанных следов по-прежнему не оценены. AQ5 даёт явное вспомогательное мнимое время; (VIIIi.7.2) показывает точную границу этого метода, а AQ6 — недостаточность одной E3 и верхних модулей коэффициентов для нижней оценки величины. При 7|N получены только внутриблочные промежутки, не разделение разных цепочек.

**U-WARD-SCALING — продолжение VIIIj.** LD2–LD3 контролируют исходные матричные элементы на явном логарифмическом диапазоне и координатную массу каждого собственного вектора, но не фазовую сумму при $m\asymp N$. LD4 даёт не меньше половины N мягких сингулярных направлений и исключает ограниченную равномерно по N резольвенту памяти при z=1. LD5 сохраняет полный спектральный якобиан и точные Schur-факторы. Для растущих коэффициентов этих факторов контроль слоя $1-|z|\asymp1/N$ не получен. LD6 исключает общий переход к Sine₂ из одних перечисленных свойств даже после добавления всех трансцендентных попарных отношений и регулярной Ward-формулы; исходный фиксированный символ в этом контрпримере не используется.

**U-COUPLING-MICRO — продолжение VIIIk–VIIIm.** CW1 и CW3 исключают постоянные спектральные веса в проверенной нормированной L1-форме. PW1–PW3 полностью контролируют классический профиль и его выравнивание. Теперь SG2 переносит фильтр на генератор изоспектральной семьи, а SG4 сохраняет микроскопические связи с остатком следующего порядка и коммутант точно. SG6 даёт новый квантовый результат масштаба 1/N для сглаженной силы, используя положительный квадратичный фазовый фактор и точный коммутатор. Нужная исходная невзвешенная Heisenberg-сумма не является этой наблюдаемой: аналитический тест нельзя заменить сингулярным с сохранением его нормы. Нужно вычислить её ведущий квантовый член при $m\asymp N$ и получить предел $-\delta_*$. PW5 этих оценок не заменяет. В преобразованиях используется полный $H_\tau$; фиксированная близость к $H_0$ не подменяется исчезающей по N ошибкой. Alias-пример VIIIl.6 сохраняет силу: новая полунорма SG3 контролирует специальный квантовый ряд, не передаёт классическое сжатие всему квантовому сопряжению. Основные U-PAIR и U-LAW не меняются.

**U-PARAMETRIC-MICRO — новый маршрут VIIIm.** SG5 сохраняет полный член ускорения, SG6 оценивает его и даёт остаток O(1/N) в локальном параметрическом уравнении. Остаётся доказать совместную микроскопическую статистику скоростей $\sqrt N a_{jj}$, связей $N|a_{jk}|^2$ и собственных фаз. Их CUE-значения не постулируются; дополнительная случайность не вводится. Также требуется контролируемый интервал существования динамического предела: AP6 даёт простоту в исходной точке при $7\nmid N$, но не единое по N окно, и не покрывает бесконечную подпоследовательность кратных 7. Параметрический масштаб $N^{-3/2}$ и итерационное время m порядка N не отождествляются. Нормальная форма сохраняет спектр точно, но перенос FM-021 на её координатные интенсивности отдельно не доказан.

**U-POSITIVE-PAIR-RESOLVENT — новый маршрут VIIIn.** Доказать для исходной семьи при фиксированном tau локальный закон $N^{-1}\operatorname{Tr}_{\mathrm{HS}}(\mathscr L_N+a^2I)^{-1}\to1/(2a)+(1-e^{-a})/a^3$. Даже проверка при положительных целых a достаточна для всех компактных парных временных весов. Это невзвешенный объект, не требующий гипотезы о постоянных весах генератора. Сейчас доказан только порядок O(N/log N), причём один равномерный вход H1 не может дать лучший порядок: PR6 достигает его в движущемся режиме. Требуется существенное новое использование фиксированного положительного tau. Универсальный энергетический минимум соответствует решётке; целевой CUE-предел имеет строго положительный явно выписанный избыток. Его величина для исходной семьи не вычислена. Для слабого закона PR3 даёт лишь необходимую нижнюю оценку liminf, не равенство без UI. Все высшие порядки по-прежнему остаются отдельным обязательством.

**Закрытый геометрический вопрос — VIIIo.** RV4–RV5 полностью классифицируют C¹-централизатор исходного F_tau и исключают все C¹-обращатели времени. Историческое ограничение SG7 только аффинными симметриями здесь снято новым доказательством. Топологические обращатели существуют и не опровергаются. Квантовый коммутант и произвольные антиунитарные операции этим не классифицируются. Утверждение о Sine₂ из отсутствия классических симметрий не доказано и не принимается как вход. RV6 не переносит линейные резонансы из t=0 в фиксированное tau: его относительная оценка содержит tau N². Основные U-PAIR и U-LAW сохраняются.

**U-QUANTUM-APPROXIMATION — инструмент VIIIp.** QS3 доказывает перенос исходного парного теста через любой матричный параметрикс с ошибкой O(N⁻²), в том числе неунитарный. При унитарности остаток O(1/log N), в общем случае O(1/sqrt(log N)); доступны и более общие исчезающие диапазоны. Этот перенос не определяет сам предел: нужен конкретный объект, для которого невзвешенная Heisenberg-сумма действительно вычислена. QS5 запрещает заменять такой контроль одним совпадением фиксированного классического F_tau: в другой близкой квантовой семье сохранены перечисленные классические, интенсивностные и коротковременные данные, а локальный процесс пуст. Её отличие от точной формулы кика доказано по определителю; N⁻²-Egorov и SG6 для неё не доказаны, так что исходная цель остаётся открытой. Различие слабого закона и неограниченного парного момента сохранено в QS1–QS4.

### IX.2. Что не следует из результатов

- Нарушение парного моментного теста с положительным знаком само по себе не опровергает слабый точечный закон. Z3 — строгий контрпример к такому общему выводу.
- Исчезновение буквальных отражений не означает, что весь $Y$ исчезает. Требуемая отрицательная поправка остаётся.
- Отражение координатного слова не тождественно отсутствию любой физической антиунитарной симметрии после смены базиса.
- Полиномиальный растущий диапазон в части II относится к $V^W$ при $\tau=0$; он не переносится на $m\asymp N$ или на положительный $\tau$ без нового доказательства.
- Контрпример $Q_{N_j}$ из III.5 — другая семья. Он опровергает общий критерий достаточности, а не исходную модель.
- Точные тождества для детерминанта дают представление, но не нужную оценку его предела.
- Прежний счётный аргумент R2 не выделял предписанное время. Теперь E4 части VIIIb исключает точные проектные периоды именно при $10^{-80}$, но не даёт требуемого контроля близких возвратов. R4 сохраняет силу: качественное отсутствие периодов само по себе недостаточно для локального закона.
- Глобальная равномерность и оценка следов в логарифмическом диапазоне из VI верны также при $\tau=0$; они не дают требуемых микроскопических корреляций.
- Малые моды парного гессиана из VIIId не дают сами по себе спектрального вклада. SP5 исключает весь сектор шагов $o(\sqrt N)$; в VIIIe дополнительно оценена гауссово взвешенная версия критической области. Полная невзвешенная область и остальные секторы не оценены.
- Простота исходного спектра и трансцендентные попарные отношения из AP6 не дают количественной статистики близких фаз. Разрешённые N указаны явно; размерности, кратные 7, не покрыты новой теоремой.
- TV1 относится к другим матрицам с совпадающими интенсивностями всех степеней. Он исключает универсальный переход от одних временных интенсивностей к спектральному следу, но не опровергает исходный закон.
- LD3 относится к координатной массе собственных векторов; для локальной статистики собственных фаз требуется отдельная оценка. LD4 утверждает малость сингулярных чисел I-D, не расстояний собственных значений D до 1. Тождество LD5 не определяет статистику спектрального якобиана.
- Вспомогательная мера взвешенных фазовых разностей CW2 не является микроскопическим точечным процессом. Отрицательная корреляция генератора CW1 не равна исходному парному отклонению и не опровергает Sine₂.
- Все классические времена PW1 и точное выравнивание PW3 не означают контроль квантового Heisenberg-времени. PW4 доказывает исчезающую ошибку на логарифмическом диапазоне; ведущий эффект исходной спектральной суммы порядка 1/N остаётся не выделен. В VIIIm генератор изменён посредством точного изоспектрального сопряжения; собственные фазы исходного U сохранены.
- Точечная оценка SG6 относится к сглаженной силе с аналитическим фазовым фактором. Она не является исходным парным пределом; остаток O(1/N) в параметрическом ускорении не задаёт закон неизвестных весов и скоростей.
- SG7 исключает общий аффинный обращатель двух факторов, а не все нелинейные или N-зависимые антиунитарные симметрии полного отображения.
- Положительная резольвента PR1 представляет нужный невзвешенный объект, но её целевой локальный закон PR2 не доказан. Оценка O(N/log N) допускает расходимость; решётчатый минимум PR4 строго ниже CUE-эталона. Нерегуляризованный обратный момент исходных промежутков также не вычислен.
- Результаты конечного перебора, числа и рисунки сами по себе не доказывают ни один требуемый предел.

### IX.4. Интенсивностный субтест: теперь решён отрицательно

Несимметрия интенсивностей из T1 не определяет предел $\operatorname{Tr}[(P_N-J_N)^2]$. Для вещественной $E=P_N-J_N$, с $S=(E+E^T)/2$, $A=(E-E^T)/2$, точно
$$
\operatorname{Tr}E^2=\|S\|_{\mathrm{HS}}^2-\|A\|_{\mathrm{HS}}^2.
$$
Действительно, $\operatorname{Tr}SA=0$, симметричная часть даёт положительную норму, а кососимметричная — отрицательную. Нижняя оценка для $\|A\|$ сама по себе не определяет разность. На предыдущем этапе эта разность оставалась открытой. Теперь теорема I1 части VIII доказывает для исходного положительного параметра строго положительный предел: $\mathcal C(\tau)=L\tau^8+O(10^{55}\tau^9)>0$ с явной оценкой (VIII.1.3). Исходная когерентная спектральная задача этим не решается.


## X. Полные сертификаты квадратичных форм

Это конечные рациональные сертификаты, а не вычисление асимптотики. В каждом случае $D'$ — главный блок разности матриц смежности исходного цикла и указанного обхода после удаления последней координаты. Матрица $T$ удовлетворяет $T^TD'T=B$, где $B$ имеет указанные в части II блоки. Столбцы $T$ задают замену координат. Перестановки и сдвиги Шура в алгоритме имеют определители $\pm1$; дополнительно все определители ниже пересчитаны отдельным рациональным исключением Гаусса.

Знаменатели всех элементов $T$ — степени 2, и $\det T=\pm1$. Поэтому $T$ обратима по каждому нечётному модулю. Это обосновывает применение сертификата сразу ко всем нечётным $N$.

## XI. Полные воспроизводимые скрипты

Каждый блок ниже можно сохранить под указанным именем. Нужен Python с NumPy; SciPy используется для отдельно отмеченной квадратуры в первом и пятом скриптах. Скрипты сохраняют собственные результаты и манифест, но не объявляют успешный запуск доказательством локального закона.

Их ограничения принципиальны: численная проверка при вспомогательном $\tau=0.2$ проверяет только точные тождества и индексы. Строгое заключение о $10^{-80}$ в III получается из явных аналитических остатков.


### XI.1. trace005_verify.py

```python
#!/usr/bin/env python3
"""Exact finite audits for TRACE-005 auxiliary tau=0 results.
Run: python trace005_verify.py --output trace005_checks.json
Needs NumPy; optional SciPy for the explicitly numerical plateau check.
This does NOT test the fixed-tau Heisenberg limit.
"""
import argparse, hashlib, itertools, json, math, platform, time
from collections import defaultdict
from datetime import datetime, timezone
from fractions import Fraction as F
from pathlib import Path
import numpy as np


def cycles(m):
    for tail in itertools.permutations(range(1, m)):
        if tail[0] < tail[-1]:
            yield (0,) + tail


def canonical(c):
    j = c.index(0)
    a = c[j:] + c[:j]
    return min(a, (a[0],) + tuple(reversed(a[1:])))


def orbit(c):
    m = len(c)
    return {canonical(tuple((sgn*x+s) % m for x in c))
            for s in range(m) for sgn in [-1, 1]}


def adjacency(c):
    m = len(c)
    a = [[0]*m for _ in range(m)]
    for i in range(m):
        u, v = c[i], c[(i+1) % m]
        a[u][v] += 1
        a[v][u] += 1
    return a


def difference(c):
    b, a = adjacency(tuple(range(len(c)))), adjacency(c)
    return [[u-v for u,v in zip(rb,ra)] for rb,ra in zip(b,a)]


def matmul(a,b):
    return [[sum(x*y for x,y in zip(row,col)) for col in zip(*b)] for row in a]


def transpose(a):
    return [list(x) for x in zip(*a)]


def identity(n):
    return [[F(i==j) for j in range(n)] for i in range(n)]


def congruence_blocks(D):
    """Return exact block congruence T' D T = B over Z[1/2]."""
    n = len(D)
    orig = [[F(x) for x in row] for row in D]
    a = [row[:] for row in orig]
    T = identity(n)
    pos = 0
    blocks = []
    while pos < n:
        pair = next(((i,j) for i in range(pos,n) for j in range(i+1,n)
                     if a[i][i] == a[j][j] == 0 and abs(a[i][j]) == 1), None)
        if pair:
            chosen = list(pair)
            typ = 'H'
        else:
            pivot = next((i for i in range(pos,n) if a[i][i] != 0
                          and abs(a[i][i].numerator) & (abs(a[i][i].numerator)-1) == 0), None)
            if pivot is None:
                pivot = next((i for i in range(pos,n) if a[i][i] != 0), None)
            if pivot is None:
                assert all(a[i][j] == 0 for i in range(pos,n) for j in range(pos,n))
                blocks.append(('zero',n-pos))
                break
            chosen = [pivot]
            typ = 'd'
        rest = [i for i in range(pos,n) if i not in chosen]
        order = list(range(pos)) + chosen + rest
        P = [[F(i == order[j]) for j in range(n)] for i in range(n)]
        a = matmul(transpose(P),matmul(a,P))
        T = matmul(T,P)
        size = len(chosen)
        c = a[pos][pos+1] if typ == 'H' else a[pos][pos]
        E = identity(n)
        for j in range(pos+size,n):
            if typ == 'H':
                E[pos][j] = -a[pos+1][j]/c
                E[pos+1][j] = -a[pos][j]/c
            else:
                E[pos][j] = -a[pos][j]/c
        a = matmul(transpose(E),matmul(a,E))
        T = matmul(T,E)
        blocks.append((typ,str(c)))
        pos += size
    assert matmul(transpose(T),matmul(orig,T)) == a
    assert all(x.denominator & (x.denominator-1) == 0 for row in T for x in row)
    return blocks, T, a
```

```python
        self.I=float(self.weights@self.phi(self.nodes))

    def phi(x):
        x=np.asarray(x)
        ans=np.zeros_like(x,dtype=float)
        mask=abs(x)<1
        ans[mask]=np.exp(-1/(1-x[mask]**2))
        return ans

    def __call__(self,t):
        t=np.asarray(t,dtype=float)
        lo=np.maximum(-1.,t-1)
        hi=np.minimum(1.,t+1)
        half=np.maximum(0.,(hi-lo)/2)
        x=(lo+hi)[...,None]/2+half[...,None]*self.nodes
        conv=half*np.sum(self.weights*self.phi(x)*self.phi(t[...,None]-x),axis=-1)
        return conv**2/(4*self.I**4)
```
