# Historical formal drafts

Files here are preserved formalization attempts that are scientifically useful
as provenance but are not imported by the active Lean library.

`OpLocal.lean` is the exact R86-era source. It type-checked with explicit
`sorry` placeholders when imported during the reconstruction audit, but its
comments and target reduction predate the corrected pair-key/elliptic M1 route.
It is therefore retained here rather than presented as a current proof
obligation.
