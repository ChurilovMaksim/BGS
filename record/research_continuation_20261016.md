# Продолжение BGS: абелева жёсткость и точный равнорёберный сектор

База: `b425a36141cd81c7ef4e832984e7f7ff5074ddc7`. Дата: 16 октября 2026.
Глобальная цель — микроскопическая универсальность хаотических квантовых
систем при точных динамических и симметрийных условиях. Фиксированное
отображение с tau=10^-80 остаётся отдельным, явно заданным исследовательским
классом. Его решение само по себе не было бы теоремой для всех систем.

## Что установлено в этом проходе

**TRACE-092.** [Полное доказательство](../mathematics/abel_clock_rigidity_20261016.md)
даёт точное положительное разложение абелева избытка и количественную
жёсткость: локальное ограниченное липшицево расстояние до равномерно
сдвинутого целочисленного спектра не превосходит C sqrt(delta).
Теорема доказана также для произвольного стационарного точечного процесса
интенсивности один с конечной указанной энергией. Допускаются кратности,
неэргодичность и пустая компонента. Показатель 1/2 оптимален: чередующиеся
зазоры дают энергию порядка epsilon^2 и расстояние не меньше epsilon.
Физический абелев избыток этим не оценён.

**TRACE-093.** [Полное доказательство](../mathematics/gaussian_equal_edge_20261016.md)
для точно плоских интенсивностей устанавливает B/G->1 при каждом m=o(N).
Первоначальная оценка m=o(N^(3/4)) восстановлена, а затем усилена аргументом
с гауссовым гессианом. Масштаб N^(3/4) не является критическим для этого
относительного сравнения. На временах m/N->alpha>0:

\[
 \frac{\log B_{N,m}}N\to(1+\alpha)\log(1+\alpha)-\alpha,
 \qquad \mathbb E_W C_{\mathrm{edge}}\to2\alpha^2.
\]

Тройные использования ребра имеют исчезающую вероятность. Для среднего
найдена точная конечномерная формула через веса крюков. При m>=N+2 она
сокращается до

\[
 F(N,m)=\frac{2m\{(N+5)m(m+1)-(N+2)(N+3)\}}
                    {(N+1)(N+2)(N+3)(m+2)}.
\]

На каждом положительном компактном диапазоне m/N ошибка этой рациональной
формулы экспоненциально мала; при alpha_N=m/N среднее равно
2alpha_N^2-2(alpha_N^2+alpha_N+1)/N+O(N^-2). Это оценка первого момента,
а не закон распределения.

При m=floor(sqrt(c N log N)) получено B~N^((c+1)/2)/sqrt(c log N).
Для c>3 унитарность уже требует почти полной компенсации этого положительного
сектора: R/B=-1+O(sqrt(log N)N^((3-c)/2)). Конечный знаковый остаток
контролируется здесь лишь до N^2. Его CUE-масштаб и значение остаются задачей.

Сам гауссов конечный эталон и sinh-предел известны с 2002 года.
[Проверка первоисточников](../literature/abel_gaussian_sources_20261016.md)
исправляет ловушку с нормировочным множителем. Приоритет более сильных
сравнений и жёсткости полностью не установлен; оценка уровня премий
по этому внутреннему проходу не делается.

## Следующая точная подзадача

В плоской задаче кандидат — C_edge => Poisson(2alpha^2) при m/N->alpha.
Вместе с исчезновением тройных рёбер он дал бы B/G->exp(-alpha^2), поскольку
на дополнении к тройным рёбрам prod nu!=2^C_edge. Для этого достаточно
доказать соответствующие все фиксированные факториальные моменты с нужным
контролем, либо прямо сходимость ограниченных преобразований распределения.
Первый момент такой сходимости не даёт.

Полезное точное тензорное продолжение уже выводится из Фоковой градуировки.
Для H^(k)=D^k p_m, 2<=k<=m, частичная перестановка двух верхних индексов
имеет скалярное произведение

\[
 K_k=(m-2)_{k-2}K_2,\qquad
 \|H^{(k)}\|_2^2=(m)_k h_m,\qquad
 \frac{K_k}{\|H^{(k)}\|_2^2}
       =1-\frac{2\bar j}{m-1}.
\]

Доказательство: к двум полиномам степени m-2 в исходной свёртке применяются
одни и те же k-2 производные; суммирование их координатных скалярных
произведений даёт падающий множитель (m-2)_(k-2). Симметрия по полным
парам переносит вывод на любую верхнюю транспозицию. Поэтому при фиксированном
k и m~alpha N тензор почти симметричен отдельно по верхним индексам.
Усредняя по перестановкам и раскладывая их не более чем в k(k-1)/2
транспозиций, получают относительную квадратичную потерю O_k(bar j/m).
Этот вывод не оценивает автоматически все свёртки со совпадающими вершинами.

Первый незамкнутый шаг следующей ветви: равномерно контролировать высокие
производные с заданными совпадениями концов рёбер. Конкретный кандидат
на достаточную оценку для отбрасывания таких совпадений:

\[
 \|\partial_{11}^{\,k}p_m\|_2^2/h_m
          \le C_{a,b,k}N^{-k},\qquad aN\le m\le bN,
\]

для каждого фиксированного k. Гауссовы диаграммы имеют неотрицательные
дельта-ограничения, поэтому совпадение всех предписанных меток даёт верхний
контроль любой фиксированной координатной производной. Сама отображённая
равномерная оценка для всех k в этом проходе НЕ доказана. Даже её доказательство
потребует закончить оценку главных хааровских свёрток; переход к Пуассону
не зарегистрирован как готовая импликация.

## Исходная физическая задача

Сохраняется U_N=exp(i tau N A_N)M_N, tau=10^-80, все нечётные N, полный
фиксированный символ и установленный порядок сопряжения. Для каждого
гладкого компактного веса остаётся доказать хотя бы парное сравнение

\[
 N^{-2}\sum_{m\ge1}w(m/N)
        [|\operatorname{Tr}U_N^m|^2-\min(m,N)]\to0,
\]

а затем всю знаковую факториальную иерархию. Новая плоская теорема не
передаётся автоматически неплоскому профилю. Абелева жёсткость не даёт
положительного CUE-избытка. Классическая интенсивностная щель не заменяет
оценку комплексных амплитуд. Зарегистрированные TRACE-005 и BGS-BGS-001
остаются OPEN.
