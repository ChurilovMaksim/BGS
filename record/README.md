# Scientific status and research record

This directory records theorem status, dependency structure, corrections and
actual review coverage. It is the provenance layer of the scientific corpus;
current status must be read before using a historical route.

| File | Role |
|---|---|

[The research brief](../RESEARCH.md) gives the present mathematical frontier.
Older route records report outcomes under their stated assumptions; they do
not override this living surface.

## Historical record

[history/2026/INDEX.md](history/2026/INDEX.md) is the maintained historical
entry point. Indexed snapshots and evidence retain their original bytes.

`claim_ledger.md`. Obsolete root summaries remain recoverable from Git
history, including the removed root roadmap.

## Execution boundary

A proof review, a finite arithmetic run, a floating diagnostic, a formal build
and hosted CI are different events. Each receipt states what actually ran.
The [evidence guide](../evidence/README.md) and
[11 October packets](../evidence/executions/20261011/chat-research/README.md)
and [cavity continuation](../evidence/executions/20261011/cavity-continuation/README.md)
provide those boundaries. Earlier executions remain preserved. A successful build cannot promote an unproved
asymptotic implication, and internal reconstruction is not external refereeing.
