# Licensing policy

No new public license is granted by this repository-normalization change.

The repository combines manuscript text, mathematical exposition, source code,
formalization, figures, and research evidence. Selecting legal terms for those
classes is a maintainer decision with consequences beyond repository
organization; it should not be silently inferred from a technical cleanup.

Before a public archival release, choose and record an explicit license policy
(for example, separate terms for code and scholarly text if desired), update
`CITATION.cff` and archival metadata consistently, and have the decision
reviewed as a release gate.

Until such a decision is made, absence of an open-source license must not be
interpreted as permission beyond applicable law.
