# Licensing policy

This repository is released under layered licensing (decision R3,
applied at the phase-5 release; before this release no open license
was granted — see the history note below).

- Source code — MIT License (`LICENSE`): `computations/`,
  `formalization/`, and other source code (scripts, build tooling,
  verification code).
- Scholarly texts and data — Creative Commons Attribution 4.0
  International (CC BY 4.0, `LICENSE-CC-BY-4.0.txt`): the manuscript
  (`manuscript/`), mathematical exposition (`mathematics/`), registries
  and research records (`record/` texts and data), `literature/`,
  `docs/`, and figures.

`archive/` contents retain their original terms where a source note
states them; otherwise the layered scheme above applies to the
archival copies as repository content. Evidence files are research
records under CC BY 4.0 unless a source note says otherwise.

Single-license metadata fields cannot express the layering:
`CITATION.cff` records `MIT` with a comment noting the CC BY 4.0
layer, and `.zenodo.json` records `CC-BY-4.0` with the split
documented in its notes (the proposal is superseded by the applied release policy). This
file is authoritative for the per-path map.

## History

Before the phase-5 release, no new public license was granted by the
repository-normalization change, and absence of an open-source license
was not to be interpreted as permission beyond applicable law. That
position is superseded by this policy from the release commit onward;
it remains the correct description of the pre-release state.
