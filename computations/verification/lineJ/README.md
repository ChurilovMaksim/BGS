## Scope
* Theorem J (BGS-TRACE-225) is a **subsequence** statement. In each class mod 168 it gives both signs within every 6 consecutive
  members, for m ≥ M0(j). It controls only the d = 7 term of ρ = (±2,8). The other levels, O_m, are not controlled.
* (±2,16) at d = 7 is controlled for m ≥ 243 (BGS-TRACE-227).
* Theorem J3 (BGS-TRACE-231) is conditional on H♮ and H_arg. Only denominators < 1339 are excluded for arg ξ/2π.
* The table values K_j carry a 10⁻³ margin. J3 uses K_min = 0.00998476, the minimum of K_j⁺ and K_j⁻, which is ≥ the table minimum
  0.009975.
* Nothing here proves or disproves R′ (BGS-TRACE-206), R (BGS-TRACE-179), R_NSW (BGS-TRACE-210) or BGS.
