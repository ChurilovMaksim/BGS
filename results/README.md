# Results

Only curated current outputs live here.

- `verified/` — finite identities or implementation regressions that have been freshly rerun and whose scope is explicit.
- `numerical/` — statistical evidence; never theorem status.
- `diagnostics/` — falsifiers, failure localization and active-bottleneck measurements.
- `reference/` — immutable reference inputs required to reproduce a current verification.

Historical outputs, including files once labelled `[PROVEN]`, live in `archive/legacy-workspace/` and have no active status unless promoted here.
