# Research notes

This directory contains the **current** scientific argument, not the full history.

- `theory.md` — stable mathematical core and exact reductions.
- `ledger.md` — concise chronology of decisions and new results.
- `problems/` — open load-bearing problems, one file per problem.
- `notes/` — derivations and experiments that directly serve an open problem.
- `archaeology/` — promising results found in the old workspace that still require re-certification.

Historical run-number prose (`R82`, `R101`, etc.) is translated here into descriptive names.  Run numbers remain only as provenance references.
