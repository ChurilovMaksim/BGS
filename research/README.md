# Active research

This directory contains the current scientific argument and its live problems. It should stay small enough to read end-to-end.

## Read in this order

1. `theory.md` — exact finite algebra/combinatorics already accepted as active mathematics.
2. `problems/m1_fluctuation_energy.md` — the load-bearing fourth-moment concentration problem.
3. `notes/k2_cayley_energy.md` — exact Cayley/additive-energy treatment of the mixed `k=2` component, including cyclotomic exceptional primes.
4. `notes/m1_offoff_elliptic_family.md` — generic off/off elliptic pencil, parameter symmetries, non-isotriviality and the first realistic trace-correlation regime.
5. `notes/m1_cross_terms.md` and `notes/m1_mobius_fibers.md` — audit notes explaining why the historical Möbius proof route was retired.
6. `archaeology/old_results_review.md` — useful old results that were found in the ZIP but still require promotion checks.
7. `ledger.md` — short chronological record of major scientific decisions.

## Status vocabulary

- **Exact** — algebraic/combinatorial identity with a derivation and finite regression checks.
- **Verified finite** — independently reproduced at named finite designs; not automatically asymptotic.
- **Conditional target** — a theorem whose remaining hypothesis is written explicitly; not a result yet.
- **Numerical evidence** — empirical scaling or spectral behavior only.
- **Retracted historical route** — preserved for provenance/falsification, never a theorem input.

Historical run numbers remain only as provenance references. The active programme intentionally prefers one precise open lemma over many theorem-named scripts.
