# M1-A — Möbius divisor classification

Status: `ACTIVE LEMMA WORK`.

This note classifies the rational map used by the historical Möbius-fiber route before any Weil-type estimate is applied.

## Rational map

For

`v_d(u) = ((d-1)u + 1)/(d+1-u)`

the representing Möbius matrix is

`[[d-1, 1], [-1, d+1]]`.

Its determinant is

`(d-1)(d+1) + 1 = d^2`.

Therefore the map is nonconstant exactly when `d != 0`.

At `d=0`, numerator and denominator are both `1-u`, so

`v_0(u)=1`

away from the cancelled point `u=1`. This is the exact degeneracy already detected by the Python/C++ audit.

## Zero and pole

For `d != 1`, the finite zero is

`alpha_d = -1/(d-1) = 1/(1-d)`.

The finite pole is

`beta_d = d+1`.

The historical draft states the pole as `u=d-1`; that location is algebraically incorrect for the displayed denominator `d-u+1`.

The zero and pole collide exactly when

`1/(1-d) = d+1`,

which reduces to `d^2=0`, hence `d=0` over a field.

Two additional divisor-collision values matter because the zero or pole meets the divisor of `u`:

- `d=1`: the zero of `v_d` moves to infinity;
- `d=-1`: the pole of `v_d` is at `u=0`.

Thus the natural divisor stratification is `d=0`, `d=1`, `d=-1`, and generic `d notin {0,1,-1}`.

## Divisor of the combined twist function

Let the annihilator character group be generated by a character `eta`, and write a twist pair as

`psi1 = eta^r`, `psi2 = eta^s`.

Then

`psi1(u) psi2(v_d(u)) = eta(u^r v_d(u)^s)`.

The relevant rational function is therefore

`f_(r,s,d)(u) = u^r v_d(u)^s`.

### Generic d

For `d notin {0,1,-1}`, the four points

`0`, `infinity`, `alpha_d`, `beta_d`

are distinct, and

`div(f) = r[0] - r[infinity] + s[alpha_d] - s[beta_d]`.

If `eta` has order `n` and `r,s` are represented modulo `n`, divisibility of this divisor by `n` forces

`r = 0 mod n`, `s = 0 mod n`.

So no nontrivial perfect-`n`-th-power degeneration occurs in the generic stratum.

### d = 1

Here

`v_1(u) = 1/(2-u)`,

so

`div(v_1) = [infinity] - [2]`

and

`div(f) = r[0] + (s-r)[infinity] - s[2]`.

Divisibility by `n` again forces `r=s=0 mod n`.

### d = -1

Here

`v_-1(u) = (-2u+1)/(-u)`

up to a nonzero constant, hence

`div(v_-1) = [1/2] - [0]`

and

`div(f) = (r-s)[0] + s[1/2] - r[infinity]`.

Divisibility by `n` again forces `r=s=0 mod n`.

### d = 0

Here `v_0=1`, so

`f_(r,s,0)(u)=u^r`

independently of `s`, with

`div(f)=r[0]-r[infinity]`.

Therefore every pair with `r=0 mod n` is degenerate, regardless of `s`. In particular, `psi1=1`, `psi2!=1` gives a constant integrand on the admissible d=0 fiber and

`A_(1,psi2)(0)=N-2`.

This exactly matches the observed violations at `N=53` and `N=199`.

## Character-order warning

The historical draft speaks of a `perfect K-th power`. This needs to be re-derived from the actual character convention. For `S={chi: chi(a)=1}` with `|S|=m=(N-1)/K`, the annihilator character group has size `m`; individual twist-character orders divide `m`. The power-exclusion theorem must therefore be stated using the actual order of the character being applied, not by inserting `K` automatically.

This point is not yet promoted to a theorem about the full current M1 object; it is a normalization/proof-obligation warning that must be resolved when the exact twist identity is re-derived.

## What is now reduced

For the historical rational map itself, the geometric degeneration is completely transparent:

- the Möbius determinant vanishes only at `d=0`;
- `d=0` creates the large constant-fiber family;
- `d=±1` change the divisor support but do not by themselves create nontrivial perfect-power pairs under the exponent model above;
- generic `d` has four distinct divisor points.

The next step is to derive the exact character order/exponent convention from the current `k=4` assembly and then prove that this divisor classification is the correct one for the theorem-level object.
