## 1. Where C0 comes from [P-sketch]

Estimate U asks for |z_γ| ≤ C₀ r^{n_nr(γ)} on N11 polymers with at least one
non-resonant λ-site. From N11 §1 the activity is a cyclic product of bump blocks B_j
and gap remainders Ñ_j:

```
|z| ≤ (∏_j ‖B_j‖/μ^{ℓ_j}) · (∏_j ‖Ñ_j‖).
```

### 1.1 Old Euclidean prefactor (eliminated for gaps)

N11 §2: pair interaction ≤ G_b² R₂ κ^g with G_b = Cpow²(1+ε₀)² G_c and
Cpow = sup_n ‖L^n‖/μ^n ≤ **3246.8** [CA, N8] ⇒ G_b ~ **4×10⁸**. That forced g₁ ≈ 64.
**This is not the C0 of Estimate U after N12/N13**; it is the gap transient in the
working norm.

### 1.2 Adapted H-norm (TRACE-311) [CA]

N12/N13 Stein/Lyapunov norm H = ω ψ̄ψᵀ + Q̃*P Q̃, kap = 0.45, ω = 1:

| piece | value | role in C0 |
|---|---:|---|
| V3b ‖(A0/s)Q̃‖_H ≤ kap | **0.45, constant 1** | **C_gap = 1** (replaces Cpow/R₂) |
| V1 cond_H = c_hi/c_lo | **≤ 21.103** | only if converting H → Euclidean |
| Lip_H | ≤ 167.213 | twist Lipschitz |
| N_H(t) ≤ 1+1e-12+4260 t² | \|t|≤1/256 | local step bound |
| Nsum | ≤ 8.3288 | crude one-step any t |
| core→true Pert_H/\|s\| | ≤ 2.1e-8 | negligible |

Scalar path: |ψ B Φ| ≤ ‖B‖_H when ‖Φ‖_H = 1 and ‖ψ‖_* ≤ 1 [P-sketch from H's
dominant block]. **cond_H does not multiply C0 on this path.**

### 1.3 Decomposition for Estimate U

```
C0 ≤ C_end² · C_bump · C_gap · C_core_true
```

with C_gap = 1 [CA], C_core_true = 1+O(10⁻⁸), and (C_end, C_bump) the geometric
stay-end / bump products in H-norm (§2).

### 1.4 Scope warning [P-sketch]

N11 bumps have **geometrically decaying** twists δ_k ~ θ λ^{−k}, not long constant-|t|=η
words. Fixed-twist ρ(A(η)/s) ≈ 0.956 at η=1/20 [N, ckpt 01]. Using r = ρ_cut ≈ 0.223
as the rate against those words makes C_trans explode. Estimate U's C0 is meaningful
only for **N11-scoped geometric bumps / coded types**. Arbitrary non-resonant words
need a different rate (max_t ρ(t) ≈ 0.96, useless for H5(b)).

### 2.4 Weight-family (kap) optimisation [N, failed rebuild]

Approximate Stein rebuild with frozen eigenpair (`05_kap_scan.json`): cond falls with

### 2.5 Interval arithmetic for C0

C0 reduces to finitely many quantities only after fixing a finite type list (N12's
~1350 coded two-bump windows + singles). That is exactly N13's c_replay arb queue
(interaction δ_int), **not re-done here**. A closed-form C0 ≤ 3 from N_H-table products
alone is false (prod N_H ≫ 1); the cancellations that make ‖∏‖_H = O(1) need the
actual product, i.e. per-type or geometric-family enclosures.
