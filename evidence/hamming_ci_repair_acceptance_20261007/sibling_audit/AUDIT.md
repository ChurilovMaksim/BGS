## Hamming findings requiring repair

1. `computations/verification/fractional_hamming_replay.py:80-91` removes only expected `/elapsed_seconds` from author data, then uses ordinary Python equality. The original author source (`evidence/fractional_hamming_20261007/raw/author/checks.py:178`) records `/python = sys.version`, `/sympy = sp.__version__`, and `/elapsed_seconds = time.time()-T0`. Its maintained port (`fractional_hamming/author_checks.py:237`) emits `/python` and `/sympy` but omits elapsed time. Those two root strings are known environment provenance, not science.
2. `computations/verification/fractional_hamming/full_replay.py:37-42,87,132-133` repeats the same author defect. Its docstring and `omitted_fields` report explicitly say Python version is retained in equality. This archival sibling should use the same repaired comparator as the default path. The historical copies under `evidence/.../executed_sources` and `replay_history` are frozen history and should remain untouched.
3. `fractional_hamming/check_routing.py:55-59` fabricates author actuals from frozen result bytes, retaining frozen `/python` and `/sympy`. Consequently its routing test passes in a different runtime and masks the metadata defect. A revised fixture needs intentionally different valid runtime metadata and adversarial schema/type mutations.
4. Default raw observed output is deleted on failure: its `TemporaryDirectory` at line 62 cleans up even after line 91 raises. The fixture probes verified this. The hosted artifact therefore contains a traceback, not the failing actual JSON. `verify_workspace.py:30-35` routes durable artifacts for four other replay families but has no Hamming route. A durable explicit output mode and all-nine-entry routing are needed to retain future CI evidence.
5. Archival `full_replay.py` leaves a failed result JSON in its requested output directory, but `output_files` and `records` are updated only after successful equality (lines 148-150). A mismatch therefore omits that failed actual from `declared_results`/`outputs`. Preserve and declare raw actual bytes before parsing/comparing, including failure, and retain raw expected bytes, stdout/stderr, observed runtime metadata, hashes, bounded mismatch paths, and failure status.

The default author and synthesis routes and all eight split paths were exercised with scientific fixtures in both normal and optimized modes. Split cases are exactly `full_end_2_1`, `full_end_2_2`, `full_end_2_3`, `full_end_3_2`, `top_gram`, `torus`, `network`, `offcharge_bound`. `case_runner.py:29-34` returns either the selected scientific family subobject or filtered full-End rows; it does not emit `/runtime_seconds`, `/python`, or `/sympy`. Frozen independent `all_results.json` contains only `/runtime_seconds` as root provenance. Frozen synthesis contains no provenance fields.

Recommended repair boundary: a common, strict, schema-aware, nonrecursive comparator for these exact Hamming roots/subobjects; separate only declared top-level provenance, retain its raw values and bytes, and compare every remaining scientific value and type. Validate present metadata and required family-specific fields. Account explicitly for the author/reviewer historical runtime field being absent from maintained adapter output. Do not generically drop keys by name, change mathematics or adapter output bytes, normalize scientific strings, or rewrite frozen expected data/history.

## Schema/type and retention caveats outside the CI blocker

No accidental recursive stripping was found: all separators act on root dictionaries. Schur, charge, checkpoint, and intermediate reject nested provenance-named additions and preserve typed scientific equality; probes verify this. Schur, charge, and checkpoint also reject duplicate keys/nonfinite JSON through strict parsers. Intermediate uses ordinary JSON decoding but a typed recursive scientific comparator.

Hamming uses ordinary JSON decoding and ordinary Python equality, so a scientific integer changed to an equal float is accepted; probes demonstrate this in both the direct archival equality and the actual default wrapper route. Central-residual, half-radius, residual125, and odd-newest likewise use ordinary dictionary equality, which conflates equal numeric types. Their runtime exemptions either require presence (`pop`/`del`) or, for archival Hamming, silently tolerate absence; central/half/odd/residual runtime values lack finite/nonboolean validation. These are fail-closed hardening gaps, not additional observed version-CI failures. No broadened sibling repair is warranted for the narrow metadata incident.

Schur and checkpoint explicit durable modes retain raw actual bytes before comparison and publish failure receipts; the workspace routes them. Charge explicit durable mode saves actual result/stdout/stderr before equality, but expected bytes and full failed comparison/provenance are not published when an exception prevents its final manifest. Intermediate mismatch diagnostics retain raw actual/expected plus environments even without its durable option. Central, half-radius, and residual125 use temporary outputs cleaned on failure; odd-newest retains outputs when invoked with its explicit output directory, but its top-level certificate wraps that directory in temporary storage. These retention gaps are recorded, not silently claimed resolved.
