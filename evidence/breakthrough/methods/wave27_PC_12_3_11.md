# Wave 27, task 6 — Lemma PC for (m, p₁, p₂) = (12, 3, 11): PROVED

## Verdict

PC is **proved** for (12, 3, 11), adapting the wave-26 triangle method
from mod 5 to mod 11. The (3,17) transplant stays blocked (classes are
triangles, not symmetric pairs), but the triangle method itself
transfers, and the recovery lemma is proved here structurally by power
sums — stronger than the mod-5 finite 7-triangle check. Repository
untouched; no Lean built.

## 1. Setup (wave 14/26 notation)

m = 12, t = gcd(12, 4) = 4, classes O_r = {r, r+4, r+8}, r ∈ ℤ/4,
D₄ acting by r ↦ εr + k (mod 4). a_j = Tr(Aα^j) mod 3,
b_j = Tr(Bα^j) mod 11, α = 3+2√2. Πᵢ = {π ∈ D₄ : per-class multisets
match}; hypothesis (∗): {(a_{d₁(j)}, b_{d₂(j)})} = {(a_j, b_j)}.

## 2. The mod-3 side (unchanged from wave 26 §2)

α⁴ = 1 mod 3, so a is 4-periodic and constant = v_r on class r, with
v = (−x, −y, x, y) mod 3 for A = (x, y). If A = 0, Π₁ = D₄ (trivial).
Else v-fibres have size ≤ 2, and some reflection ρ = (−1, k) ≠ id
lies in Stab(v), swaps within pair fibres and fixes singletons
(x = 0 → k = 2; y = 0 → k = 0; x = y → k = 1; x = −y → k = 3).

## 3. The mod-11 side: triangles and the (M, N, −M, −N) pattern

ord(α) = 12 mod 11, ζ := α⁴ = (5, 1) has order 3, 1 + ζ + ζ² = 0,
and α⁶ = −1. Class O_r carries the triangle
T_r = {Tr(Bα^r), Tr(Bα^r ζ), Tr(Bα^r ζ²)}, summing to 0 mod 11.
Since b_{j+6} = −b_j and O_{r+2} = O_r + 6, the pattern is
**(M, N, −M, −N)** with M = T(B), N = T(Bα) — the sign-flipped
analogue of the mod-5 (M, N, M, N) pattern (there α⁶ = 1).
If all T_r are equal, Π₂ = D₄ (trivial). Else proceed.

## 4. Reduction (P) (wave 26 §4 verbatim)

Grouping (∗) by first coordinate p: a is constant = v_r on class r,
and as j runs over O_r, d₂(j) runs over O_{π₂(r)}. With
δ = π₁ ∘ π₂⁻¹ and ε = δ⁻¹, (∗) becomes, for every v-fibre F,
(P): ⊔_{f ∈ F} T_{ε(f)} = ⊔_{f ∈ F} T_f (value multisets).

## 5. Triangle recovery lemma mod 11 (structural proof)

Let T(z) = {Tr(zζ^s) : s = 0, 1, 2} for z ∈ R/11, ζ̄ = ζ².
Power sums of one triangle (cross terms vanish by Σ_s ζ^s = 0):
Σ t = 0, Σ t² = 6N(z), Σ t³ = 3Tr(z³), where N(z) = zz̄.
Conversely, w = z³ satisfies w² − Tr(z³)w + N(z)³ = 0, so w is
determined up to conjugation, and z up to ⟨ζ⟩ and conjugation —
exactly the ambiguity fixing T(z). Hence **(N(z), Tr(z³)) determines
T(z)** (for z = 0 both are 0 and T = (0, 0, 0)).

**Union lemma.** If T_a ⊔ T_b = T_c ⊔ T_d as 6-multisets, then
{T_a, T_b} = {T_c, T_d}. Proof by power sums of the union:
p₂ = 6(N_a + N_b) and p₄ = 18(N_a² + N_b²) determine {N_a, N_b}
(via N_aN_b = ((N_a+N_b)² − (N_a²+N_b²))/2);
p₃ = 3(τ_a + τ_b) and p₅ = 15(N_aτ_a + N_bτ_b), τ = Tr(z³),
determine {τ_a, τ_b} when N_a ≠ N_b (linear system, determinant
N_a − N_b); when N_a = N_b ≠ 0, p₆ = 3(τ_a² + τ_b²) + 54(N_a³+N_b³)
gives τ_aτ_b, hence {τ_a, τ_b}. Each (N, τ) then determines its
triangle. All divisions (by 2, 3, 6, 15, 18) are valid in
characteristic 11. Exhaustive check agrees: 26 distinct triangles
mod 11, 0 collisions among pairs of unions.

Hence (P) implies the item-level condition (I):
{T_{ε(f)} : f ∈ F} = {T_f : f ∈ F} for every v-fibre F
(|F| = 1 is trivial; |F| = 2 is the union lemma).

## 6. Assembly (wave 14 §§5–7 verbatim, with triangles for pairs)

Singletons give T_{ε(s)} = T_s pointwise; pair fibres give
match-or-swap by (I). The case analysis (A) one pair + two
singletons / (B) two pairs uses only fibre sizes ≤ 2 and
ρ ∈ Stab(v), so it yields E = T or E = T ∘ ρ (E = T ∘ ε), hence
δ ∈ Stab(v)·Stab(T); writing δ = σ_v ∘ σ_c, the element
π = σ_c ∘ π₂ lies in Π₁ ∩ Π₂ (same computation as wave 14 §7).
This proves PC for (12, 3, 11). ∎

Note (as in wave 26 §6): Π-shapes alone do NOT force the conclusion
— the (M, N, −M, −N) pattern's stabiliser and Stab(v) can be
disjoint as sets. The hypothesis (∗) is essential, and only through
(P) → (I) → assembly does the intersection follow. The assembly
does not use the pattern shape, so the sign flip from mod 5 costs
nothing.

## 7. Non-degeneracy witness and numerical confirmation

Witness (d₁ = d₂ = id): A = (0, 1) mod 3 gives v = (0, 2, 0, 1),
fibres [0, 2], [1], [3], Π₁ = {id, ρ₂}; B = (1, 0) mod 11 gives
triangles ((2, 10, 10), (0, 5, 6), (1, 1, 9), (0, 5, 6)),
Π₂ = {id, ρ₀}; intersection {id} ≠ ∅, neither side full.
