# O* при m=8 — рабочая заметка (не теорема, не deliverable)

## Вердикт

O* при m=8 **выживает в смысле разделения** и **падает в строгом
смысле** — эти два чтения надо различать, иначе отчёт врёт:

- **(R) Разделение: 0 плохих волокон из 85106.** Каждый вектор волокна
  есть аффинная перестановка представителя: все точки волокна имеют
  один аффинный каноник (лексикографический минимум по 32 перестановкам
  `p[j] = a·j + b mod 8`, `a ∈ {1,3,5,7}`).
- **(S) Строгое равенство «волокно = полная аффинная орбита»: ложно
  для 84672 волокон из 85106.** Аффинные перестановки в общем случае
  не сохраняют `Fix₈` множественно (`σHσ⁻¹ = 6I − C³ − C⁻³ ≠ H`
  при `a = 3`), поэтому полная орбита обычно содержит векторы вне
  ядра. Строго хороши только 434 волокна (по размерам: 1:4, 2:14,
  4:90, 8:191, 16:102, 32:33).

## Числа (точный целочисленный перебор, CRT по 9·289·512)

- `D₈ = 1331712`, точек `Fix₈` — 1331712, волокон — 85106.
- Размеры волокон: 1:4, 2:14, 4:90, 8:3647, 16:81318, 32:33.
- Γ-плохих волокон — 39, воспроизведено независимо: 33 волокна
  размера 32 (орбиты 16+16) и 6 волокон размера 16 (орбиты 8+8).
  Всего Γ-орбит — 85145.
- **Поправка к таблице M08:** её распределение орбит (8:3653,
  16:81345, сумма 85106) считает по одной орбите на плохое волокно:
  оно недосчитывает ровно 39 вторых орбит (33 размера 16 и 6
  размера 8). Число плохих волокон (39) от этого не меняется.
- Три примера из `M08_BAD_M8.json`: аффинная орбита размера 32,
  все 32 вектора в ядре, орбита = волокно (для них верны оба чтения).

## Явный пример строгого провала

Волокно размера 16, представитель
`y = (0, 244800, 137088, 577728, 665856, 753984, 1194624, 1086912)`.
Его аффинная орбита — 32 кортежа, из них 16 вне `Fix₈`, например
`(0, 577728, 1194624, 244800, 665856, 1086912, 137088, 753984)`:
тот же мультисет, но `H·y′ mod D =
(0, 940032, 1018368, 940032, 0, 391680, 313344, 391680) ≠ 0`.
Поэтому формулировку O* «волокно равно орбите» в строгом смысле
нельзя использовать нигде: корректная форма — только (R).

## CRT-склейка

Покомпонентно (ядра mod 9, 289, 512; волокон 3, 27, 76) чтение (R)
тоже выполняется везде: плохих волокон 0. Значит, при m=8 склейка
несовместимых множителей `a_p` **не реализовалась** — глобальный
исчерпывающий тест это исключает. Но механизм для m ≥ 9 остаётся
живым: у `D₉` примарные компоненты 4, 49, 39601, у `D₁₂` их ещё
больше, и там вектор, аффинный покомпонентно с разными `a_p`,
но не глобально аффинный, мог бы существовать. Следующий тест —
целенаправленный поиск такой склейки на уровне компонент при
m=9, 12, а не полный перебор (7,7 млн точек при m=9 — на грани,
при m=12 невозможен).

## Что это даёт для 152

- `hSep` в исходной Γ-формулировке остаётся ложным; O* его не
  «чинит», а заменяет класс разделения: пара с равными modeSum
  (отсюда равные мультисеты по Ньютону) лежит в одной **аффинной**,
  а не диэдральной орбите. `modeSum` инвариантен относительно
  любой перестановки координат, значит, и относительно `Aff`,
  так что шаг разделения с `Aff` содержательно тот же.
- Но числовое значение меняется: `Bsym` в проекте определён через
  размеры **Γ**-орбит, а при замене группы предел strong-kick
  (если остаток цепочки — затухание `ω` вне аффинных пар —
  держится) равен аффинному аналогу
  `(1/|supp|) Σ_M |aff-волокно(M)|²`, а не Γ-`Bsym`.
  Пример: первое плохое волокно даёт вклад 32, а не 16.
  Утверждение 152 нуждается в переформулировке, а не в молчаливой
  замене группы.
- O* проверено только при m=8. Для общего m это по-прежнему
  гипотеза; O′ (ограничение носителем) при m=8 теперь избыточно
  в смысле разделения (оно верно везде), но для общего m остаётся
  более слабым запасным вариантом.
