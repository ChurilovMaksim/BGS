# Wave 11, task 1 — Per-class pattern lemma: proof

## Statement

Let $P = 2^L$, $L \ge 2$, and let $p, p' \in \mathrm{Fix}_P \bmod 2^a$,
$a = 2L+3$, be patterns (solutions of $y_{n+1} = 6y_n - y_{n-1}$ modulo
$2^a$ with period dividing $P$). Classes are $r \in \mathbf{Z}/4$,
class $r = \{j : j \equiv r \pmod 4\}$. $D_4$ acts on classes by
$r \mapsto r+b$ and $r \mapsto -r+b$.

**Theorem.** If $p$ and $p'$ have the same multiset, then their
per-class multisets are $D_4$-related: there is $\pi \in D_4$ with
$M'_r = M_{\pi(r)}$ for all $r$, where $M_r$ (resp. $M'_r$) is the
multiset $\{p_j : j \equiv r \pmod 4\}$ (resp. for $p'$).

This is exactly the lemma Lemma Y needs at the 2-primary level:
given a class-permuting pattern $\tau$, the blockwise lift
$\sigma'(kP+j) = kP + \tau(j)$ is a global class-permuting matching.

## Reduction to blocks

All pattern entries are divisible by $2^L$ (checked for $P=4,8,16$;
it follows from the recurrence and $v_2$ of the initial values).
Dividing by $2^L$ gives a bijection between patterns mod $2^{2L+3}$
and blocks

$$r_s = T c_s + D e_s \pmod{2^{L+3}}, \qquad s = 0, \dots, 2^L - 1,$$

where $c_0 = 1$, $c_1 = 3$, $e_0 = 0$, $e_1 = 1$,
$c_{n+1} = 6c_n - c_{n-1}$, $e_{n+1} = 6e_n - e_{n-1}$,
$T$ is arbitrary mod $2^{L+3}$, and $D$ is a multiple of $8$.
Scaling by $2^L$ is injective, so per-class multisets of patterns
are $D_4$-related iff those of the corresponding blocks are.
Henceforth we prove the theorem for blocks.

Write $W = T + (D/4)\sqrt2 \in \mathbf{Z}[\sqrt2]$, so that
$r_s = \mathrm{Tr}(W \alpha^s)/2$ with $\alpha = 3 + 2\sqrt2$,
$\alpha^s = c_s + 2e_s\sqrt2$.

## L1. Period lemma

For $t \ge 5$, a block reduced mod $2^t$ has period $2^{t-3}$:
$r_{s + 2^{t-3}} \equiv r_s \pmod{2^t}$ for all $s$.

*Proof.* $\alpha$-power lemma: for $j \ge 2$,
$\alpha^{2^j} \equiv 1 + 3\cdot 2^{j+1}\sqrt2 \pmod{2^{j+4}}$.
Indeed for $j=2$, $\alpha^4 = 577 + 408\sqrt2 \equiv 1 + 24\sqrt2
\pmod{64}$; and if $u = 3\cdot 2^{j+1}\sqrt2$, then
$(1+u)^2 = 1 + 2u + u^2$ with $2u = 3\cdot 2^{j+2}\sqrt2$ and
$u^2 = 9\cdot 2^{2j+3}$, which is $0 \bmod 2^{j+5}$ for $j \ge 2$,
giving the induction step.
Now let $M = 2^{t-3}$. Then
$\alpha^M - 1 \equiv 3\cdot 2^{t-2}\sqrt2 \pmod{2^{t+1}}$.
Write $W\alpha^s = A_s + B_s\sqrt2$ with $A_s = r_s$ and
$B_s = 2Te_s + (D/4)c_s$. Since $D/4$ is even and $c_s$ is odd,
$B_s$ is even. The rational part of
$W\alpha^s(\alpha^M - 1)$ is $B_s \cdot 3\cdot 2^{t-1}$,
a multiple of $2^t$. Hence $r_{s+M} \equiv r_s \pmod{2^t}$. ∎

In particular, mod $32$ the period is $4$: $r_s \bmod 32$ depends
only on $s \bmod 4$. The **base tuple** is
$x = (x_0,x_1,x_2,x_3)$ with
$x_r = r_s \bmod 32$ for $s \equiv r \pmod 4$, i.e.
$x = (T,\ 3T+D,\ 17T+6D,\ 3T+3D) \bmod 32$, $D = 8d$.

## L2. Shift lemma

Let $t \ge 5$ and consider a segment at level $t+1$ (length $2M$,
$M = 2^{t-3}$, modulus $2^{t+1}$). Then for $s < M$,
$$r_{s+M} \equiv r_s + 2^t \delta_s \pmod{2^{t+1}}, \qquad
\delta_s = \big(D/8 + T\cdot(s \bmod 2)\big) \bmod 2,$$
so $\delta_s$ depends only on the class parity: write
$\delta^{(r)} = (d + T\cdot(r \bmod 2)) \bmod 2$ with
$d = D/8 \bmod 2$.

*Proof.* Same computation as L1 with $M = 2^{t-3}$:
$\alpha^M - 1 \equiv 3\cdot 2^{t-2}\sqrt2 \pmod{2^{t+1}}$,
rational part of $W\alpha^s(\alpha^M-1)$ is
$B_s \cdot 3\cdot 2^{t-1} = (B_s/2)\cdot 3\cdot 2^t$.
Mod $2^{t+1}$ this is $2^t \cdot ((B_s/2) \bmod 2)$, and
$B_s/2 = Te_s + dc_s \equiv T\cdot(s \bmod 2) + d \pmod 2$,
since $e_s \bmod 2 = s \bmod 2$ and $c_s \equiv 1 \pmod 2$. ∎

## L3. Base lemma (mod 32)

If two base tuples have the same multiset, they are $D_4$-related.

*Proof.* Mod $16$, $x \equiv (T,\ 3T+8d,\ T,\ 3T+8d)$.
Put $a = T \bmod 16$, $b = (3T+8d) \bmod 16$.
If $a \ne b \bmod 16$, the multiset splits by mod $16$ into the
$a$-pair $\{x_0,x_2\}$ and the $b$-pair $\{x_1,x_3\}$.
The subgroup of $D_4$ preserving the partition $\{\{0,2\},\{1,3\}\}$
is the Klein $4$-group generated by swapping $0\leftrightarrow2$
and $1\leftrightarrow3$; it acts transitively on the $4$ assignments
of the two values in each pair to the two classes. Hence the
$D_4$-orbit is determined by the two pair-multisets, which are
determined by the overall multiset.
If $a = b \bmod 16$, then $T \equiv 0 \pmod 4$ and there are only
$16$ cases $(T \bmod 32, d)$. Direct check gives: the multiset
determines the $D_4$-orbit, with the count-$2$ case alternating
iff the common value $v \equiv 0 \pmod 8$ and adjacent iff
$v \equiv 4 \pmod 8$ (e.g. $(0,0,16,16)$ is alternating,
$(4,4,20,20)$ is adjacent; constant cases are trivial). ∎

## Segments and induction

For $t \ge 5$, a **segment at level $t$** is the first $M = 2^{t-3}$
values of a block mod $2^t$. Its per-class multisets are defined by
$s \bmod 4$. Since $M$ is a multiple of $4$ and values mod $32$
depend only on $s \bmod 4$, the per-class multiset for class $r$,
reduced mod $32$, is $(M/4)$ copies of $x_r$; hence the base tuple
is recovered from the per-class multisets.

**Induction hypothesis IH($t$).** If two segments at level $t$
have the same overall multiset, their per-class multisets are
$D_4$-related.

IH($5$) is L3 (segments of length $4$, per-class multisets are
singletons). We prove IH($t$) $\Rightarrow$ IH($t+1$) for $t \ge 5$.
Let $A,B$ be segments at level $t+1$ (length $2M$, modulus $2^{t+1}$)
with the same overall multiset. Their reductions mod $2^t$ have
the same overall multiset, so by IH($t$) their level-$t$
per-class multisets are $\pi$-related for some $\pi \in D_4$.
Relabel $B$'s classes by $\pi^{-1}$; it suffices to prove the
level-$(t+1)$ per-class multisets are then exactly equal
(resp. determined as below), since undoing the relabelling gives
$\pi$-relatedness.

**$\delta$-covariance.** If base tuples are $\pi$-related, then
$\delta$-patterns are $\pi$-related:
$\delta^B_{\pi(r)} = \delta^A_r$. It suffices to check generators:
shift $(T,D) \mapsto (3T+D,\ 8T+3D)$ gives
$d' = T + d \pmod 2$ (rotation by $1$, flips parity, and
$d' + T = d$); reflection $(T,D) \mapsto (T,-D)$ gives $d' = d$
(parity-preserving); reflection composed with shift by $1$ gives
$d' = T + d$ (parity-flipping). Composition preserves the relation.
Hence after normalisation, $A$ and $B$ (relabeled) have the same
base tuple and the same $\delta^{(r)}$ for every $r$.
Write $T_2 = T \bmod 2$, $d = D/8 \bmod 2$ (common to $A,B$ after
normalisation). Three cases:

**Case A: $T_2 = 0$, $d = 1$.** Then $\delta^{(r)} = 1$ for all $r$.
For $s$ in class $r$ (first half), the pair (first-half lift,
second-half lift) is $(b_s, b_s + 2^t)$ in some order, where $b_s$
is the level-$t$ value, since the second half is the first half
shifted by $2^t$. Hence the full per-class multiset for class $r$
is: each level-$t$ value $b$ with multiplicity $m_r(b)$ contributes
$m_r(b)$ copies of $b$ and $m_r(b)$ copies of $b + 2^t$.
It is determined by the level-$t$ per-class multiset. Since
$A,B$ share level-$t$ per-class multisets, their level-$(t+1)$
per-class multisets are exactly equal. ∎

**Case B: $T_2 = 0$, $d = 0$.** Then $T$ is even and $D$ is divisible
by $16$, so all values are even. Divide by $2$: we get sequences
$A',B'$ of length $2M$ mod $2^t$ with parameters $(T/2, D/2)$
($D/2$ a multiple of $8$), which are $M$-periodic by L1. Their
first $M$ positions are segments $A'_0, B'_0$ at level $t$.
Equal overall multisets for $A,B$ imply equal overall multisets
for $A'_0, B'_0$ (divide by $2$, halve the doubled multiset).
By IH($t$), $A'_0, B'_0$ per-class multisets are $\pi'$-related.
Original per-class multisets are obtained from these by
"multiply values by $2$ and double multiplicities" (using
$M$-periodicity and $M \equiv 0 \pmod 4$ for class alignment),
which commutes with class permutation. Hence $A,B$ per-class
multisets at level $t+1$ are $\pi'$-related. ∎

**Case C: $T_2 = 1$.** Then $\delta^{(r)} = d$ for even $r$ and
$1-d$ for odd $r$: one parity has $\delta = 1$, the other $\delta = 0$.
For $\delta = 1$ classes, Case A gives full per-class multisets
from level-$t$ per-class multisets. For $\delta = 0$ classes,
we use disjointness:
- Cross-parity base values are distinct mod $16$ (hence mod $32$)
  when $T$ is odd: the four differences $x_{\text{even}} -
  x_{\text{odd}}$ are $\equiv \pm 2T \pm 8d$ or $\equiv 14T \pm 8d
  \pmod{16}$, and $2T, 14T \bmod 16 \in \{2,6,10,14\}$ for $T$ odd,
  so no difference is $0 \bmod 16$.
- The two $\delta = 0$ classes have bases differing by exactly
  $16 \bmod 32$: if $d$ is even, $\delta = 0$ classes are even
  ($0,2$) and $x_2 - x_0 = 16T + 48d \equiv 16 \pmod{32}$ (since
  $T$ odd, $d$ even); if $d$ is odd, $\delta = 0$ classes are odd
  ($1,3$) and $x_3 - x_1 = 16d \equiv 16 \pmod{32}$.
Hence the two $\delta = 0$ classes have disjoint value sets, and
their bases are distinct from all $\delta = 1$ classes' bases
mod $32$. Therefore, grouping the overall multiset at level $t+1$
by value mod $32$, the values with base $\equiv x_r$ for a
$\delta = 0$ class $r$ are exactly class $r$'s full per-class
multiset. So $\delta = 0$ classes' multisets are determined by
the overall multiset and the (common) base tuple, and together
with the $\delta = 1$ classes they give exactly equal
level-$(t+1)$ per-class multisets after normalisation. ∎

This completes IH($t+1$). For a full block with $P = 2^L$,
$t = L+3$; for $L = 2$ this is L3, for $L \ge 3$ it follows by
induction from $t = 5$ to $t = L+3$. This proves the theorem for
blocks, hence for patterns.

## Computational confirmation

Exact C++ check (`wave11_p64.cpp`, enumerating all blocks by
$(T,D)$, grouping by sorted multiset, testing per-class multisets
against a single $D_4$ orbit):

- $P = 64$ ($L=6$, modulus $512$): 32768 blocks, 539 groups,
  8,412,174 pairs, **0 bad groups**.
- $P = 128$ ($L=7$, modulus $1024$): 131072 blocks, 1056 groups,
  129,997,838 pairs, **0 bad groups**.

This extends the Wave 10 verification ($P \le 32$, 1,120,284 pairs)
to $P = 128$ with no counterexample.

## Status and consequence

The per-class pattern lemma is **proved** (proof above;
Lean formalisation not attempted, per task scope). In particular
the naive "flip" argument is not used: first-half lifts of two
blocks with the same level-$t$ per-class multisets need not be
flip-related (e.g. $(T,D) = (0,8)$ vs $(0,40)$ at $L=5$), but the
full per-class multisets are still controlled, via the
$\delta = 1$ doubling formula, the scaling reduction (Case B),
and base-disjointness (Case C).

Consequence for Lemma Y: with the odd component (Wave 8), P2
uniform (Wave 10), P3' (Wave 9), and now Pmix via this lemma,
all four components of Lemma Y are proved in sketch form.
Lemma Y is therefore closed as a proof sketch; its Lean
formalisation remains open, as does the application of Lemma Y
to claim 152 (restatement vs O' route).

Note on scope: this closes the *pattern* lemma (Task 1). It does
not by itself close the full exact per-class lemma for $\mathrm{Fix}_m$
(Task 2, separate note `wave11_perclass_proof.md`), whose remaining
gaps G1 (odd prime-power lift) and G3 (common $\pi$ across
components) are untouched here.
