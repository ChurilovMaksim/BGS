# O′ при m=8 — рабочая заметка (не теорема, не deliverable)

## Вердикт

O′ выживает при m=8, и сильнее: ни одно из 39 плохих волокон не
пересекает носитель φ̂₈ вообще. Примера пересечения нет.

## Определения (main)

- `mathematics/fixed-map/band_limited_kick_bridge.md` §4 (D3, Prop R):
  φ̂_s(ξ) = D⁻¹ Σ_n e(2sQ(n) − n·ξ), |φ̂_s|² ∈ {0, |V[4]|/D}, носитель
  не зависит от s (s нечётное, взаимно простое с D).
- `formalization/Bgs/LineDOrbitPairFull.lean`: `phihat` через
  `phiSummand` (Qnum/pairNum по adjugate X_m), `torsionSubgroup`
  (4·[z] = 0 в V = ℤ^m/H_mℤ^m), `phihatFix` = `phihat ∘ fixEquivQuot`,
  `phihat_modulus`: |φ̂|² = D⁻¹ · Σ_{γ∈torsion} phiSummand(w, γ),
  сумма равна |torsion| или 0.
- Отсюда критерий носителя (s = 1): для w = (H·lift(y))/D и
  z_γ = (H·v_lift)/4 при v ∈ V4 = ker(H mod 4) нужно
  (2·Qnum(z_γ) − pairNum(z_γ, w)) ≡ 0 (mod D) для всех 16 γ.
  Здесь 2·Qnum(z_γ) ≡ 0 (mod D) для всех γ, так что критерий —
  pairNum(z_γ, w) ≡ 0 (mod D).

## Перебор (скрипт: oprime_m8_test.py)

- D = 1331712 = 9·289·512. Fix₈ перечислен через CRT: ker mod 9 = 9
  точек, mod 289 = 289, mod 512 = 512; всего 1331712 точек.
- Волокно = класс по sorted(y); Γ-орбита = лексикографический
  минимум по 16 диэдральным перестановкам j ↦ ±j + k.
  (Осторожно: поэлементный минимум по орбитам — не каноник:
  действие транзитивно, он даёт константу; первая версия скрипта
  из-за этого дала 0 плохих волокон, после исправления на
  лексикографический минимум — ровно 39.)
- Сверка: волокон 85106, максимальный размер 32, плохих 39 —
  совпадает с M08. Точек в плохих волокнах 1152.

## Результат

- Точек носителя в плохих волокнах: 0 из 1152, во всех 39 волокнах.
- Независимая векторная проверка критерия носителя на всех
  1331712 точках: размер носителя 83232 = D/|V4| = D/16, как
  требует теория (|φ̂|² = |V4|/D на носителе, Σ|φ̂|² = 1).
  Это подтверждает и сам критерий, и реализацию.
- Три примера из M08_BAD_M8.json также вне носителя (по 12 из 16
  torsion-условий не выполнены в каждом).
