# Wave 45, task 2 — JBL-grade pairing at m=32, (8192,577), by sampling

## Verdict

**No JBL-bad pair found.** JBL-grade pairing (equal globals ⟹
per-class joints agree under some π ∈ D₄) holds on the entire
sample at the dangerous pair (8192,577): 57,939,907 exact global
collisions checked, 0 JBL-bad. This is sampling, not a proof —
but the dangerous regime here is generic, not a corner (§4), and
the per-B2 slices are exhaustive within each slice (§2).
Repository untouched; no Lean built.

## 1. Setup (definitions verbatim from wave44_GPL_test.py)

m = 32, t = gcd(32,4) = 4, classes r = i mod 4. Genuine B ∈
ker(α³² − 1) in R/M, R = ℤ[√2]; sequence s_i = Tr(Bα^i) mod M.
Per-class joints: sorted pairs (p_i, o_i), i ≡ r (mod 4);
global: sorted pairs over all i. JBL check: ∃π ∈ D₄ with
j[r] = j0[π(r)] for all r. Facts verified first: α³² ≡ 1 mod
577R, so all 332,929 Bq are genuine; |G2| = 8192 (solver
replication, wave43 witness side (0,128) confirmed genuine).
Pattern class-period profiles over all 8192 B2: (1,1,1,1)×2048,
(2,2,2,2)×2048, (4,4,4,4)×4096 — all classes share one period
per B2. Exhaustive census (8192 × 332,929 ≈ 2.73·10⁹ pairs)
is infeasible, hence sampling.

## 2. Phase A — per-B2 slices, all Bq (100,544,558 pairs)

Stratified sample of 302 B2 (100 per profile, plus forced
(0,128) and (0,64)); for each, ALL 332,929 Bq enumerated,
globals hashed (sum of per-position hashes, every match
verified by exact sorted comparison; 0 hash false alarms),
every exact collision JBL-checked:

| profile | slices | collisions | π = id | π ≠ id | JBL-bad |
| 1 | 100 | 29,126,664 | 12,498,408 | 16,628,256 | 0 |
| 2 | 101 | 19,467,072 | 14,158,656 | 5,308,416 | 0 |
| 4 | 101 | 8,641,152 | 0 | 8,641,152 | 0 |
| total | 302 | 57,234,888 | 26,657,064 | 30,577,824 | 0 |

So for each sampled B2, the JBL-grade statement is verified
against EVERY Bq — the sampling is only over the pattern side.
Two structural facts: (i) profile-4 collisions NEVER agree
under π = id — every one is genuinely π-twisted, yet a π
always exists; this is the JBL-grade phenomenon in pure form
(and why the class-by-class GPL fails while JBL holds).
(ii) Forced slice (0,64) has 0 collisions at all; forced
slice (0,128) (wave43 witness pattern side) has 166,464
collisions, all π = id, 0 bad.

## 3. Phases B and C — cross-B2 and structured siblings

- **Phase B** (random full pairs): 3,000,000 random (B2, Bq),
  globals hashed across the sample: 705,019 exact collisions
  (88,356 π = id, 616,663 π ≠ id), **0 JBL-bad**. The 23.5%
  collision rate is real: globals are highly degenerate
  (dihedral orbits), which is what makes sampling productive.
- **Phase C** (structured siblings): 2,000 random (B2, Bq) × 5
  siblings (−Bq, conj(Bq), Bq·β^k, k = 1,2,3) = 10,000 tests:
  3,288 give global equality, **0 JBL-bad**.

## 4. The dangerous regime is generic here

Odd class-0 periods over 20,000 random Bq: **4 in all 20,000**
(0 with period 1 or 2). Wave43's criterion says the Pairing
Lemma fails exactly when both periods are even; at (8192,577)
the odd side is ALWAYS period 4, and 6,144/8,192 pattern sides
have even period — so the sample tested the dangerous regime
pervasively, not at isolated points. Collision rates match
dihedral-orbit sizes (50% / 75% / 87.5% per slice).

## 5. A bug caught and fixed (method note)

The first C++ run reported 48% JBL-bad — an artifact of C++
`%` on negative numbers in the D₄ builder (`(-r+b) % 4`
yields negatives, unlike Python), corrupting every reflection
π and reading out of bounds. Fixed by normalizing
`((eps*r+b) % t + t) % t`, plus a permutation self-test (8
distinct perms). The fixed implementation was validated by an
independent Python recomputation (wave44 definitions verbatim)
of slice B2 = (3712,7168): exact match — coll = 291,024,
id = 125,712, nonid = 165,312, bad = 0.

## 6. What this does and does not establish

- **Establishes:** JBL-grade pairing at (8192,577) for all Bq
  at 302 sampled pattern sides (all three profiles), for
  3M random cross-pattern pairs, and for 3,288 structured
  sibling collisions — 0 bad in 57,939,907 collisions.
- **Does not establish:** the exhaustive (8192,577) census
  (2.73·10⁹ pairs, still infeasible); other dangerous pairs,
  e.g. (8192,577) is done by sampling only; the
  multi-component common-π step (pair-level π_q vs one π for
  all q) remains the precise gap of the direct route; PC in
  general; nothing here is a Lean theorem.
