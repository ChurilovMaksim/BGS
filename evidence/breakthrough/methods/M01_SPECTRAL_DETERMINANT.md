# M01 — Спектральные детерминанты и динамические дзета-функции

**Статус.** Гипотеза о методе, а не теорема. Ничего из этого файла
не является доказательством BGS, не формализовано в Lean и не
вносится в main. Цель файла — честно ответить на один вопрос:
даёт ли язык детерминантов/дзета-функций обход времени Гейзенберга,
или только переупаковывает ту же трудность в другую форму.

## Вердикт в одном абзаце

В общем случае — **нет, обхода нет**. Спектральный детерминант
квантового отображения — это, по существу, его характеристический
многочлен, а его коэффициенты эквивалентны следам степеней
пропагатора вплоть до размерности Гильбертова пространства, то есть
вплоть до времени Гейзенберга. Переход к дзета-функции не уменьшает
объём информации, который нужно контролировать: он меняет базис
(орбиты вместо следов) и даёт надежду на сокращения в разложении
по псевдоорбитам, но эти сокращения сами нуждаются в доказательстве
с точностью, много лучшей, чем среднее расстояние между уровнями.
Метод становится реальным только в специальном случае, когда
дзета-функция рациональна или следовая формула точна — а тогда
трудность уже перемещена в арифметику орбит (равномерное
распределение действий и фаз), а не исчезла. Для замороженного
отображения это означает: M01 не закрывает ни hEquidist, ни
kickMatInf, ни hSep — он переформулирует их как задачу
о распределении орбитальных действий.

## 1. Три разных объекта, которые нельзя путать

Это самая частая ошибка в разговорах о «дзета-подходе», поэтому
фиксируем различение сразу.

### 1.1. Классический динамический детерминант (резонансы Рюэля)

Для классического отображения `T` на фазовом пространстве
рассматривается оператор переноса (Рюэля–Перрона–Фробениуса),
действующий на плотностях. Его динамический детерминант —
это детерминант Фредгольма этого оператора на подходящих
анизотропных банаховых пространствах; его нули — это обратные
величины собственных значений оператора переноса, то есть
резонансы Рюэля–Полликотта, описывающие скорость перемешивания
и затухания классических корреляций.

**Что это даёт:** классическую динамику, распад корреляций,
скорость перемешивания.

**Чего это не даёт:** квантовые собственные фазы. Резонанс
Рюэля — не собственное значение квантового пропагатора.
Подмена одного другим — категориальная ошибка, и любой
«вывод BGS из дзета-функции», который её совершает, ложен.

### 1.2. Дзета-функция Рюэля (классическая)

Схематически, для отображения:

```
ζ_R(z) = ∏_{p примитивная периодическая орбита} (1 − z^{n_p} · w_p)^{-1},
```

где `n_p` — период орбиты, а `w_p` — вес, построенный из
неустойчивого якобиана вдоль орбиты (точная форма веса зависит
от выбранного оператора переноса: для разных весов получаются
разные дзета-функции, связанные отношениями детерминантов).
Для гладких аносовских систем эта функция имеет мероморфное
продолжение; это глубокий, но классический результат
(см. источники ниже). Он ничего не говорит о статистике
квантовых уровней.

### 1.3. Квантовый спектральный детерминант (Гутцвиллер–Ворос)

Для гамильтоновой системы спектральный детерминант формально
`Δ(E) = det(E − Ĥ) = ∏_n (E − E_n)`, а след функции Грина —
его логарифмическая производная. Полуклассическое приближение
к нему — произведение Гутцвиллера–Вороса по примитивным
периодическим орбитам:

```
Δ_GV(E) ≈ ∏_p (1 − t_p),   t_p ≈ exp(iS_p/ħ − iν_pπ/2) / √|det(M_p − I)|,
```

где `S_p` — действие орбиты, `M_p` — её матрица монодромии,
`ν_p` — индекс Маслова. Обобщение этой конструкции за пределы
полуклассики (с систематическими поправками по ħ, орбита за
орбитой) существует, но это всё ещё разложение, а не точное
равенство для generic-системы. Знак `≈` здесь — вся проблема:
для микроскопической статистики нужна точность, много лучшая,
чем расстояние между соседними уровнями, а полуклассическое
приближение такой точности в общем случае не даёт.

## 2. Точный аналог для отображений на торе

Пусть `U` — унитарный пропагатор квантового отображения,
действующий в гильбертовом пространстве размерности `𝒩`
(этот символ мы используем для размерности, чтобы не путать
её с параметрами `m`, `N` из документов проекта; при
инстанцировании для замороженного отображения `𝒩` нужно
отождествить с размерностью из проекта явно — это отдельный
шаг, здесь он не предполагается доказанным).

Собственные значения: `λ_j = e^{iθ_j}`, `j = 1, …, 𝒩`,
`θ_j ∈ [0, 2π)`. Спектральный детерминант отображения — это
его характеристический многочлен в переменной `z`:

```
Δ(z) = det(I − zU) = ∏_{j=1}^{𝒩} (1 − z λ_j),   нули: z_j = e^{−iθ_j}.
```

Степенные следы:

```
a_n = Tr(U^n) = Σ_j λ_j^n = Σ_j e^{inθ_j},   n ≥ 1.
```

Коэффициенты `Δ(z) = Σ_{k=0}^{𝒩} (−1)^k σ_k z^k`
(где `σ_k` — элементарные симметрические функции от `λ_j`)
связаны со следами тождествами Ньютона:

```
k·σ_k = Σ_{j=1}^{k} (−1)^{j−1} σ_{k−j} · a_j,   σ_0 = 1.
```

Следствия, которые и составляют «отсутствие бесплатного обеда»:

1. **Полный спектр эквивалентен полным следам до `𝒩`.**
   Зная все `a_1, …, a_𝒩`, мы восстанавливаем `Δ`, а значит
   и все фазы `θ_j`. Обратно, зная все фазы, мы знаем все `a_n`.
   Никакой информации не создаётся и не уничтожается при
   переходе «следы ↔ детерминант ↔ дзета»: это смена
   представления одних и тех же `𝒩` комплексных данных.

2. **Унитарность лишь примерно вдвое уменьшает данные.**
   Симметрия характеристического многочлена унитарной матрицы
   связывает коэффициенты `σ_k` и `σ_{𝒩−k}` (с точностью
   до фазы `det U`), так что независимых вещественных
   параметров остаётся порядка `𝒩` (сами фазы), а не порядка
   `log 𝒩`. Симметрия не превращает задачу порядка `𝒩`
   в задачу порядка `log 𝒩`.

3. **Форм-фактор — это та же информация, в квадрате.**
   Дискретный форм-фактор `K(n) = |a_n|² / 𝒩` при `n = 1, 2, …`
   — это фурье-образ парной корреляции фаз. Для ансамбля CUE
   (случайные унитарные матрицы) среднее значение равно
   `min(n, 𝒩)/𝒩`: линейный рост («рампа») до `n = 𝒩`
   и плато после. Микроскопическая статистика (расстояния
   между соседними уровнями, парная корреляция на масштабе
   одного среднего расстояния `2π/𝒩`) требует контроля
   `K(n)` и, эквивалентно, следов `a_n` на всём интервале
   вплоть до `n ~ 𝒩` — времени Гейзенберга `T_H ~ 𝒩` шагов.
   Короткие времена `n ≪ 𝒩` дают только грубую, макроскопическую
   информацию о спектре.

## 3. Почему время Гейзенберга возвращается

Полуклассическая следовая формула контролирует `a_n`
приблизительно до времени Эренфеста

```
T_E ~ log 𝒩 / λ_Lyap,
```

где `λ_Lyap` — показатель Ляпунова: за это время волновой
пакет расплывается до размера всего фазового пространства,
и полуклассическое приближение по отдельным орбитам теряет
контроль. Числовой пример для кошачьего отображения
`A = [[2,1],[1,1]]` (показатель `log((3+√5)/2) ≈ 0.962`):
при `𝒩 = 64` имеем `T_E ≈ 4.3` шага, а `T_H ≈ 64` шагов —
разрыв в 15 раз. Тождества Ньютона показывают, что коэффициенты
`σ_k` при `k ≲ T_E` ещё могут быть под контролем, а при
`k ~ 𝒩/2` — нет: они зависят от всех `a_j` с `j ≤ k`,
включая длинные времена, где орбитальная сумма не обоснована.

**Надежда на разложение по циклам (cycle expansion).**
Произведение `∏_p (1 − t_p)` при раскрытии даёт сумму
по псевдоорбитам (формальным комбинациям примитивных орбит).
Идея Цвитановича: псевдоорбита, «затеняющая» длинную орбиту,
почти сокращается с вкладом самой этой орбиты (curvature
cancellations), поэтому обрезанное разложение может сходиться
быстрее, чем наивная сумма по орбитам. Для классических
аносовских систем с аналитичностью это — теорема о детерминанте
Фредгольма. Для квантового детерминанта это — эвристика:
нужно не просто «сходимость», а количественная оценка остатка.

**Количественный критерий, который решает всё.**
Пусть `θ̃_j` — фазы, полученные из обрезанного
детерминанта/дзета-функции, а `θ_j` — точные. Для
микроскопической статистики необходимо

```
max_j |θ̃_j − θ_j| ≪ 2π/𝒩      (много меньше среднего расстояния),
```

то есть при `𝒩 = 64` ошибка должна быть много меньше `0.1`
радиана, а при `𝒩 = 1024` — много меньше `0.006`.
Ошибка порядка `1/𝒩` уже сравнима с расстоянием и размывает
статистику соседей; ошибка порядка `1` делает результат
бесполезным для BGS, даже если он хорош для грубой плотности
состояний. Никакая известная общая оценка для обрезанного
детерминанта Гутцвиллера–Вороса такой точности не даёт.
Это и есть тест, который убивает метод в общем виде
(см. §6).

## 4. Специальные случаи, где метод действительно работает — и почему они не дают generic-BGS

### 4.1. Конечный тор: рациональная дзета (точный контроль, нулевая квантовая механика)

Дискретное кошачье отображение `T_𝒩` на конечном торе
`(ℤ/𝒩ℤ)²` — это перестановка `𝒩²` точек. Её оператор
переноса — матрица перестановки, и её детерминант
вычисляется точно через разложение на орбиты:

```
det(I − zP_𝒩) = ∏_{O орбита T_𝒩} (1 − z^{|O|}).
```

Это точная, проверяемая формула (см. простейший случай в §5),
но она описывает классическую перестановку, а не квантовый
пропагатор размерности `𝒩`. Она полезна как контроль
правильности языка, а не как доказательство квантовой
статистики.

### 4.2. Дзета-функция Сельберга (точная, но не универсальная)

Для поверхностей постоянной отрицательной кривизны
дзета-функция Сельберга — целая функция, чьи нули дают
спектр лапласиана, а следовая формула Сельберга точна.
И тем не менее точная дзета-функция сама по себе не даёт
RMT-статистики: универсальность требует статистической
информации о длинах замкнутых геодезических и их корреляциях,
которой произведение по орбитам не содержит бесплатно.
Точность ≠ универсальность. Этот пример — прямое
предупреждение против лозунга «возьмём точную дзета —
получим BGS».

### 4.3. Квантовое кошачье отображение: точная следовая формула, но арифметика против generic-статистики

Для квантового cat map известна точная (в смысле
Кейтинга) форма следовой формулы: `Tr(U_𝒩^k · Op_𝒩)` выражается
через сумму по неподвижным точкам `Fix(S^k)` классического
отображения с явными фазами и гауссовыми суммами.
В этом специальном случае детерминант действительно
собирается из точных следов — но тогда дзета-функция
не является обходом: она лишь bookkeeping для уже
имеющихся точных следов до `k ~ 𝒩`. Более того, именно
арифметика cat map (квантовый период `P_𝒩`, erratic
зависящий от `𝒩`, большие вырождения) делает его спектр
не-generic: без десимметризации и без выбора подпоследовательностей
`𝒩` статистика не является RMT. То есть даже там, где
метод работает полностью, он работает против наивной BGS,
а не за неё: он точно показывает, почему этот пример —
исключение.

**Вывод для замороженного отображения.** Если у замороженного
отображения следовая формула окажется точной (аналог §4.3),
то M01 сводится к уже открытым задачам проекта: равномерному
распределению фаз неподвижных точек / орбитальных действий
(родственно hEquidistUnits) и идентификации квантового
пропагатора (родственно kickMatInf). Если же следовая формула
только полуклассическая, то M01 добавляет к ней лишь
переупаковку и недоказанные сокращения псевдоорбит.
В обоих случаях центр тяжести — не детерминант, а
равномерное распределение.

## 5. Простейший проверяемый случай

### 5.1. Классический контроль (обязательно проходит, иначе неверен сам язык)

Возьмите `A = [[2,1],[1,1]]`, `𝒩 = 5`. Отображение
`T_5(x) = Ax mod 5` на 25 точках `(ℤ/5ℤ)²`.

1. Перечислите все орбиты `T_5` прямым перебором (25 точек —
   задача на секунды).
2. Составьте многочлен `∏_O (1 − z^{|O|})`.
3. Независимо постройте матрицу перестановки `P_5` размера
   `25×25` и вычислите `det(I − zP_5)` (например, через
   характеристический многочлен).
4. Сравните коэффициенты: они должны совпасть точно
   (целочисленно).

Если этот тест не проходит — ошибка в определении
дзета-функции/детерминанта, а не в физике. Если проходит —
язык проверен, но о квантовой статистике не доказано ничего.

### 5.2. Квантовый протокол (то, что решает судьбу метода)

Возьмите квантовое отображение с явно заданной унитарной
матрицей `U_𝒩` и известным точным спектром из диагонализации
(для первого прогона достаточно `𝒩 = 32` и `𝒩 = 64`;
конкретный выбор отображения — например, квантовый пекарь
или возмущённый cat map — фиксируется в протоколе
эксперимента до запуска, а не подбирается после).
Затем:

1. Вычислите точные фазы `θ_j` диагонализацией.
2. Постройте обрезанный детерминант Гутцвиллера–Вороса,
   включив только примитивные орбиты периода
   `≤ L`, где `L` — порядка времени Эренфеста
   (`L ≈ log 𝒩 / λ_Lyap`, для `𝒩 = 64` это `L ≈ 4–6`).
3. Найдите нули обрезанного детерминанта `θ̃_j`.
4. Измерьте `δ = max_j |θ̃_j − θ_j|` (после оптимального
   сопоставления фаз) и сравните с `2π/𝒩`.

## 6. Тест, который убивает подход (M01-KILL)

**Критерий провала.** Если при `𝒩 = 64` (и повторно
при `𝒩 = 128` или `256`) выполняется

```
δ ≳ 2π/𝒩        (ошибка сравнима со средним расстоянием
                 или больше),
```

то обрезанный спектральный детерминант **не даёт**
микроскопической статистики, и M01 в этой форме
отклоняется как метод доказательства BGS. Он может
остаться как метод для макроскопической плотности
состояний и коротких времён, но не для соседних
расстояний, парной корреляции и форм-фактора на
масштабе `τ ~ 1`.

**Критерий выживания (необходимый, не достаточный).**
Если `δ ≪ 2π/𝒩` устойчиво при росте `𝒩` и при
нескольких отображениях (а не при одном подогнанном),
метод переходит в фазу Б: нужно доказать оценку
остатка псевдоорбитального разложения с явной
зависимостью от `𝒩`, а не только продемонстрировать
её численно. Численный проход теста — не доказательство;
численный провал — окончательное отклонение обрезанной
формы метода.

**Дерево решений.**

- Провал на `𝒩 = 64` → M01 закрыт как путь к микроскопике;
  ресурсы переводятся на другие методы (M02–M10) и на
  прямую работу с равномерным распределением.
- Проход на `𝒩 = 64`, провал на `𝒩 = 256` → метод
  работает только в пределе малых размерностей; для BGS
  (предел `𝒩 → ∞`) он не годится.
- Проход на всех доступных `𝒩` → формулируется точная
  лемма об остатке, которую нужно доказать; до её
  доказательства статус остаётся «численно выживший
  кандидат», а не теорема.

**Дополнительный убийственный тест (арифметический).**
Если для замороженного отображения точная следовая
формула существует, но её фазы концентрируются
(например, из-за квантового периода или вырождений
типа cat map), то даже точный детерминант даёт
не-RMT статистику. В этом случае M01 не просто
не доказывает BGS — он доказывает, что для этого
класса нужна десимметризация или сужение класса
систем, и это тоже результат: он уточняет постановку,
а не подтверждает её.

## 7. Что нужно, чтобы возродить метод

Список лемм, каждая из которых в настоящее время открыта
для generic-замороженного отображения (порядок — по
логической зависимости, а не по лёгкости):

1. **Точная или количественно контролируемая следовая
   формула** для `Tr(U^k)` при всех `k ≤ 𝒩`, а не только
   при `k ≲ log 𝒩`, с явной оценкой остатка.
2. **Равномерное распределение орбитальных действий**
   по модулю `2π`: фазы `e^{iS_p/ħ}` для орбит периода
   до `𝒩` должны вести себя как независимые случайные
   фазы в нужных корреляциях (это и есть аналитическое
   ядро, родственное hEquidistUnits).
3. **Контроль псевдоорбитального остатка**: сумма
   по псевдоорбитам длины `> L` должна быть `≪ 1/𝒩`
   в смысле сдвига нулей детерминанта, а не только
   «мала» в какой-то слабой норме.
4. **Идентификация пропагатора**: квантовый объект,
   чей детерминант считается, должен быть доказанно
   тем же объектом, что и в проекте (родственно
   kickMatInf); иначе детерминант доказывает статистику
   другой модели.
5. **Десимметризация**: явное описание симметрий,
   которые нужно снять, чтобы не получить ложную
   статистику из-за вырождений.

Без пунктов 1–3 метод остаётся эвристикой; с ними —
он уже не нужен как обход, потому что пункты 1–2
сами составляют сердце BGS.

## 8. Связь с другими методами программы

- M01 не конкурирует с прямым анализом форм-фактора,
  а эквивалентен ему через тождества Ньютона: прогресс
  в одном языке автоматически переводится в другой.
- Классическая часть M01 (резонансы Рюэля) полезна
  для скорости перемешивания и для контроля
  коротких времён, но не должна цитироваться как
  аргумент в пользу квантовой статистики.
- Если в ходе фазы А другой метод даст точную следовую
  формулу, M01 следует пересмотреть первым: именно
  тогда детерминант становится удобным языком для
  записи уже доказанных следов.

## Источники (сверено поиском; вторичные места помечены)

- Vattay, «Periodic orbit quantization beyond semiclassics»:
  обобщённый продукт типа Сельберга для спектрального
  детерминанта и его связь с дзета-функциями Рюэля.
  https://arxiv.org/pdf/chao-dyn/9509015
- Liverani, «Fredholm determinants, Anosov maps and Ruelle
  resonances»: динамический детерминант как детерминант
  Фредгольма оператора переноса для аносовских отображений.
  https://ia600200.us.archive.org/2/items/arxiv-math0505049/math0505049.pdf
- Dyatlov–Zworski, «Dynamical zeta functions for Anosov flows
  via microlocal analysis»: мероморфное продолжение дзета-функции
  Рюэля для аносовских потоков.
  http://math.berkeley.edu/~zworski/zeta.pdf
- Nonnenmacher–Schwartz, слайды о квантовом cat map:
  точная следовая формула (Кейтинг), квантовый период
  и его erratic-зависимость от `𝒩`, связь с QUE.
  http://www.mi.uni-koeln.de/geometrische_analysis/QCONF_2023/Nonnenmacher_Cologne2023.pdf
- Nonnenmacher, «Some open questions in wave chaos»:
  время Эренфеста против времени Гейзенберга и проблема
  парной корреляции.
  https://arxiv.org/pdf/0805.4137

**Не сверено напрямую в рамках этой ветки:** полные тексты
Гутцвиллера–Вороса в оригинале, монография Цвитановича
о разложении по циклам, оригинальные работы Рюэля 1976 года.
Формулы в §§1–2 — стандартные определения, а не цитаты
из непроверенных источников; при переносе в Lean каждое
тождество (в частности, тождества Ньютона) должно быть
доказано заново, а не заимствовано из этого обзора.
