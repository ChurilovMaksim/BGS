## 1. Точные объекты

Пусть `m ≥ 3` — целое, `C` — циклический сдвиг координат,
`H_m = 6I − C − Cᵀ`, то есть

```
(H y)_i = 6 y_i − y_{i+1} − y_{i−1}   (индексы mod m).
```

Пусть `D_m = det H_m` (точное целое, см. таблицу §2) и

```
Fix_m = { y ∈ (ℤ/D_m)^m : H_m y = 0 }.
```

Группа `Γ = Dih_m` (диэдральная, порядка `2m`) действует перестановкой
координат: вращения `r^i : j ↦ j+i` и отражения `sr^i : j ↦ i−j`
(в обозначениях replay: `gammaPerm`, действие предкомпозицией).
Отображение «мультисет»:

```
μ : Fix_m → мультисеты,   μ(y) = sorted(y_0, …, y_{m−1}),
```

то есть `μ(y)` — это отсортированный кортеж координат, он же
мультисет `{e(ξ_j)}` при `ξ_j = y_j / D_m`, поскольку
`exp(2πi·/D_m)` инъективен на `[0, D_m)`.

Волокно над мультисетом `M` — это `μ⁻¹(M)`. Тривиальное включение
всегда верно: `Γ·y ⊆ μ⁻¹(μ(y))`, потому что `Γ` лишь переставляет
координаты. Нетривиально ровно обратное включение.

**Это не доказательство даже для m ≤ 7 в смысле Lean** (ядро Lean
такой перебор не потянет: см. §6) и тем более не говорит ничего о
`m ≥ 8` — а для `m = 8` перебор говорит противоположное O1.

### 2.3. Контрпример при m = 8 (явный, проверяемый за секунды)

`D_8 = 1331712`. Вектор (все координаты различны, стабилизатор
в `S_8` тривиален):

```
y  = (0, 1276224, 998784, 721344, 665856, 610368, 332928, 55488),
y′ = (0, 721344, 332928, 1276224, 665856, 55488, 998784, 610368).
```

Оба вектора лежат в `Fix_8` (`H y ≡ H y′ ≡ 0 mod 1331712`,
проверяется прямым вычислением), оба имеют один и тот же
отсортированный мультисет

```
μ = (0, 55488, 332928, 610368, 665856, 721344, 998784, 1276224),
```

но `y′ ∉ Γ·y`: `|Γ·y| = 16`, а волокно имеет размер 32.
Перестановка, переводящая `y` в `y′` в обозначениях
`y′_j = y_{p[j]}`:

```
p = (0, 3, 6, 1, 4, 7, 2, 5),   то есть p[j] = 3j mod 8.
```

Это умножение индексов на 3 mod 8 — элемент мультипликативной
группы `(ℤ/8)^×`, а не диэдральной группы (диэдральные
перестановки — это `j ↦ j+i` и `j ↦ i−j`, то есть множители
`±1`). Механизм: `y` — торсионный подъём,
`y = 55488 · z` с `z = (0, 23, 18, 13, 12, 11, 6, 1)` и
`H z ≡ 0 (mod 24)` (так как `55488 · 24 = D_8`); в малом модуле
24 ядро слабее, и множитель 3 его сохраняет, а подъём переносит
это в `mod D_8`. Два других первых плохих волокна устроены
точно так же, с тем же `p` и подъёмами
`z = (0, 7, 2, 5, 4, 3, 6, 1) (mod 8)` и
`z = (0, 19, 18, 17, 12, 7, 6, 5) (mod 24)`.
Полный список примеров — в файле
`M08_BAD_M8.json` рядом с этим документом (39 плохих волокон
всего, сохранены первые 3 примера с явными `y, y′, p`).

Отсюда же — исправленный кандидат (§3.4): для этого волокна
аффинная орбита (см. ниже) имеет размер 32 и совпадает
с волокном.

### 2.2. SNF-структура ядра (вычисление, m = 3..8)

Точная целочисленная SNF матрицы `H_m` (SymPy, `smith_normal_form`,
здесь — вычисление, а не теорема Lean):

| m | SNF H_m (по модулю знака) | D_m | a_m | b_m |
|---|---------------------------|-----|-----|-----|
| 3 | 1, 7, 28 | 196 | 7 | 28 |
| 4 | 1, 1, 12, 96 | 1152 | 12 | 96 |
| 5 | 1, 1, 1, 41, 164 | 6724 | 41 | 164 |
| 6 | 1, 1, 1, 1, 70, 560 | 39200 | 70 | 560 |
| 7 | 1, 1, 1, 1, 1, 239, 956 | 228484 | 239 | 956 |
| 8 | 1, 1, 1, 1, 1, 1, 408, 3264 | 1331712 | 408 | 3264 |

Закономерность, видимая для `m ≤ 8` (как гипотеза о всех `m`,
не как доказанный факт): все инварианты, кроме двух последних,
равны 1, а последние два — `(a_m, b_m)` с `b_m = 4 a_m` при нечётном
`m` и `b_m = 8 a_m` при чётном `m`. Отсюда, *если* SNF имеет такой вид,
следует структура ядра: при замене базиса по SNF уравнение
`H_m y ≡ 0 (mod D_m)` покомпонентно даёт `d_i z_i ≡ 0 (mod D_m)`,
а число решений равно `gcd(d_i, D_m)`; для `d_i = 1` это 1, для
`a_m` и `b_m` — сами `a_m` и `b_m` (оба делят `D_m = a_m b_m`). То есть

```
Fix_m ≅ ℤ/a_m × ℤ/b_m   (при SNF-виде выше),
D_m = a_m b_m = 4 a_m² (m нечётно), 8 a_m² (m чётно).
```

Это согласуется с известным из моста 154 фактом `D_eff = A_m²`
при `A_m = 2 a_m`. Главное следствие для метода: **ядро
двухпараметрическое**. Вектор из `Fix_m` определяется двумя
параметрами (в SNF-базисе — парой `(s, t)`), а его `m` координат —
это `m` линейных форм `L_j(s, t)`. Вопрос о волокнах становится
вопросом линейной алгебры, а не комбинаторики всех перестановок:
определяет ли мультисет значений `m` линейных форм пару `(s, t)`
с точностью до действия `Γ` на пространстве параметров?

Факторизация `D_m` подтверждает ту же картину (точные разложения):

```
m=8:  2^9 · 3² · 17²;   m=9:  2² · 7² · 199²;   m=12: 2^7 · 3^4 · 5² · 7² · 11².
```

Нечётные простые входят в `D_m` в чётных степенях — это тень
того же спаривания инвариантов. Доказательство SNF-закономерности
для всех `m` — отдельная задача (§5, пункт 1), а не следствие
таблицы для `m ≤ 8`.

## 3. Кандидат O: стратификация волокон

### 3.1. Формулировка (гипотеза)

**Кандидат O1 (жёсткость волокон).** Для всякого `m ≥ 3` и всякого
`ξ ∈ Fix_m`

```
μ⁻¹(μ(ξ)) = Γ·ξ.
```

**Кандидат O2 (стратификация и усреднение по орбитам).** Если O1
верно, то фактор `Fix_m / Γ` отождествляется с множеством
мультисетов, встречающихся как `μ(ξ)`, и для всякого
`Γ`-инвариантного подмножества `X ⊆ Fix_m` и всякой
`Γ`-инвариантной функции `F : Fix_m → ℂ`

```
(1/|X|) ∑_{ξ∈X} F(ξ)
  = (1/|X|) ∑_{M : волокно(M) ⊆ X} |волокно(M)| · F(M),
```

где `F(M)` — общее значение `F` на волокне. В частности, для
`Bsym` (определение из `LineDParity`: среднее по `α` размера
орбиты, `(∑_{x∈α} |Γx|)/|α|`), при `α = supp φ̂`, из O1 следует

```
Bsym = (1/|supp|) ∑_M |волокно(M)|²,
```

то есть `Bsym` вычисляется только по размерам мультисетных
волокон, без действия группы. Проверка формулы: сумма по `x`
группируется по волокнам; волокно размера `k` даёт `k` слагаемых,
каждое равное `k`.

**Кандидат O′ (ограниченная версия, достаточная для 152).**
O1 требуется только для `ξ` из носителя `φ̂_s` (именно по носителю
идёт парная сумма в strong-kick пределе), либо только для `m`
из указанного множества (например, `m ≤ 7`, `m` простое).
Если универсальный O1 падёт, а O′ устоит, метод для приложения
152 всё равно закрыт, а как общая теорема о `Fix_m` — нет.
Эти два утверждения нельзя смешивать: в отчёте о любом
контрпримере обязательно указывать, лежит ли плохое волокно
в носителе или нет (§6, уровень 1).

### 3.4. Исправленный кандидат O* (после убийства O1) — гипотеза

Пусть `Aff_m` — аффинная группа индексов,
`j ↦ a j + b` с `a ∈ (ℤ/m)^×`, `b ∈ ℤ/m` (в обозначениях
`y′_j = y_{p[j]}` это перестановки `p[j] = a j + b mod m`).
Диэдральная группа `Γ` — это подгруппа `a = ±1`.
**Кандидат O*:** волокно `μ⁻¹(μ(ξ))` равно `Aff_m`-орбите `ξ`,
а не `Γ`-орбите. Для первого плохого волокна при `m = 8`
это проверено точно: аффинная орбита `y` имеет размер 32,
все её 32 вектора лежат в ядре, и она содержит диэдральную
орбиту размера 16; поскольку волокно тоже имеет размер 32,
волокно = аффинная орбита для этого волокна. O* — гипотеза:
она не проверена ни для всех волокон при `m = 8` (аффинная
орбита может быть строго меньше волокна и там), ни для
`m ≥ 9`, и та же CRT-склейка (§5.5) может убить и её —
на этот раз склейкой разных множителей `a_p` в разных
примарных компонентах. Если O* верно, то для приложения 152
разделение классов даёт не `Γ`-орбиту, а аффинную орбиту,
и `Bsym` надо пересчитывать через аффинные орбиты —
это изменение содержания, а не косметика, и оно требует
пересмотра места `hSep` в цепочке, а не молчаливой замены
группы.

### 3.2. Что O заменяет, а что — нет

Цепочка в strong-kick пределе (152) такова:

```
S(ξ) = S(ξ′) для всех k ∈ 𝒦, 𝒦 ⊇ {1..m}
  ⟹ степенные суммы мультисета {e(ξ_j)} равны
     (modeSum — это ровно p_k: e(k ξ_j) = e(ξ_j)^k)
  ⟹ мультисеты равны (Ньютон)
  ⟹ ξ′ ∈ Γξ   ← ровно здесь нужен O1 (это и есть hSep)
  ⟹ пара (ξ, ξ′) — на орбите, а не вне её.
```

Внеорбитальные пары убиваются в пределе `η → ∞` затуханием
фактора `ω` (гауссова / J0-ансамбля). Поэтому точная замена такова:

| Что делает O1 | Что O1 НЕ делает |
|---|---|
| Заменяет гипотезу `hSep` конечным комбинаторным утверждением о `Fix_m` | Не заменяет затухание `ω` и не убирает ансамбль коэффициентов: без `ω → 0` внеорбитальные пары не исчезают |
| Даёт полную систему инвариантов действия `Γ` на `Fix_m` (мультисеты) | Не даёт RMT-статистики: предел равен `Bsym` — рациональной величине подсчёта орбит, а не GOE-расстоянию между уровнями |
| Позволяет вычислять средние `Γ`-инвариантных наблюдаемых по волокнам | Не заменяет `N`-усреднение / `ν`-усреднение (175) и не заменяет `θ`-усреднение (149): это другие средние, по другим переменным |
| Сводит разделение классов к конечной линейной алгебре | Не закрывает `m ~ N` режим, следовую формулу в целом и микроскопическую BGS |

Ошибка, которую надо избегать explicitly: сказать «усреднение по
ансамблю заменено усреднением по орбите». Нет. Заменена только
*гипотеза разделения* — ансамблевое затухание осталось. Кто
утверждает большее, тот завышает следствие, и adversarial-рецензия
должна это ловить.

### 3.3. Почему это могло бы быть тематикообразующим

Если O1 верно в общем виде, то это конечный точный аналог
классической ситуации «орбитальное пространство = инварианты»:
на всём `(ℤ/D_m)^m` мультисет, конечно, не определяет
диэдральную орбиту (перестановок гораздо больше, чем диэдральных),
а на ядре `H_m` — определяет. Жёсткость создаётся именно
уравнением ядра, а не группой. Тот же вопрос после этого естественно
ставить для других циркулянтных ядер, для периодических орбит
cat-отображений и для квантовых графов — но это вопросы, а не
переносы: ни один из них здесь не утверждается.

## 4. Простейший случай: m = 3 — тривиален, m = 4 — первый настоящий

**m = 3 — не доказательство и не тест.** Диэдральная группа
треугольника — это уже вся симметрическая группа: `|Dih_3| = 6 =
|S_3|`. Поэтому для `m = 3` равенство «волокно = орбита» верно
по определению группы, и ссылаться на `m = 3` как на
подтверждение O1 нельзя. Это ловушка для отчётности: строка
«m=3: PASS» в таблице §2.1 содержательно пуста.

**m = 4 — первый нетривиальный случай.** Здесь `|Γ| = 8`,
`|S_4| = 24`: утверждение уже отрезает 16 перестановок.
Конкретный проверяемый пример (проверен прямым перебором всех
перестановок; `D_4 = 1152`):

```
y = (0, 1056, 576, 96) ∈ Fix_4,
μ(y) = (0, 96, 576, 1056),   |Γ·y| = 8.
```

Проверка: среди всех 24 перестановок координат ровно 8
удовлетворяют `6 y_i − y_{i+1} − y_{i−1} ≡ 0 (mod 1152)`,
и эти 8 — ровно диэдральная орбита `y`. Координаты здесь
попарно различны, так что стабилизатор в `S_4` тривиален и
никаких оговорок о повторениях не нужно.

Аналогичный пример для `m = 5` (`D_5 = 6724`, тоже проверен:
среди 120 перестановок в ядре ровно 10 диэдральных):

```
y = (0, 6560, 5740, 984, 164) ∈ Fix_5,
μ(y) = (0, 164, 984, 5740, 6560),   |Γ·y| = 10.
```

Эти два примера — минимальный ручной (машинный за секунды)
свидетель того, что O1 нетривиален и всё же выполняется
хотя бы где-то за пределами тривиального `m = 3`. Они не
доказывают O1 ни для `m = 4` в целом (нужны все 1152 вектора —
это и даёт replay), ни тем более для общего `m`.

## 5. Что нужно доказать для общего m

Доказательство O1 распадается на пять подзадач. Ни одна из них
здесь не закрыта; порядок — от самой структурной к самой
комбинаторной.

**1. SNF для всех m.** Доказать, что инварианты Смита `H_m` —
`(1, …, 1, a_m, b_m)` с `b_m / a_m ∈ {4, 8}` (по чётности `m`),
и найти замкнутую форму `a_m` (последовательность
`7, 12, 41, 70, 239, 408, …` удовлетворяет рекуррентности
`x_{n+1} = 6 x_n − x_{n−1}` парами и явно связана с единицей
`α = 3 + 2√2`). Естественный путь: `H_m` — циркулянт с
полиномом `6 − z − z⁻¹`, то есть (с точностью до множителя `z⁻¹`)
`−(z − α)(z − α⁻¹)`; детерминантные делители должны читаться
из НОД этого полинома с `z^m − 1` и его циклотомических
сомножителей. Без этого пункта параметризация §2.2 остаётся
наблюдением для `m ≤ 8`.

**2. Параметризация линейными формами.** По SNF получить явные
линейные формы `L_0, …, L_{m−1}` на `ℤ/a_m × ℤ/b_m`, такие что
`ξ ↦ (L_j(s, t))_j` — биекция `Fix_m ≅ ℤ/a_m × ℤ/b_m`, и явное
действие `Γ` на параметрах `(s, t)` (матрицы 2×2, индуцированные
перестановкой координат). Тогда O1 эквивалентно утверждению:
отображение `(s, t) ↦ {L_j(s, t)}` инъективно с точностью
до этого действия. Это переформулировка, а не доказательство,
но она переводит задачу из комбинаторики перестановок в
конечную линейную алгебру, где есть шанс на явные инварианты.

**3. Рекуррентная / α-параметризация и её пределы.** Вектор ядра
удовлетворяет рекуррентности `y_{j+1} = 6 y_j − y_{j−1} (mod D_m)`,
то есть формально `y_j = u α^j + v α^{−j}` с `α + α^{−1} = 6`.
Диэдральное действие на этой записи прозрачно: сдвиг `j ↦ j+i`
умножает `u` на `α^i`, а `v` на `α^{−i}`; отражение меняет `u`
и `v` местами. Вопрос O1 становится вопросом: определяют ли
значения `u α^j + v α^{−j}` (как мультисет) пару `(u, v)` с
точностью до этих двух операций? Осторожно: формула с `α`
требует расширения кольца (`ℤ[√2]`) и деления на `α − α^{−1} =
4√2`, которое над `ℤ/D_m` при составном `D_m` не всегда
возможно; в примарных компонентах, где `2` необратим, и там,
где `α` имеет малый порядок, формула вырождается. Поэтому
этот путь — эвристика и источник контрпримеров, а не готовое
доказательство.

**4. Стратификация вырожденных случаев.** Доказательство обязано
отдельно обработать векторы, где наивные аргументы ломаются:
постоянные векторы (орбита размера 1; их ровно 4 при `m ≤ 7`),
чередующиеся векторы (период 2 при чётном `m`), периодические
векторы с периодом `d | m` (их мультисет — повторение
`d`-паттерна) и векторы с повторениями координат (нетривиальный
стабилизатор в `S_m`). Для периодических векторов есть шанс на
редукцию к делителю `d`: перестановка, сохраняющая периодический
вектор как вектор, не даёт нового вектора, а перестановка,
дающая новый вектор, должна сохранять `d`-паттерн как мультисет
— но это сведение само нуждается в доказательстве, а не в
ссылке на интуицию.

**5. Склейка по китайской теореме об остатках (главное
диагностическое место).** По CRT `Fix_m` раскладывается в
произведение примарных компонент `Fix^{(p)}` по простым степеням
`q ‖ D_m`, причём вектор `mod D_m` — это независимый набор
векторов `mod q`. Перестановка `σ` даёт вектор в ядре тогда и
только тогда, когда она даёт вектор в ядре в каждой примарной
компоненте. Отсюда точный механизм возможного контрпримера:
`σ` может действовать как диэдральный элемент `g_p` в каждой
компоненте, но с *разными* `g_p` в разных компонентах — тогда
компонентно всё «в порядке», а глобально нет единого `g ∈ Γ`
с `σy = g y`. Поэтому доказательство O1 должно либо показать,
что `g_p` определяется глобальным инвариантом (например,
положением максимума координаты или SNF-параметрами, общими
для всех компонент), либо найти `σ` и компоненты, где `g_p`
несовместимы. Примарные компоненты при этом малы: например,
при `m = 8` размеры компонент — `512 · 9 · 289 = 1331712`,
то есть поиск несовместимой склейки на порядки дешевле полного
перебора (см. §6, уровень 3). Если O1 ложно, то с наибольшей
вероятностью оно ломается именно здесь — на первом составном
`m` с несколькими простыми делителями (`m = 8`, затем `m = 12`).

Дополнительно, для приложения 152, а не для O1 в целом: мост
modeSum → степенные суммы (несколько строк, `exp_nat_mul`) и
шаг Ньютона (степенные суммы `p_1..p_m` определяют мультисет)
должны быть в Lean, а не только в тестовой копии
(`bgs-test-156`, LineDNewton). Без них O1 сам по себе не даёт
`hSep`: O1 говорит о мультисетах координат, а `hSep` — о
равенстве modeSum.

## 6. Тест, который убил бы подход (протокол)

Тест строится лесенкой от дешёвого к дорогому. Достаточно одного
плохого волокна на любом уровне, чтобы убить универсальный O1;
отсутствие плохих волокон — не доказательство, а только
«кандидат выжил до следующего уровня».

**Уровень 0 — один вектор (секунды).** Для заданного `y ∈ Fix_m`
перебрать все `m!` перестановок координат, оставить те, что лежат
в ядре (`H y′ ≡ 0 mod D_m`), и проверить, что все они лежат в
`Γ·y`. Применимо при `m ≤ 10` (`10! = 3628800`). Выборка обязана
включать не только случайные векторы, но и структурированные:
периодические подъёмы с делителей `d | m`, торсионные векторы
(кратные `D_m / p`), постоянные и чередующиеся, векторы с
повторениями. Один плохой вектор — полный kill универсального O1.

**Уровень 1 — полный перебор волокна (следующий m).**
Перечислить `Fix_m` методом replay (ядро 2×2 + рекуррентность,
не фильтрация `D^m`), сгруппировать по `sorted(y)`, для каждого
волокна сравнить множество с `Γ`-орбитой первого элемента.
Отчёт обязан содержать раздельно: (а) число плохих волокон всего,
(б) число плохих волокон, пересекающих носитель `φ̂_s`
(для этого носитель надо вычислить отдельно по определению
`phihatFix` — в replay для `m ≤ 7` это не понадобилось, так как
плохих не было вовсе, но при первом же плохом волокне без
этого разделения нельзя сказать, убит ли O′). Стоимость и итог:
`m = 8`: 1331712 точек — выполнено в рамках этой задачи
(два прогона, ~175 с каждый): 85106 волокон, 39 плохих,
явный контрпример — §2.3, файл `M08_BAD_M8.json`.
`m = 9`: 7761796 точек — Python на грани, рекомендуется C++
(для универсального O1 уже не нужно: он убит; для O*
и для O′ на носителе — нужно); `m = 10`: 45239072 точек —
только выборка.

**Уровень 2 — примарная склейка (дешёвый и диагностичный).**
Для каждого простого `p | D_m` и каждой степени `q ‖ D_m`
проверить жёсткость волокон для `ker(H_m mod q)` (множества
на порядки меньше: при `m = 8` компоненты имеют размеры
512, 9, 289). Затем искать `σ ∉ Γ` и набор компонентных
векторов `y_p` с `σ y_p ∈ ker_p`, у которых индуцированные
диэдральные элементы `g_p` попарно несовместимы (при
тривиальных стабилизаторах `g_p` определяется однозначно).
Найденная несовместимая склейка собирается по CRT в глобальный
контрпример; её отсутствие при малых компонентах — сильный,
но не решающий аргумент в пользу O1.

**Уровень 3 — m = 12 и дальше (только целевой поиск).**
Полный перебор невозможен (`D_12 = 1536796800`). Остаются:
случайная выборка уровня 0, структурированные семейства
(периоды, торсия) и склейка уровня 2. Положительный результат
на этом уровне ничего не доказывает; отрицательный (один плохой
вектор) убивает универсальный O1 окончательно.

**Правило отчётности о kill.** Плохой пример публикуется полностью:
`m`, `D_m`, вектор `y`, вектор `y′` из того же волокна,
перестановка `σ` с `σy = y′`, и проверка, что `y′ ∉ Γ·y`
(то есть `σ ∉ Γ·Stab_{S_m}(y)`). Без явного `σ` заявление
«найден контрпример» не принимается. И наоборот: отчёт
«плохих волокон не найдено при `m = 8`» не должен превращаться
в «O1 верно» — это лишь выживание кандидата.

## 7. Вердикт охотника и следующие шаги

1. **Универсальный кандидат мёртв — и это результат.**
   Он пережил `m ≤ 7` (replay) и нетривиальные проверки
   `m = 4, 5`, но убит при `m = 8` ровно предсказанным
   механизмом: торсионный подъём из малого модуля плюс
   множитель 3 mod 8, не входящий в `Γ`. Двухпараметрическая
   природа (SNF) не спасла: переопределённость при `m ≥ 4`
   не исключает систематических симметрий малого модуля.
2. **Место смерти подтвердилось: m = 8** — первое
   непроверенное `m`. Дальнейшее подтверждение `m ≤ 7`
   теперь бессмысленно; следующие тесты адресованы O* и O′,
   а не O1.
3. **Порядок работ.** (а) Для 39 плохих волокон при `m = 8`
   вычислить пересечение с носителем `φ̂_8` — это решает
   судьбу O′ для приложения 152; (б) проверить O* (аффинные
   орбиты) для всех волокон при `m = 8`, затем уровень 2
   (склейка разных множителей) для `m = 9, 12`; (в) только
   если O* выживет — доказательство SNF для всех `m`
   (§5.1) как первый шаг к Lean, а не попытка `decide`
   по всем точкам (она невыполнима уже при `m = 6–7`
   по оценке из replay-отчёта: ядро должно было бы прогнать
   `D^m` кортежей, а прецедент `det H_7` уже убит по OOM).
4. **Что не делать.** Не цитировать `m = 3` как подтверждение;
   не называть replay доказательством; не переносить O1 на
   другие ядра без отдельной проверки; не смешивать O1 и O′
   в отчётах; не использовать выживание кандидата как аргумент
   для записи `hSep` как доказанного в реестре.
