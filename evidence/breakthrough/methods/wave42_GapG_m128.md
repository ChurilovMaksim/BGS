# Wave 42, task 1 — Gap G at m=128: PROVED
**Theorem.** Let $y$ be a kernel sequence mod $Q=131072$, 128-periodic, $y_{i+1}=6y_i-y_{i-1}$, minimal period $p\in\{8,16,32,64,128\}$, $\nu=(1,0)$ ($y_{i+p/2}-y_i=(Q/2)\nu_{i\bmod2}$). Then the odd sub-multiset $O=\{y_i:i\text{ odd}\}$ is never $(Q/2)$-symmetric ($\Phi y\notin F(y)$); $\nu=(0,1)$ follows by shift. Hence the Split Bit Lemma is unconditional at $m=128$.
## Shared setup
$w_k=y_{2k+1}$ satisfies the 34-recurrence mod $Q$, period $p/4$ (Lemma L, level-independent: $6\tilde y\equiv0\bmod Q\Rightarrow\tilde y\equiv0\bmod Q/2$; checked: $w$-period $=p/4$ on all $\nu=(1,0)$ points). $O$ is the $w$-cycle repeated, so $O$ symmetric $\iff$ $w$-cycle symmetric. Quarter defect $w_{k+p/8}=w_k+(Q/2)\varepsilon_k$ ($k<p/8$); $v_k=w_k\bmod(Q/2)$, $t_k$ top bit.
**Lemma Balance.** For a class $c\bmod(Q/2)$, $K_c=\{k<p/8:v_k=c\}$, $A_c=\#\{k\in K_c:\varepsilon_k=0\}$, $B_c=\sum_{k\in K_c,\varepsilon_k=0}(1-t_k)$: $w$-cycle symmetric $\iff$ $2B_c=A_c$ for all $c$ (lower-lift count is $2B_c+|K_c|-A_c$).
**Lemma $\varepsilon$-alternation.** $d_i=y_{i+p/4}-y_i$, $g_i=d_i/(Q/4)\bmod4$: $g_{\text{odd}}=2\varepsilon$, $g_{\text{even}}$ odd; recurrence mod 4 at even $i$ gives $\varepsilon_k+\varepsilon_{k-1}$ odd (cyclic, $p/8$ even), so $\varepsilon_k=\varepsilon_0\oplus(k\bmod2)$.
**Parametrisations** (exact, substitution-verified). $p=32$: $y_0=512t$, $y_1=1536t+4096s$; $p=64$: $y_0=256t$, $y_1=768t+2048s$; $p=128$: $y_0=128t$, $y_1=384t+1024s$; in each case $\nu=(1,0)\iff t,s$ odd (counts 2048/8192/32768).
## $p=8,16$
$p=8$: $O=\{w_0,w_1\}$ doubled; swapped quarter-defect gives $w_1-w_0\in\{Q/4,3Q/4\}\ne Q/2$ (checked: 64+64 points). ∎
$p=16$: $p/8=2$, $\varepsilon=(\varepsilon_0,1-\varepsilon_0)$; any class with $A_c>0$ has $A_c=1$, so $2B_c\ne A_c$. ∎
## $p=32$: (A), (B)
$u_k=w_k\bmod(Q/2)$ ($k<4$); $u_{k+2}\equiv u_k\pmod{Q/4}$ since $f_i=y_{i+4}-y_i$ has $f_{\text{odd}}\equiv0\pmod{Q/4}$ and $f_{\text{even}}\equiv Q/8\pmod{Q/4}$ (Lemma 2 instances; checked). $\delta_k=(u_{k+2}-u_k)/(Q/4)\bmod2$.
(A) $\delta_0+\delta_1=1$: $u$-recurrence mod $(Q/2)$ at $k=1,2$ gives $17u_1\equiv u_0+(Q/8)\delta_0$, $17u_0\equiv u_1+(Q/8)\delta_1\pmod{Q/4}$; combining, $9u_1\equiv512(\delta_0+\delta_1\bmod2)\pmod{1024}$. Parametrisation gives $w_1=y_3=35y_1-6y_0\equiv512t\equiv512\pmod{1024}$ ($t$ odd), so $9u_1\equiv512$, forcing $\delta_0+\delta_1$ odd.
(B) $\varepsilon_0=\delta_1$: $e_i=y_{i+4}-y_i$; recurrence mod $(Q/2)$ at $i=2$ gives $e_3\equiv Q/4-e_1$, so $\delta_1=1\iff e_1\equiv0\pmod{Q/2}$. Mod $Q$, writing $e_2=Q/8+(Q/4)a+(Q/2)a'$, $e_4=Q/8+(Q/4)b+(Q/2)b'$: $e_5=e_1+(Q/2)(b-a)$; since $d_1=y_9-y_1=e_1+e_5=(Q/2)\varepsilon_0$, $\varepsilon_0\equiv(1-\delta_1)+(b-a)\pmod2$. The $f$-argument ($f_i=(e_i/(Q/8))\bmod8$, $f_{i+1}\equiv-f_{i-1}\pmod4$ at odd $i$ from the recurrence) gives $f_4\equiv-f_2\pmod4$ with $f_2\equiv1+2a$, $f_4\equiv1+2b\pmod4$, so $a\ne b$, hence $\varepsilon_0=\delta_1$.
Finish: balance at $c=v_0$ (if $\varepsilon_0=0$) needs $v_2=v_0$, i.e. $\delta_0=0$; but $\varepsilon_0=0\Rightarrow\delta_1=0$ (B) $\Rightarrow\delta_0=1$ (A). Balance at $c=v_1$ (if $\varepsilon_0=1$) needs $v_3=v_1$, i.e. $\delta_1=0$; but $\varepsilon_0=1\Rightarrow\delta_1=1$ (B). Both fail. ∎ (Checked: (A),(B) 0 violations on 2048 points.)
## $p=64$: $\varphi$-machinery
$f_i=y_{i+8}-y_i$; $\varphi_k=f_{2k+1}/(Q/4)\bmod4$ ($k<8$), well-defined since $f_{\text{odd}}\equiv0\pmod{Q/4}$ (Lemma 2; checked). (i) $\varphi_{k+1}\equiv2\varphi_k-\varphi_{k-1}\pmod4$ ($f_{\text{odd}}$ has the 34-recurrence; $34\equiv2\bmod4$). (ii) $\varphi_k\equiv\varepsilon_k\pmod2$: both parities 2-periodic ((i) mod 2; alternation); suffices $k=0,1$, from parametrisation: $f_1\equiv16384(3t+s)\pmod{Q/2}$, $d_1\equiv32768(3t+s)\pmod Q$ give $\varphi_0\equiv\varepsilon_0\equiv(3t+s)/2\pmod2$; $f_3\equiv16384(t+s)\pmod{Q/2}$, $d_3\equiv32768(t+s)\pmod Q$ give $\varphi_1\equiv\varepsilon_1\equiv(t+s)/2\pmod2$ ($t,s$ odd). (iii) $\varphi_k+\varphi_{k+4}\equiv2\varepsilon_k\pmod4$ ($d_{2k+1}=f_{2k+1}+f_{2k+9}=(Q/2)\varepsilon_k$). $\delta_k:=(u_{k+4}-u_k)/(Q/4)\bmod2=\varphi_k\bmod2=\varepsilon_k$ ($u_{k+4}-u_k\equiv f_{2k+1}\pmod{Q/2}$). $t$-rule: $w_k=(Q/4)\alpha_k+\rho_k+(Q/2)t_k$, $w_{k+4}=w_k+(Q/4)\varphi_k\pmod Q$ gives $t_{k+4}=t_k\oplus((\alpha_k+\varphi_k)//2\bmod2)$; $\varphi_k$ even: $0\Rightarrow t$ same, $2\Rightarrow t$ flips.
Unique $\varphi=0$: $\varepsilon=0$ indices among $k<4$ are $\{0,2\}$ or $\{1,3\}$; $\varphi\in\{0,2\}$ there by (ii); if both equal, (i) at the middle index ($\varepsilon=1$, $\varphi$ odd) gives $\varphi_1\equiv\varphi_0\pmod2$, impossible. So exactly one $j^*<4$ has $\varphi=0$.
Pair analysis: pairs $(j,j+4)$, $j<4$, cover $k<8$. $\delta=1$ pairs contribute 0 (members in different classes, $\varepsilon=1$). A $\delta=0$ pair contributes $2(1-2t_j)$ if $\varphi_j=0$, $0$ if $\varphi_j=2$. Only pair $j^*$ contributes, to class $c^*=v_{j^*}$: $2B-A=\pm2\ne0$. ∎ (Checked: unique $\varphi=0$ and failing class, 0 violations, 8192 points.)
## $p=128$: $\varphi+\psi+D$
$f_i=y_{i+16}-y_i$; $\varphi_k=f_{2k+1}/(Q/4)\bmod4$ ($k<16$); (i) and (iii) as above with shift 8; (ii) from parametrisation: $f_1=49152t+16384s$, $d_1=98304t+32768s$ give $\varphi_0\equiv\varepsilon_0\pmod2$; $f_3=16384(t+s)$, $d_3=32768(t+s)$ give $\varphi_1\equiv\varepsilon_1\pmod2$ (with $t=2a+1$, $s=2b+1$: $\varphi_0=(3a+b+2)\bmod4$, $\varphi_1=(a+b+1)\bmod4$).
$\psi$-analysis: write $\varphi_k=\varepsilon_k+2\psi_k$ ($\psi_k\in\{0,1\}$) by (ii); (i) mod 4 gives $\psi_{k+1}+\psi_{k-1}$ odd (using $\varepsilon_{k\pm1}=1-\varepsilon_k$), so $\psi$ alternates on each parity class. Among $\varepsilon=0$ indices $j<8$ (four, same parity), exactly two have $\psi=0$, i.e. $\varphi=0$, and they differ by 4.
$D$-analysis: $h_k=w_{k+4}-w_k$ ($g_{2k+1}$, $g_i=y_{i+8}-y_i$); $g_{\text{odd}}\equiv0\pmod{Q/8}$ (Lemma 2 instance; checked), so $H_k:=h_k/(Q/8)\bmod4$ is defined. $H$ satisfies the same recurrence mod 4 as $\varphi$, so $D_k:=H_k-\varphi_k$ satisfies $D_{k+1}\equiv2D_k-D_{k-1}\pmod4$, i.e. $D_k=D_0+k\delta$. Also $h_k+h_{k+4}\equiv(Q/4)\varphi_k\pmod Q$ gives $H_k+H_{k+4}\equiv2\varphi_k\pmod4$; with $\varphi_{k+4}=\varphi_k$ ($\varepsilon,\psi$ periods 2,4) this gives $D_k+D_{k+4}\equiv0\pmod4$, forcing $D_0,\delta$ even. Parametrisation pins $D_0=D_1=2$: $H_0=((7t+s)/2)\bmod4=(3a+b)\bmod4$, $\varphi_0=(3a+b+2)\bmod4$; $H_1=((5t+s)/2)\bmod4=(a+b+3)\bmod4$, $\varphi_1=(a+b+1)\bmod4$. Hence $D\equiv2$, i.e. $H_k=\varphi_k+2\pmod4$ for all $k$; in particular $\varphi_k=0\Rightarrow h_k\equiv Q/4\pmod{Q/2}\Rightarrow v_{k+4}\ne v_k$.
Pair analysis: pairs $(j,j+8)$, $j<8$. The two $\varphi=0$ pairs $j^*,j^*+4$ have distinct classes ($v_{j^*+4}=v_{j^*}+Q/4\bmod Q/2$), each contributing $2B-A=\pm2\ne0$ ($t$-rule as above). ∎ (Checked: $D=2$, $H=\varphi+2$, two $\varphi=0$ pairs 4 apart in distinct classes, both failing, 0 violations on 32768 points.)
