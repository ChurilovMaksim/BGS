# Wave 33, task 3 (retry): M5 at (324,3) mod 243 — verified in gauge-free form

**Verdict.** No counterexample. The level-5 vertex/block decomposition holds
exactly, and the physical content of M5 — rigid-block shifts vanish, i.e.
rigid value multisets of corresponding classes match under π — holds exactly
at (324,3). The general M5 proof remains open; this is one case only.

## 0. Setup

p = 3, modulus 243, R = Z[√2], α = 3+2√2, L₀ = ord(α mod 3) = 4,
γ = α⁴ = (91,165) = 1+3u, u ≡ √2 mod 3 (μ = 1), γ of order 81.

## 1. (V1) Block decomposition: exact dichotomy

For every unit base point C (52,488), blocks classified rigid (1 value),
full line (3 values, same mod 81, each mult 3), or OTHER:

- Collapsed (C real mod 3, C ≢ 0 mod 3; 13,122 points): 118,098 blocks =
  39,366 rigid + 78,732 lines, 0 OTHER, 0 fiber violations; every orbit
  has exactly 3 rigid blocks + 6 full-line blocks.
- Non-collapsed (39,366 points): 354,294 blocks, 0 rigid, 0 lines, all
  OTHER, all violating the mod-81 fiber property.

So rigid/line structure occurs exactly on collapsed orbits.

## 2. (V2) Rigid multisets match under every class correspondence

127 global groups (as wave 32); rep = first unit per group; 52,488 unit

## 3. Gauge subtlety (why v1's delta-check was the wrong target)

A first attempt checked δ(a,C) = 0 for all a over all algebraic fits
A′ = A₀^εα^s(1+9η₁+27η₂+81η₃) with Tr(η₁) = Tr(η₂) = 0. It fails:
δ ≠ 0 in 2/3 of 8,503,056 evaluations, and 25,272/52,488 units admit no
such fit against an arbitrary group rep. Cause: gauge freedom. E.g. the
identity pair admits the gauge fit s = 12 (twist (α¹²)⁻¹) with
η₁ = (0,2), η₃ = (1,0) and δ ≡ 1 for all a — an artifact of comparing
orbit sequences with shifted base points, not a physical shift. The
physical rigid shift is gauge-free, and §2 verifies it exactly. The
literal "δ(a,C) = 0 for all a" is therefore only meaningful with the
normalized level-4 output, whose rep-normalization is not reproduced by
arbitrary-fit enumeration; that normalization question is open, but it
does not affect §2.
