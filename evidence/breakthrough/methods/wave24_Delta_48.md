# Волна 24, задача 4: Δ(48) численно (прогноз волны 23 проверен — и опровергнут количественно)

## Вердикт

Прогноз волны 23 (Δ(48) ~ 10⁻³²–10⁻³⁰ по пакету RB) **не держится**:
Δ(48) ≈ **1,27×10⁻²⁴ ± 1,2×10⁻²⁶** (оценка по случайной выборке),
строгий интервал **4,42×10⁻²⁷ ≤ Δ(48) ≤ 2,11×10⁻²³**.
Превышение прогноза ~10⁶ раз. Тренд Δ → 0 при этом жив:
1,27×10⁻²⁴ < Δ(36) ≈ 6,5×10⁻²¹. Точное значение — в работе
(полный перебор 418080 произведений, ~7 ч, см. §6).

## Жёсткие волокна (только нули в остальных компонентах)

Произведения (supported-2048 × split81 × нули): **68 глобальных
волокон**, суммарный дефицит **321408** точно (все полностью
гасятся). Только-жёсткий Δ ≈ 9,22×10⁻³¹ — внутри прогноза волны 23.

## Фрагменты по свидетелям (0,1)/(0,2)

Мультисочный mod-P свип: для пары орбит (5,6) выжило 42048 срезов
(qt=289: 576, qt=332929: 41472); точная перепроверка: все 42048 —
настоящие 2-представительные свидетели, срезово-жёстких extras 0.
Множества выживших (0,1) и (0,2) **совпадают полностью**
(не только счётчики). Различных пар (f2048, f_qt): **5328**
(qt=289: 144, все f_qt размера 8; qt=332929: 5184, все размера 16).
Полные произведения: 5382144 точки, 18944 групп, **все смешивающие**,
суммарный дефицит **1539440640**. Типичная пара (2,16): 1152 точки →
4 группы по 288 с counts (96,96,96) → 331776 на пару.
Жёсткие + фрагменты(0,1) = 1539762048 → Δ = 4,4168×10⁻²⁷
(это только нижняя оценка — см. §5).

## Главный новый факт: (6,7)-твиновая идентичность

Для пары орбит (6,7) свип дал выживших **буквально все комбинации**:
qt=289: 11232/11232, qt=332929: 12984192/12984192
(на qt=1329409 и большой компоненте — 0 новых).
Точная проверка (не mod-P): sorted CRT(p0,a6,t) == sorted CRT(p0,a7,t)
для 20/20 случайных (p0, t) на обоих qt. То есть **каждое**
произведение (f2048 × split81 × f_qt) при qt ∈ {289, 332929}
содержит смешивающие волокна: всего **418080 произведений**
(39 × (27 + 10693)). Структура репов: a7 = a6 ∘ σ, где σ фиксирует
нечётные позиции и поворачивает чётные на 8 внутри 12-блоков;
a7 − a6 делится на 27 и нулево на нечётных позициях.
Почему идентичность держится именно при qt ∈ {289, 332929}
(17², 577²) и падает при остальных qt — **механизм открыт**.

## Оценка вклада (1,2) и итог

Полный перебор 418080 пар невозможен в рамках одного шага, поэтому
оценка — по равномерной случайной выборке (перемешанный порядок пар,
seed 12345): n = 3304, средний дефицит пары 1061812 ± 10060 (SE),
нулевых пар 0, min 5184, max 2654208. Дефицит часто равен
10368·n_p·n_s (все волокна 288 с counts (96,96,96)), но не всегда:
при n_s = 16 встречаются разложения 288/144 — точная экстраполяция
по (n_p, n_s) невозможна, нужен полный перебор.
Оценка: вклад (1,2) ≈ 4,439×10¹¹ ± 4,2×10⁹;
**Δ(48) ≈ (321408 + 4,439×10¹¹)/|supp| ≈ 1,273×10⁻²⁴ ± 1,2×10⁻²⁶**.
Строгие границы: снизу 1541000304/|supp| ≈ 4,420×10⁻²⁷
(жёсткие + фрагменты(0,1) + 3 на каждую из остальных 412752 пар —
в каждой есть свидетельское волокно с ≥2 орбитами);
сверху 7355196949248/|supp| ≈ 2,110×10⁻²³
(на пару ≤ (n_p·36·n_s)², суммы квадратов размеров волокон
289: 3585, 332929: 10506241, 2048-supported: 540).

## Следствия для RB (волна 23)

Клауза RB1 «синглетоны в остальных компонентах» **ложна при m = 48**:
доминируют произведения с многоточечными f_qt (8/16/32 точки),
а вклад (1,2) в ~300 раз больше вклада (0,1)-фрагментов.
Счётные рамки RB качественно живы (число вкладовых волокон и
максимальный размер остаются полиномиальными), но константы и
механизм (твиновые орбиты 6,7) в RB не учтены — прогноз 10⁻³²–10⁻³⁰
заменён оценкой ~10⁻²⁴. Тот же урок задним числом: «точные»
Δ(24)/Δ(36) опирались на экран свипа без доказательства полноты;
там выживших не было, но полнота экрана не доказана.

## Что блокирует точное Δ(48)

1. Полный перебор (1,2)-произведений: запущен
   (`wave24_m48_fragments12.py`, resumable JSONL, ~17 пар/с,
   на момент записки 3304/418080, ETA ~7 ч). По завершении
   Δ(48) = (321408 + итог JSONL)/|supp| станет точным при условиях 2–4.
2. Полнота экрана свипа не доказана: произведения без свидетелей
   (с фиксированными p0 и парой репов) не исключены строго.
   При qt ∈ {289, 332929} это закрыто твиновой идентичностью
   (все произведения свидетельствованы); при остальных qt —
   только ноль выживших + набросок.
3. Совместные ненулевые семейства исключены только наброском
   CRT-инъективности (мультисеты по компонентам).
4. Полная проверка φ̂ при m = 48 невозможна (суммы S по 188 млн
   членов большой компоненты); Γ-инвариантность S_q — набросок.
