## (a) Радикальная лемма, случай p = 2: ДОКАЗАНА (набросок, m ≥ 1)

`x = pellX m`, `y = pellY m`, `D = 2(x−1)`, `g = gcd(x−1, y)`, `gp = (x−1)/g`.
Лемма 1 (норма): `x² − 8y² = 1` — индукция, шаг `(3x+8y)² − 8(x+3y)² = x² − 8y²`, база 1.
Отсюда `(x−1)(x+1) = 8y²`.
Лемма 2 (чётность/mod 4): `x` нечётно при всех `m` (шаг `3x+8y`); `x_{n+1} ≡ 3x_n (mod 4)`, значит `x_m ≡ 3^m (mod 4)`;
`y_{n+1} = x_n + 3y_n ≡ 1 + y_n (mod 2)`, `y_0 = 0`, значит `y_m ≡ m (mod 2)`.
Пусть `a = v2(x−1)`, `b = v2(x+1)`, `t = v2(y)` (при `m ≥ 1`: `x ≥ 3`, `y ≥ 1`).
Так как `x` нечётно, `min(a,b) = 1` (из двух соседних чётных чисел ровно одно `≡ 2 mod 4`),
и из нормы `a + b = 3 + 2t`.
- `m` нечётно: `x ≡ 3 (mod 4)`, значит `a = 1`; `y` нечётно, значит `t = 0`; `v2(gp) = a − min(a,t) = 1`.
- `m` чётно: `x ≡ 1 (mod 4)`, значит `b = 1`, `a = 3 + 2t − 1 = 2 + 2t`; `v2(gp) = a − min(a,t) = 2 + t ≥ 2`.
Итого `v2(gp) ≥ 1` при всех `m ≥ 1`, а `2 | D` всегда. Двойка входит в радикал с обеих сторон,
расхождения нет. Вместе с уже известным нечётным случаем (для нечётного `p | x−1`: `p ∤ x+1`,
поэтому `2·v_p(y) = v_p(x−1)` и `v_p(gp) = v_p(x−1)/2 > 0`; обратно `p | gp ⇒ p | x−1 ⇒ p | D`)
получается `rad(D_m) = rad(gp)` при всех `m ≥ 1`. Случай `m = 0` исключён (`y = 0`, `gp = 0` по определению).
Численная сверка `m = 1..30` (точные целые, факторизация): valuations совпали с формулой
(нечётные `m`: `v2(gp) = 1`; чётные: `v2(gp) = 2 + v2(y)`, напр. `m = 8: 5`, `m = 16: 6`),
полное равенство радикалов — во всех 30 случаях. (Наблюдение, не используется: при чётных `m ≤ 30`
оказалось `v2(y_m) = v2(m)`.)
