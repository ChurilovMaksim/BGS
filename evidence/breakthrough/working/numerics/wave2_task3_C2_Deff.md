## 0. Объекты и таблицы

D_m = 2(x_m−1), gp = (x_m−1)/gcd(x_m−1,y_m), yp = y_m/gcd(...),
NmZ(n) = Σ_{i,j} n_i n_j x_{|i−j|}, x_d — Pell x_d,

Для m = 3..6 проверено факторизацией: rad(D_m) = rad(gp). Значит
gcd(N, D_m) = 1 ⇔ gcd(N, gp) = 1, и окно — это в точности единицы mod gp,
повторяющиеся по интервалу. Общего доказательства леммы о радикале здесь нет
(случай p = 2 в M03 открыт в общем виде); для этих m она верна по таблице.

## 1. Тождество отклонения и маршрут через S

Окно W_X = {X < N ≤ 2X, gcd(N, D_m) = 1}, ν_N = N⁻¹ mod gp,
c_ν = #{N ∈ W_X : ν_N = ν}, winAvg = Σ_ν (c_ν/|W_X|) Btup(ν),
nuAvg = (1/φ(gp)) Σ_ν Btup(ν). Тогда

  winAvg − nuAvg = Σ_ν δ_ν Btup(ν),  δ_ν = c_ν/|W_X| − 1/φ(gp).

Счёты по всем единицам (включая нулевые при X < gp) отличаются не более чем на 1:
интервал длины X даёт каждый вычет mod gp либо ⌊X/gp⌋, либо ⌈X/gp⌉ раз, а
gcd-фильтр зависит только от вычета (при rad(D) = rad(gp)). Проверено для
m = 3..6, X = 10, 100, 1000, 20000: spread по всем единицам = 1,
max |c_ν − |W|/φ| ≤ 1. Отсюда, так как Btup ≥ 0,

  |winAvg − nuAvg| ≤ S / |W_X|.                                    (S-маршрут)

Это и есть вся сила маршрута C2: он не использует ничего о Btup, кроме S.
Поэтому ветвь Deff через этот маршрут эквивалентна оценке S.

## 2. Какая нижняя граница счётов нужна

Пусть ρ = φ(D_m)/D_m = φ(R)/R, R = rad(D_m). Блочный подсчёт mod R даёт

  |W_X| ≥ φ(R)·(X/R − 1) = ρ·X − φ(R),          (счётная граница)
  |W_X| ≥ ρ·X/2 при X ≥ 2R.

Требование для ветви Deff через S-маршрут: S/|W_X| ≤ D_m·Deff/X, т.е.

  |W_X| ≥ S·X / (D_m·Deff).                     (необходимая граница счётов)

Подстановка счётной границы: достаточно (с запасом 2) S ≤ Deff·φ(D)/2 при X ≥ 2R;
точно, без запаса, достаточно S < Deff·φ(D) и

  X ≥ X₀ := D_m·Deff·φ(R) / (Deff·φ(D) − S).     (порог по X)

Если S ≥ Deff·φ(D), то никакой границы вида |W_X| ≥ c·X с c ≤ ρ не спасает:
плотность |W_X|/X не может превысить ρ + O(R/X), а S/|W_X| асимптотически
≥ S/(ρX) > D_m·Deff/X. Это убийство S-маршрута, а не обязательно самой ветви:
фактическое |diff| может быть меньше S/|W| из-за корреляции знаков δ_ν с Btup(ν).

Контраст с ветвью s0^{2m}: там S ≤ φ(gp)·s0^{2m} тривиально, и счётная граница
одна даёт ветвь с константой 4·gp при X ≥ 4R/3 (проверка: φ·X ≤ 4·gp·(ρX − φ(R))
при ρ = φ(gp)/gp эквивалентно X ≥ (4/3)R). Ветви s0 счётной границы достаточно;
ветви Deff — нет, нужен ещё вход про S, т.е. про сам ĝ.

## 4. Два уровня убийства

### 4A. Убийство S-маршрута: S > Deff·φ(D)

Примеры (S/(Deff·φD) > 1): m = 3 K = 7 (1.63), m = 4 K = 9 (14.15), K = 10 (11.39),
K = 12 (4.15), alternating K = 8 (5.97); m = 5 K = 7 (1.38), K = 9 (1.21),
alternating K = 8 (5.50); m = 6 K = 7 (4.98), K = 9 (104.36), K = 10 (315.91),
alternating K = 8 (27.27). Для этих ĝ никакой порог X₀ не существует:
S-маршрут не может доказать ветвь Deff ни при каком X. Заметьте: m = 3 K = 7
при этом имеет max R_Deff = 0.21 — фактическая ветвь в проверенном диапазоне
выполняется, а S-маршрут её просто не видит. Различать эти два уровня обязательно.

Btup и S масштабируются как t^{2m}, а член D_m·Deff/X от t не зависит, поэтому
никакая ĝ-независимая оценка S через Deff невозможна в принципе.

## 5. Какой вход про ĝ достаточен

Достаточно вычислить для конкретного ĝ величину S (или, что то же, nuAvg)
и проверить одно из двух:
  (i) S ≤ Deff·φ(D)/2 — тогда S-маршрут + счётная граница дают ветвь
      с константой 2·D_m·Deff при X ≥ 2R;
  (ii) S < Deff·φ(D) — тогда точная константа D_m·Deff получается при
      X ≥ X₀ из §2.
Диагональ q^m = (Σ|ĝ_k|²)^m для этого не годится ни как верхняя, ни как нижняя
оценка nuAvg: в нулевых примерах диагональ 8 при nuAvg = 0 (сокращение
внедиагонали), а в m = 6, K = 9 диагональ 531441 при nuAvg = 71592563
(резонансное усиление в ~135 раз). Проверять надо именно S, т.е. распределение
A_r = Σ_{NmZ≡r} phi(n) по классам вычетов: S ≤ gp·Σ_r |A_r|² (Парсеваль по всем
вычетам, а не только по единицам), и концентрация A_r — это точный объект,
который решает судьбу ветви для данного ĝ.

## 6. Убивающий тест (зафиксирован)

- K-S: если для проверяемого ĝ выполнено S > Deff·φ(D), S-маршрут мёртв.
- K-V: если для некоторого X выполнено X·|winAvg − nuAvg| > D_m·Deff,
  дословная ветвь для этого ĝ ложна.
- K-C: если spread счётов по всем единицам > 1 или |W_X| < ρX − φ(R),
  счётная граница ложна (в проверках не наблюдалось).
- Выживание: S ≤ Deff·φ(D)/2 и X ≥ 2R дают ветвь с фактором 2 через S-маршрут;
  точная константа требует (ii) и X ≥ X₀.
