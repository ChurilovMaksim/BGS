## 1. Модельная матрица (явное определение, не проектная)

Индексы `j, k ∈ {0, …, N−1}`, `N` нечётное (по умолчанию 61).

Базовая матрица (фурье-подобная, симметричная):

    Q[j,k] = N^(−1/2) · exp(2πi·(j² − j·k + k²)/N)

Унитарность — прямое вычисление, а не ссылка на авторитет: при суммировании
по `k` член `k²` сокращается, а сумма `Σ_k exp(−2πi·(j−j′)·k/N)` равна `N`
при `j = j′` и `0` иначе. Симметричность `Q[j,k] = Q[k,j]` очевидна из
формулы. Скрипт проверяет оба свойства численно (`< 10⁻¹⁰`).

Варианты (кик — замороженный, то есть один и тот же для всей матрицы):

- **Q (без кика):** `U = Q`. Контроль-ловушка, см. §5.
- **S (симметричный замороженный кик):** `U = D^(1/2)·Q·D^(1/2)`,
  `D = diag(exp(i·φ_j))`, `φ_j = η·cos(2πj/N)` (по умолчанию `η = 5`).
  Матрица симметрична, поэтому ожидается класс COE, а не CUE.
- **G (ансамбль случайных киков):** `U = diag(exp(i·φ_j))·Q`,
  `φ_j` независимо равномерны на `[0, 2π)` в каждой реализации.
  Это ансамбль, а не одна система: его среднее — диагностика, а не BGS.
- **I (интегрируемый контроль):** `U = diag(exp(i·φ_j))`, `φ_j` независимо
  равномерны. Фазы — независимые случайные числа, поэтому spacing —
  пуассоновский по построению. Это калибровка, а не открытие.
- **CUE (эталон RMT):** случайная унитарная матрица по мере Хаара
  (QR-разложение комплексной гауссовой матрицы с коррекцией фаз `R`).
  Эталон класса CUE/GUE, а не модель отображения.

Наблюдаемое на малых `N` (проверено прогоном, §6): ансамбль `G` и
сдвинутый вариант `S` дают `⟨r⟩ ≈ 0.52–0.54` — рядом с COE (0.536),
далеко от Пуассона (0.386) и от GUE (0.603). Поэтому в этом скрипте
**нет примера класса CUE из отображения**; CUE представлен только
эталоном Хаара. Если кто-то заявит, что модель даёт GUE, — это
противоречит измеренному `⟨r⟩` и должно быть убито этим тестом.

## 2. Какие статистики считать и зачем каждая

Все фазы — собственные значения `U` на единичной окружности:
`λ = exp(i·θ)`, `θ` отсортированы, с круговым замыканием
(последний интервал — до первого `+ 2π`). Средняя плотность на
окружности для этих моделей близка к равномерной, но это проверяется,
а не предполагается (§5).

### 2.1. Spacing и отношение r (главный быстрый тест)

Нормализованный интервал: `s_i = N·(θ_{i+1} − θ_i)/(2π)`, среднее `= 1`
по построению. Отношение соседних интервалов (Atas et al.):

    r_i = min(s_i, s_{i+1}) / max(s_i, s_{i+1}) ∈ [0, 1]

Эталонные средние (без unfolding, поэтому тест устойчив к ошибкам
глобального unfolding):

| класс | ⟨r⟩ |
|---|---|
| Пуассон | 0.38629 (= 2·ln 2 − 1) |
| GOE / COE | ≈ 0.53590 |
| GUE / CUE | ≈ 0.60266 |

Плюс гистограмма `P(s)` против вигнеровских приближений
(это приближения, а не точные RMT-законы):

- Пуассон: `P(s) = exp(−s)`;
- GOE: `P(s) = (π/2)·s·exp(−π·s²/4)`;
- GUE: `P(s) = (32/π²)·s²·exp(−4·s²/π)`.

Гистограмма — вспомогательная: при малых `N` она шумная, а `⟨r⟩`
сходится быстрее. Решение «RMT или Пуассон» принимается по `⟨r⟩`
с погрешностью, а не по красоте гистограммы.

### 2.2. Спектральный форм-фактор (та же величина, что в проекте)

    K(m) = (1/N) · ⟨|Tr U^m|²⟩,   τ = m/N

Это в точности объект `E_θ|Tr U^m|²`, нормированный на `N`,
только усреднение здесь — по ансамблю киков, а не по `θ` проекта.
Эталоны (большие `N`, `m ≠ 0`):

- Пуассон: `K = 1` при всех `m` (для независимых фаз
  `E|Σ e^{imθ}|² = N`).
- CUE: `K = τ` при `τ < 1`, `K = 1` при `τ > 1` (рампа → плато).
- COE: `K = 2τ − τ·ln(1+2τ)` при `τ < 1`;
  `K = 2 − τ·ln((2τ+1)/(2τ−1))` при `τ > 1`.

Форм-фактор различает классы там, где spacing уже не может:
рампа при малых `τ` — признак спектральной жёсткости (уровневого
отталкивания), плато `1` без рампы — признак Пуассона.
Для одной реализации `K(m)` сильно флуктуирует, поэтому
форм-фактор всегда считается по ансамблю и всегда с погрешностью
среднего по реализациям. Одиночный замороженный `U` даёт одну
реализацию `K(m)` — её шум не есть опровержение рампы.

### 2.3. Number variance (долгосрочная жёсткость)

Для дуги длиной `L` средних интервалов: `Σ²(L) = Var(n(L))`,
где `n(L)` — число фаз на дуге. Эталоны:

- Пуассон: `Σ²(L) = L` (рост линейный);
- RMT: `Σ²(L) ~ (2/π²)·ln L + const` (логарифмический рост, GUE;
  у GOE коэффициент другой, но порядок тот же).

На окружности при `L`, сравнимом с `N`, наступает насыщение
(конечный размер), поэтому `Σ²` читается только при `1 ≪ L ≪ N`.
В скрипте это диагностика, а не решающий тест: дуги перекрываются,
и наивная погрешность занижена — это прямо написано в выводе.

## 3. Сколько нужно данных (порядок величин, а не магия)

Погрешность считается **по средним на реализацию**, а не по всем
интервалам сразу: интервалы внутри одного спектра коррелированы,
и формула `σ_r/√(R·N)` занижает погрешность. Правильно:
`SE = std(⟨r⟩ на реализацию)/√R`. Для модели `G` при `N = 61`
этот разброс на реализацию равен `≈ 0.038`, поэтому при `R = 20`
`SE ≈ 0.008`, а при `R = 100` — `≈ 0.004`. Для одного спектра
погрешность из его собственных интервалов вообще не имеет смысла:
один спектр судят по разбросу `≈ 0.038` между реализациями ансамбля.

- Отличить Пуассон (0.386) от GOE (0.536), разрыв 0.15, на уровне
  «разрыв ≫ погрешности»: достаточно `R ~ 20` реализаций при `N = 61`
  (`SE ≈ 0.008`), что и делает скрипт по умолчанию.
  Это уровень демонстрации, а не публикации.
- Измерить `⟨r⟩` с точностью `±0.01` (1σ): `M ~ 10³–10⁴`.
- Измерить `⟨r⟩` с точностью `±0.002`: `M ~ 2·10⁴–10⁵`,
  то есть `N ~ 251`, `R ~ 100–400`. Стоимость — `R` диагонализаций
  `O(N³)`: при `N = 251` это секунды–десятки секунд на реализацию
  в NumPy, при `N = 1001` — уже минуты на реализацию; дальше нужен
  C++ / итерационные методы, а не наивный `eig`.
- Форм-фактор: при малом `τ` значение `K ~ τ` мало, а относительные
  флуктуации велики. Практическое правило: `R ≥ 500` при `τ ≥ 0.1`,
  `R ≥ 5000` при `τ ~ 0.01` для относительной точности ~10%.
  Калибровать `R` надо бутстрепом по реализациям, а не на глаз.
- Масштабирование по `N`: BGS — утверждение о пределе `N → ∞`.
  Одна точка `N = 61` ничего не доказывает. Обязательная серия —
  `N = 61, 101, 251, 501` (нечётные, взаимно простые с параметрами
  модели), с проверкой, что `⟨r⟩` и `K(τ)` стабилизируются,
  а не дрейфуют к другому классу. Если при росте `N` класс меняется
  — это результат (модель не в универсальном режиме), а не шум.

## 4. Систематические ловушки (каждая — с тестом, который её ловит)

1. **Unfolding.** Глобальное нормирование средним интервалом работает
   только при равномерной средней плотности. Тест: гистограмма фаз
   и KS-расстояние до равномерного распределения перед spacing.
   Если плотность неравномерна — нужен локальный unfolding
   (сглаженная кумулятивная функция), иначе spacing искажён.
2. **Вырождения и почти-вырождения.** Точные совпадения дают пик
   `s = 0` и `r = 0`. Тест: доля интервалов `< 10⁻⁶` печатается
   отдельно и никогда не «размазывается» гистограммой.
3. **Симметрии и секторы.** Если у `U` есть дополнительная симметрия
   (чётность, обращение времени, арифметическая симметрия Гекке
   у cat-отображений), полный спектр — это наложение независимых
   секторов, и оно выглядит пуассоновским даже при RMT внутри
   каждого сектора. Тест: проверить симметричность/коммутирующие
   операторы, и при их наличии считать spacing внутри секторов,
   а не по полному спектру. Это — главная известная ловушка именно
   для квантовых cat-отображений.
4. **Ансамбль ≠ одна система.** Среднее по кикам может дать RMT,
   а одна замороженная система — нет (и наоборот, при малом `N`).
   Тест: всегда печатать и ансамблевое `⟨r⟩`, и `⟨r⟩` одной
   замороженной реализации `S` с её собственной погрешностью.
5. **Конечный размер и край окружности.** На окружности нет края,
   но есть насыщение `Σ²` при `L ~ N` и конечно-`N` поправки
   к `K(τ)` при `τ ~ 1`. Тест: серия по `N`, а не одна точка.
6. **Слабый кик / почти интегрируемость.** При `η → 0` модель
   стремится к `Q`, а не к Пуассону и не к RMT (§5). Тест: серия
   по `η` (0, 1, 5, 20) — класс должен быть функцией `η`, и точка
   `η = 0` не должна называться ни одним из классов без проверки.
7. **Вигнеровское приближение ≠ точный RMT.** Расхождение гистограммы
   с вигнеровской кривой на 1–2% — не опровержение RMT. Тест:
   сравнивать прежде всего `⟨r⟩` и `K(τ)` с точными эталонами,
   а гистограмму использовать как иллюстрацию.

## 5. Контроль Q без кика — что он реально показывает

Измерено (N = 31 и 61, прогон перед написанием скрипта):
у `Q` интервалы почти эквидистантны — среднее `r ≈ 0.967`,
минимальный интервал при `N = 61` порядка `10⁻¹⁵` в одной точке
(доля интервалов `< 10⁻⁶` ≈ 0.016), а при `N = 31` минимальный
интервал ≈ 0.97. Это не Пуассон (0.386), не GOE (0.536) и не GUE
(0.603) — это почти регулярная «гребёнка». Вывод, который этот
контроль убивает: «любая унитарная матрица на торе автоматически
даёт RMT». Нет: без кика нет ни хаоса, ни пуассоновской случайности
в этом смысле, а есть почти регулярный спектр фурье-подобной матрицы.
Любой будущий кандидат на проектную `M_N` должен пройти тот же
контроль: сначала спектр самой `M_N` без кика, потом — с киком.

Отдельно, уже на самой модели, поймана ловушка №3 в чистом виде
(скрипт проверяет её автоматически для варианта `S`):
замороженный кик `φ_j = η·cos(2πj/N)` без сдвига коммутирует
с обращением индекса `j → −j` (ошибка коммутатора `~10⁻¹⁵`),
спектр распадается на чётный (31) и нечётный (30) секторы, и
полный спектр даёт `⟨r⟩ = 0.372` — пуассоноподобно, —
а внутри секторов `⟨r⟩ = 0.510` и `0.592` — вокруг COE (0.536).
То есть «одна замороженная система выглядит пуассоновской»
может означать только «забыли десимметризовать». Сдвиг кика
на случайную фазу ломает эту симметрию (ошибка коммутатора `~0.25`),
и ансамбль по сдвигу возвращается к `⟨r⟩ ≈ 0.52`.

## 6. Что измерено на модели (малые N, не доказательство)

Прогон по умолчанию (`N = 61`, `R = 20`, `η = 5`, `seed = 0`,
полный вывод — в `RUN_DEFAULT.log`, время ~2 с):

- `G`: `⟨r⟩ = 0.532 ± 0.008` (погрешность — по реализациям);
- `I` (Пуассон по построению): `0.377 ± 0.005`;
- `CUE` (Хаар): `0.594 ± 0.006` — рядом с 0.603;
- `S` (одна замороженная система): полный спектр `0.372`,
  секторы `0.510 / 0.592` (см. §5) — главный урок скрипта;
- `Q` (без кика): `0.967`, доля интервалов `< 10⁻⁶` равна `0.016`;
- `Σ²(L)` для `G`: `0.46, 0.60, 0.78, 0.81, 0.78` при
  `L = 1, 2, 5, 10, 20` против пуассоновских `1, 2, 5, 10, 20` —
  логарифмическое насыщение вместо линейного роста.

Прогон-разведка (seed фиксирован, `R = 40`):

- `G`, `N = 61`: `⟨r⟩ = 0.530 ± 0.005`; `N = 101`: `0.529 ± 0.004`.
- `S` со случайным сдвигом, `N = 61`, `η = 5`: `0.524 ± 0.005`,
  `η = 20`: `0.536 ± 0.005`.
- `I` (Пуассон): `0.393 ± 0.006` (`N = 61`), `0.390 ± 0.004` (`N = 101`)
  — рядом с 0.386, как и должно быть по построению.
- Форм-фактор `G`, `N = 61`, `R = 40`: рампа есть (например,
  `K ≈ 0.14` при `τ = 0.08`, `K ≈ 0.65` при `τ = 0.49`), Пуассон
  (`K = 1`) отвергнут, но точная кривая COE при этом `N` и `R`
  не воспроизводится точно (при `τ = 0.16` измерено `0.19` против
  `0.28` по COE, при `τ = 1.48` измерено `0.83` против `0.96`).
  Это конечно-размерный и модельно-специфический эффект, а не
  опровержение RMT и не подтверждение точного COE.

Эти числа — калибровка скрипта, а не результат о проектной модели
и тем более не доказательство BGS. Численный результат никогда
не называется здесь доказательством.

## 7. Как пользоваться и что делать дальше

Запуск (только NumPy, без Lean, без сети):

    python3 experiment.py                 # N=61, R=20, быстро
    python3 experiment.py --N 251 --realizations 100 --eta 5

Дальше, по порядку: (1) серия по `N` и по `η`; (2) проверка секторов
и симметрий для кандидата на настоящую `M_N`; (3) перенос скрипта
на настоящие `M_N` и `V_θ`, как только они будут зафиксированы
в источнике, с повторением всех контролей; (4) при `N ≥ 500` —
переход на C++ (LAPACK/zheev) или итерационные собственные решатели,
потому что наивный плотный `eig` станет узким местом.
