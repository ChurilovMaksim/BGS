## 1. Замороженная модель в одной странице

Классика и квантование (по `fixed_map_resolvent_frontier.md` и FM-001).
Для нечётных `N ≥ 3`, с `e_N(t) = exp(2πi t/N)`:

- сырые модульные операторы Вейля
  `(T_N(a,b)ψ)(x) = e_N(b(x + 2⁻¹a)) ψ(x + a)`;
- `S = [[3, 4], [2, 3]]`, `(M_N)_{xy} = N^{-1/2} e_N(-8⁻¹(3x² - 2xy + 3y²))`;
- `U_N = exp(iτN A_N) M_N`, `τ = 10⁻⁸⁰`; `A_N` — квантование `f - 1/10`,
  где `f(q,p) = cos 14πq + r(q)/10 + r(q) sin 2πq/100
  + r(q) cos(2πp - α₀)/100`, `r(q) = (1 - cos 14πq)(1 + cos 2πq)`,
  `e^{iα₀} = (-3 + 4i)/5`;
- поправка словаря: обычному midpoint-квантованию соответствует символ
  `g` с заменой `q ↦ q + 1/2` в `p`-зависимом члене (FM-001, формула (1));
  классическое отображение `F_τ = Φ_g^{-τ/(2π)} ∘ S⁻¹` — вещественно-аналитический
  диффеоморфизм Аносова с тривиальным `C¹`-централизатором (только степени
  самого отображения) и без `C¹`-реверсора. Это закрывает «гладкую симметрию»
  как объяснение, но не даёт ни одной оценки следов.

Микроскопическая цель. Пусть `p_m = Tr U_N^m`. Парная цель:

```
L_N(s) := N⁻² Σ_{m≥1} e^{-2sm/N} |p_m|²  →  (1 - e^{-2s}) / (4s²),   s > 0.
```

Точная резольвентная переформулировка (для любой унитарной матрицы):
с `𝒰_N(X) = U_N X U_N*`, `𝒟_N = (N²/4)(2I - 𝒰_N - 𝒰_N*)`,
`T_N(s) = (1/N) Tr_HS(𝒟_N + s²I)⁻¹` выполнено
`1 + 2L_N(s) = N sinh(s/N) cosh(s/N) · T_N(N sinh(s/N))` и сравнение (R1):
`0 ≤ (1 + 2L_N(s))/s - T_N(s) ≤ (2/(3N)) cosh(2s/N)`. Отсюда при фиксированном
`s > 0` парный предел эквивалентен
`T_N(s) → 1/s + (1 - e^{-2s})/(2s³)`. Универсальный пол:
`L_N(s) ≥ 1/(e^{2s} - 1)` (R2, правильный `N`-угольник; строго ниже цели CUE).
Seven-cut: для обрезанного полного пропагатора `V_N = e^{iτN A_N^cut} M_N`
выполнено `‖U_N - V_N‖₁ ≤ 28π²τ/(25N)` и перенос (R3)/(R4):
`|∂_s^r(L_{U,N} - L_{V,N})| ≤ C_{K,r} τ/log N` на компактах — эквивалентность
возможных пределов, а не значение предела.

Точный мост «следы → статистика» (не требует доказательства, это тождество).
Для унитарной `U` с фазами `θ_j`, теста Шварца `φ` и
`D_U(m_1,…,m_k) = Σ_{различные j} exp(2πi Σ m_a θ_{j_a})`:

```
D_U(m) = Σ_{π ∈ Π_k} μ(π) ∏_{B ∈ π} Tr U^{Σ_{a∈B} m_a},   μ(π) = ∏ (-1)^{|B|-1}(|B|-1)!,
C_{k,N}(U;φ) = N^{-k} Σ_{m ∈ ℤ^{k-1}} φ̂(m/N) D_U(m_1,…,m_{k-1},m_k).
```

Следствие: микроскопическая статистика с компактным носителем Фурье
контролируется **совместными следами при `|m| = Θ(N)`** (гейзенберговский
масштаб). Никакая информация о фиксированных степенях или окне `o(N)`
её не определяет (контрпример: корни `N`-й степени один раз против
корней `M`-й степени дважды при `N = 2M` — одинаковые следы при
`1 ≤ |n| < M`, разная парная статистика).

### Аналитический слой моста 149–151 (θ-ансамбль)

Мост `LineDBridge` доказывает условно: из `hTrace` + `hAvg` среднее
`|T|²` по θ равно модовой сумме `PsiMode`; из `hPair` модовая сумма
равна парной сумме `PsiPair`. Открыты сами посылки:

- **O3. `hTrace` (механизм Боасмана–Китинга).**
  Формула `Tr U^m = Tr M_N^m · Σ_n Ĝ(n) e(t_N · 2Qn)` для каждого θ,
  где `t_N = (D_m⁻¹ mod N)/N`, `Qn = nᵀ X_m n`. Не доказана для истинного
  кика; в дереве нет языка θ-ансамбля.
- **O4. `hAvg` и свойства среднего `hEadd/hEsmul/hEconj`.**
  Усреднённые ковариации `E[a_n · star(a_{n'})] = c_{nn'}` для истинного
  θ-среднего («сайты iid с точностью до общей фазы, которая сокращается» —
  аналитический вход, а не теорема). Игрушечное конечное среднее их НЕ
  закрывает.
- **O5. `hPair` (модовая сумма = парная сумма).**
  Тождество реиндексации / θ-инверсии, переводящее `PsiMode` в `PsiPair`.
  Как абстрактная импликация доказано; как тождество для истинных данных —
  открыто.
- **O6. Симметрия `c` (`V → -V`) для минус-случая.**
  Фазовая замена 150 в минус-варианте требует симметричных ковариаций
  (`psiMode_even`); для истинного ансамбля не доказана. Без неё минус-форма
  фазовой леммы не применяется к истинной `Psi_m`.
- **O7. Положительность модовой суммы.**
  Вещественность при эрмитовом `c` доказана (149Props); положительность
  требует `c ⪰ 0`, т. е. картины ансамбля (`Psi_m = E|T|² ≥ 0`), а не
  алгебры модовой суммы.
- **O8. Отождествление `Psi_m = PsiMode`.**
  То, что граничная `Psi_m` — это именно модовая сумма с формой `Qform`
  и усреднёнными ковариациями. Это содержание 149-full; фазовая лемма
  работает на уровне `PsiMode` и его НЕ закрывает.

### Линия 150: фазовая замена (ложный коллапс и его замена)

- **ЗАКРЫТО (как ложное): `hcollapse`.**
  Утверждение `N₁ ≡ ±N₂ [MOD g'] ⇒ t*(N₁) ∓ t*(N₂) ∈ ℤ` для истинного
  `t* = t_N - 1/(N·D_m)` ЛОЖНО: при `m = 3` (`D = 196`, `g' = 14`)
  `t*(1) = -1/196`, `t*(15) = 13/196`, разность `-1/14 ∉ ℤ`, хотя
  `15 ≡ 1 [MOD 14]`; минус-форма тоже ложна. Следствие: `hcollapseNeg`
  в (e)-переносах 157 неприменим, а шапка `LineDBridge` как равенство
  неверна (только комментарий).
- **ЗАКРЫТО (на уровне `PsiMode`, `m = 3..9`): фазовая лемма.**
  Истинное `t* = k/D_m`, `k = (D·r - 1)/N`, и для всякого делителя
  `e | D_m` выполнено `N·k ≡ -1 (mod e)`; отсюда `N₁ ≡ N₂ [MOD e]`
  даёт `e | (k₁ - k₂)`, а `N₁ + N₂ ≡ 0 [MOD e]` даёт `e | (k₁ + k₂)`,
  и при `d | 2Q` фазы целые, поэтому модовые суммы совпадают.
  Финалы — при `3 ≤ m ≤ 9` и `N₁ ≡ ±N₂ [MOD gp m]` (минус — при
  симметричных `c`). Остаток: обобщение на все `m` (см. N2) и O6, O8.

### Линия 152: сильный кик

- **O9. `hSep` в общем виде (разделение мод).**
  Из равенства степенных сумм `S_k(ξ)` следует, что `ξ, ξ'` лежат в
  одной Γ-орбите. Источник (D5): шаг Ньютона «степенные суммы ⇒
  мультисеты» плюс точная проверка `[CA]` «мультисеты ⇒ Γ-класс» только
  для `m ≤ 7`. Независимый exact replay на чистом Python подтвердил
  таблицу для `m = 3..7` (плохих волокон 0; волокна — ровно одна
  Γ-орбита; `m = 3: 196/48/6; 4: 1152/203/8; 5: 6724/756/10;
  6: 39200/3604/12; 7: 228484/16800/14` — размер/число волокон/что-то
  порядка орбиты по таблице replay). Как теорема Lean `hCA` открыта:
  kernel-`decide` невыполним (прецедент OOM на `det H_7`); replay —
  артефакт-верификатор, а не доказательство.
- **O10. `hSepC` (комплексный вариант).**
  Разделение для комплексной G-ансамблевой сборки; остаётся гипотезой
  даже при доказанном гауссовом ω (см. ниже).
- **O11. J0-ансамбль.**
  `ω = J0(a|z|)` (среднее Клайвера, по TRACE-133). В Mathlib нет бесселя
  `J0`, поэтому затухание `J0(x) → 0` и само тождество Клайвера —
  аналитические входы, не доказанные в дереве. Гауссов случай
  (`ω = exp(-(akz)²/4)`) закрыт из Mathlib: три ω-гипотезы + Γ-инвариантность
  `modeSum` + равенство пределов по нечётным взаимно простым вычетам.
- **O12. `N`-шаг (`hN`) итерационного сильного предела.**
  Требует цепочки 149 (O3–O5) + `C^∞`-непрерывность Ψ по `t` + `t_N → t*`
  (на уровне `PsiMode` разность `t_N - t* = 1/(N·D_m) → 0` доказана;
  для истинной `Psi_m` — нет) + фазовую замену вместо ложного `hcollapse`.
- **O13. Отождествление конечного `Fix m` с тором `Fix_m`.**
  В `LineDOrbitPairFull` прямо сказано: отождествление тора с конечной
  моделью как таковое не формализовано (`fixEquivQuot` — это сама конечная
  модель). Без него «модовые суммы на `Fix m`» не привязаны к граничным

  Без неё среднее по окну — теорема о формальном объекте, а не о `U_N`.
- **O20. Окно `(X, 2X]` против полного блока.**
  Полный блок даёт точное равенство средних; окно источника имеет длину
  `X`, вообще говоря не кратную `D`, поэтому слои различаются не более
  чем на единицу на класс. Эта дискрепансия — ровно член `D/X` в O17;
  отдельно от O17 не стоит, но путать окно с блоком нельзя (именно эта
  подмена и породила бы ложное «доказательство» `hEquidist`).

### Прочие открытые обязательства, упомянутые в проверенных документах

- Значение резольвенты/парного предела для `U_N` или `V_N` (перенос R3/R4
  даёт только эквивалентность; см. раздел 1).
- Веха Грама `N⁻¹ Tr Γ_{N,N}² → 4/3` для
  `Γ_{N,N} = [N⁻¹ Tr U_N^{b-a}]_{0≤a,b<N}` — необходимый парный тест,
  не доказанный для модели; причём по TRACE-008 даже он вместе с простыми
  фазами, макроскопической сходимостью Хаара, равномерной занятостью и
  ненулевыми следами НЕ достаточен как универсальный критерий CUE-пар.
- Примарно-резонансный сектор: для каждого компактного положительного
  гейзенберговского окна `p⁻² Σ_{rd_p/p ∈ K} |Tr C_{p,d_p}^r|² = o(1)`
  (достаточное спектральное условие — энергия гребёнки Фейера `1 + o(1)`
  на сдвинутых микроскопических парах).
- FM-004 (по памяти проекта: гипотезы (H3) — три нормированных затухания
  остатков для замороженного отображения — якобы найдены в
  `three_orientation_resolvent_barrier.md` §1): локально НЕ проверено,
  требует сверки с main через коннектор; в список доказанного не вносить
  до сверки.

## 3. Новые теоремы-цели (7 штук)

Критерии отбора: (i) не перефразировка уже доказанных ядер из раздела 2;
(ii) доказуемость конечными/структурными средствами без всей BGS;
(iii) приближает именно микроскопическую спектральную статистику
(вторые моменты, разделение мод, средние следов, симметрию, масштаб
Гейзенберга), а не только формальные тождества. Порядок — по убыванию
отношения «ценность / риск».

### N1. Элементарная равномерность вычетов по единицам на окне `(X, 2X]`

**Точная гипотеза.** Пусть `m ≥ 2` фиксировано, `D = (Dm m).toNat`,
`g' = gp m`, `g' | D` (глюинг O20-леммы, см. ниже). Пусть окно —
`W_X = {N ∈ (⌊X⌋, ⌊2X⌋] : gcd(N, D) = 1}`, а `ν(N)` — обратный вычет
`ν(N)·N = 1` в `ZMod g'`. Пусть `B : ZMod g' → ℝ` — профиль с носителем
в единицах (в приложении: `B = Btup m ĝ`, `|B| ≤ s0^{2m}` суммарно
и носитель `≤ Deff`). Тогда существует явная константа `D(m)`,
зависящая только от `m` (через `D`, `g'`, `φ(D)`, `φ(g')`), такая что

```
| (1/|W_X|) Σ_{N ∈ W_X} B(ν(N))  −  (1/φ(g')) Σ_{u ∈ (ZMod g')ˣ} B(u) |
    ≤ D(m) · min( Σ_ν |B(ν)| ,  Deff(m) · max_ν |B(ν)| ) / X .
```

В частности, это в точности гипотеза `hEquidistUnits` модуля Units
(с точностью до явного вида константы, которую мост оставляет свободной).

**Почему не тривиально, но и не требует Вейля.** Ключевое наблюдение —
периодичность: при `gcd(N, D) = 1` вычет `ν(N)` зависит только от
`N mod g'` (обратный элемент mod `g'` определяется классом `N mod g'`).
Поэтому интервал `(X, 2X]` распадается на полные `D`-блоки, на каждом из
которых слои `ν` равны точно (это уже доказанный `hfib`), плюс остаток
длиной `< 2D`. Каждый класс единиц получает от остатка `O(1)` лишних
или недостающих точек (явно: не более `⌈2D/g'⌉` на класс), а знаменатель
`|W_X| ≍ X·φ(D)/D`. Отсюда дискрепансия средних есть `O(φ(g')/X)`
с явной константой — без сумм Клоостермана и без оценок Вейля.
Нетривиальная часть — аккуратный подсчёт: (a) глюинг `g' | D`
(`gp m | x_m - 1 | 2(x_m - 1) = D_m` — одна строка, оставленная модулем
Hfib «на склейку»); (b) оценка `|W_X|` снизу через `φ(D)/D` с явным
остаточным членом при малых `X`; (c) переход от поклассовой дискрепансии
к форме с `min(...)`: суммарная масса `Σ|B|` даёт одну ветвь, а
`носитель × max|B|` — вторую (обе нужны, так как мост использует `min`).
Замечание о риске: в заголовке Bridge-модуля `hEquidist` названа
«оценкой типа Вейля». Если при сверке с источником окажется, что
`ν_N` там зависит от `N` не только через `N mod g'` (например, через
дополнительный твист), элементарный аргумент рушится — поэтому первый
шаг работы над N1: сверить определение `ν` в `phase1_trace_formula.md`
§§4–5 с определением моста. Локально определения совпадают
(`ν(N)·N = 1` в `ZMod (gp m)` на окне с `gcd(N, D) = 1`).

**Чем может быть убита (численный тест).** Для `m = 2..7` и `X` по
геометрической сетке (например, `X = 10^k`, `k = 2..6`, плюс случайные
`X`) вычислить напрямую левую часть для профилей
`B = Btup m ĝ` при нескольких `ĝ` (включая `ĝ₀ = 1` на `{0,1}` —
контрольный ложный случай моста) и проверить: (a) `X × дискрепансия`
ограничена константой, не растущей с `X`; (b) константа не превосходит
предлагаемую `D(m)`. Если `X × дискрепансия` растёт (например, как
`log X` или `X^α`), элементарная гипотеза в заявленной форме ложна,
и нужен настоящий характер-суммовой аргумент. Контроль: при `m = 1`
таргет по всем вычетам даёт зазор 2 — тест обязан воспроизвести это
различие между `nuAvg` и `nuAvgUnits`.

**Что останется открытым после N1.** O18 (константа `≈2π`), O19
(`kickMatInf`), O3–O5 (аналитический слой), O1–O2. Но мост 175-units
станет безусловным по модулю O18/O19: среднее следов по окну будет
равно среднему по единицам с явной ошибкой `O(1/X)`. Это первый
безусловный гейзенберговский (окно `Θ(X)`, `X` — масштаб размерности)
результат о среднем `‖Tr U_N‖²` в программе, а не только тождество.

### N2. Общая присоединённая фазовая лемма для всех `m`

**Точная гипотеза.** Пусть `H` — целочисленная `m × m`-матрица с
`det H = D ≠ 0`, `X` — её присоединённая матрица (`H·X = D·I`),
`Q(n) = nᵀXn`. Пусть `d` — натуральное число с `d | 2X_{ij}` для всех
`i, j`, и `e = D/d` (в приложении: `H = H_m`, `X = X_m`, `D = D_m`,
`d = d_m := gcd(D, все 2X_{ii}, все 4X_{ij})` — см. ниже).
Тогда для `t₁* = k₁/D`, `t₂* = k₂/D` с `N_i·k_i ≡ -1 (mod e)`
(`N_i` — параметры из PhaseLemma) из `N₁ ≡ N₂ [MOD e]` следует
равенство модовых сумм `PsiMode c Q t₁* = PsiMode c Q t₂*`,
а из `N₁ + N₂ ≡ 0 [MOD e]` — равенство `PsiMode c Q t₁* = PsiMode c Q (-t₂*)`
при симметричных `c`. Отдельная арифметическая часть: для конкретных
`H_m` из Derand выполнено `D_m / d_m = gp m` (тождество чисел Пелля,
доказываемое рекуррентой `x_m, y_m`, а не `decide`).

**Почему не тривиально и чем отличается от доказанного.** Доказанная
фазовая лемма даёт финалы только для `3 ≤ m ≤ 9`, где вход
`d | 2X_{ij}` и равенство `D/d = gp m` проверены `decide` на конкретных
матрицах (`d = 14, 24, 82, 140, 478, 816, 2786`). Абстрактная часть N2 —
чистая алгебра присоединённой матрицы: из `H·X = D·I` и делимости
записей следует целочисленность фаз `(t₁ ∓ t₂)·2ΔQ`, а значит,
равенство сумм — без перебора `m`. Нетривиально именно отделение
алгебры от арифметики: `decide` не масштабируется (`D_7 = 228484`,
дальше хуже), а тождество `D_m/d_m = gp m` требует рекуррентной
арифметики последовательностей Пелля `x_m + y_m√2 = (3 + 2√2)^m`
(или соответствующей рекурренты для `H_m`), включая 2-адический анализ
`gcd(D_m, 2X_{ii}, 4X_{ij})`.

**Чем может быть убита (численный тест).** Вычислить `X_m`, `D_m`,
`d_m`, `gp m` для `m = 3..20` (целочисленная арифметика, дёшево) и
проверить `D_m/d_m = gp m` и `d_m | 2X_{ij}` для всех `m`.
Несовпадение хотя бы при одном `m` убивает арифметическую часть
в заявленной форме (алгебраическая часть при этом выживает с
`e = D_m/d_m` вместо `gp m`, но финалы придётся переформулировать).
Дополнительно: для `m = 10..12` проверить равенство модовых сумм
при `N₁ ≡ N₂ [MOD gp m]` на случайных `c` прямым суммированием —
если найдётся контрпример, неверна сама схема (а не только `decide`).

**Что останется открытым после N2.** O6 (симметрия `c`), O8
(отождествление), O3–O5. Но фазовый шаг 150 станет равномерным по `m`,
а не списком случаев — это убирает главное конечное препятствие
на пути от `t_N` к `t*` на уровне модовых сумм.

### N3. Тождества Ньютона и сертификат разделения `hSep`

**Точная гипотеза (две части).**
(a) *Тождества Ньютона для конечных мультисетов над `ℂ`.*
Пусть `A, B` — мультисеты комплексных чисел размера `≤ K`. Если их
степенные суммы `p_j = Σ a^j` совпадают для `j = 1..K`, то `A = B`
как мультисеты. (Доказательство: через элементарные симметрические
многочлены и обратимость матрицы Вандермонда в характеристике 0;
в заголовке 152conc прямо сказано, что леммы Ньютона в Mathlib
не найдено.)
(b) *Сертификатная редукция `hSep`.*
Для конкретных модовых сумм `S_k(ξ)` (конечная модель `Fix m`,
`ξ_j = val/D_m`) утверждение «`S_k(ξ) = S_k(ξ')` для всех `k`
влечёт `ξ' ∈ Γ·ξ`» эквивалентно конечному сертификату на `m`:
списку представителей Γ-орбит на `Fix m` и таблице степенных сумм,
проверяемой конечным перебором. В частности, после (a) остаток `hSep`
— ровно проверка `[CA]`: равные мультисеты значений
`[S_k(ξ)]` влекут Γ-эквивалентность, — и ничего более.

**Почему не тривиально.** Часть (a) — стандартная, но не формализованная
алгебра; её отсутствие блокирует формальный шаг D5. Часть (b) ценна
тем, что превращает открытую «аналитическую» гипотезу `hSep` в
задачу с явным конечным сертификатом на каждое `m`: это честный
развод между теоремой (Ньютон, для всех `m` сразу) и вычислением
(`[CA]`, по одному `m`). Нетривиальность (b) — в аккуратном описании
мультисета: какие именно значения образуют `[P]`, как Γ действует
перестановкой координат, и почему равенство всех `S_k` при
`k ≤ |Fix m|` достаточно (а не всех `k`).

**Чем может быть убита (численный тест).** Продолжить exact replay
с `m ≤ 7` на `m = 8, 9, 10`: построить волокна отображения
`ξ ↦ (S_k(ξ))_k` и проверить, что каждое волокно — ровно одна Γ-орбита.
Найденное волокно из двух разных орбит убивает `hSep` при этом `m`
(и тем самым показывает, что сильный-кик предел в заявленной форме
требует пересмотра). Риск по стоимости: `D_7 = 228484` уже велик;
для `m = 8, 9` перебор может потребовать потоковой/блочной реализации
и оценки времени заранее; если полный перебор невозможен, допустимый
ослабленный тест — случайная выборка `ξ` с поиском коллизий
(отрицательный результат слабее, но положительная коллизия всё равно
убивает гипотезу).

**Что останется открытым после N3.** Сама проверка `[CA]` при каждом
`m` (вычисление, а не теорема), O11 (J0), O12 (`N`-шаг), O8, O1–O2.
Но после N3 + N1 + N2 цепочка «разделение → сильный предел» будет
состоять только из явных конечных сертификатов и аналитического слоя
O3–O5, без скрытых алгебраических пробелов.

### N4. Ансамбль `J0`: гипотезы ω из бесселева интеграла и тождество Клайвера

**Точная гипотеза.** Определим
`J0(x) = (1/π) ∫_0^π cos(x sin θ) dθ` (эквивалентно
`(1/2π) ∫_0^{2π} e^{ix sin θ} dθ`). Тогда:
(i) `J0(0) = 1`; (ii) `|J0(x)| ≤ 1` для всех вещественных `x`;
(iii) `J0(x) → 0` при `|x| → ∞`;
(iv) *тождество Клайвера:* для равномерной фазы `φ` на окружности
`E_φ[exp(i a |z| cos φ)] = J0(a|z|)` (точное интегральное тождество,
а не приближение). Отсюда ω-гипотезы модуля StrongKick
(`ω(0) = 1`, ограниченность, затухание) выполнены для `ω = J0`,
и сильный-кик предел для J0-ансамбля сводится к тем же остаточным
гипотезам `hSInv`, `hSep` (и комплексной `hSepC`), что и гауссов случай.

**Почему не тривиально.** (i)–(ii) — тривиальны из определения;
нетривиально (iii): после разбиения `[0, π]` в точке `π/2` и замены
`u = sin θ` получается интеграл `∫ cos(xu)/√(1-u²) du` с интегрируемой
особенностью — затухание следует из леммы Римана–Лебега для `L¹`,
а не из поточечных оценок (стационарная фаза даёт скорость `x^{-1/2}`,
но для ω-гипотез нужна только сходимость к нулю). Нетривиально и
формализационное: в Mathlib нет готового `J0`, поэтому определение
через интеграл, (iv) как замена переменной и (iii) как Римана–Лебега
нужно собрать вручную. Важно: (iv) — это вход ансамбля (как именно
фазы усредняются), а (iii) — аналитический факт о функции; их нельзя
путать: доказательство (iii) не доказывает, что физический ансамбль —
именно клайверовский.

**Чем может быть убита (численный тест).** Сравнить интегральное
определение с эталонным `J0` (например, `scipy.special.j0`) на сетке
`x ∈ [0, 100]` с точностью `10⁻⁸`; проверить скорость затухания
`|J0(x)| ≲ C x^{-1/2}` и отсутствие «плато» на больших `x`;
Монте-Карло по фазам: среднее `exp(i a|z| cos φ)` по `10⁶` фаз
против `J0(a|z|)` при нескольких `a|z|`. Расхождение интеграла
с эталоном убило бы определение (ошибка в нормировке/фазе);
расхождение Монте-Карло с `J0` сверх статистической ошибки убило бы
(iv) как заявленное тождество (а не (iii)).

**Что останется открытым после N4.** `hSep`/`hSepC`, `N`-шаг O12,
O3–O5, O1–O2. Но исчезнет асимметрия «гауссов ансамбль доказан,
физический J0-ансамбль — нет»: оба ансамбля встанут на одни и те же
остаточные гипотезы, и различие между ними станет чисто вопросом
разделения, а не специальных функций.

### N5. Количественная липшицевость модовой суммы и скорость `t_N → t*`

**Точная гипотеза.** Пусть `PsiMode c Q t` — конечная модовая сумма
(149Props доказывает только качественную `C^∞`-гладкость). Тогда
с явной константой

```
|PsiMode c Q t − PsiMode c Q t'| ≤ 2π · M_Q · (Σ_{n,n'} |c_{nn'}|) · |t − t'|,
M_Q := max_{n,n'} 2|Qn − Qn'|.
```

Для конкретной формы `Qform` (присоединённая матрица `X_m`)
`M_Q` оценивается явно через записи `X_m` (конечная оценка на `m`).
В сочетании с точным `t_N − t* = 1/(N·D_m)` отсюда:

```
|PsiMode c Qform t_N − PsiMode c Qform t*| ≤ 2π · M_Q(m) · (Σ|c|) / (N·D_m) = O_{m,c}(1/N).
```

**Почему не тривиально и чем отличается от доказанного.**
149Props даёт `C^∞` без констант и `t_N − t* = 1/(ND)` без их соединения.
N5 — это их количественное соединение: оно превращает «`t_N` стремится
к `t*`» в скорость `O(1/N)` для модовой суммы с явной константой.
Нетривиальная часть — явная оценка `M_Q(m)` через `X_m` (записи растут
с `m`; грубая оценка через `‖X_m‖` даёт константу, но для приложений
к сильному пределу важно, что она зависит только от `m`, а не от `N`).
Это не приближает O1 само по себе, но закрывает один из трёх
ингредиентов `N`-шага O12 количественно.

**Чем может быть убита (численный тест).** Для `m = 3..7`, случайных
`c` (включая `c ≡ 1` и веса `phihatFix`) и сетки `t, t'` проверить
неравенство напрямую и измерить запас `левая/правая часть`:
если отношение превышает 1 хотя бы в одной точке, константа неверна
(ошибка в множителе 2 или в `M_Q`); если отношение близко к 1
систематически, константа остра и улучшать её некуда. Отдельно:
проверить `O(1/N)`-скорость на `t_N, t*` при `m = 3`, `N = 1, 15, 13`
(известные значения `t*`) — отклонение от `1/N` укажет на ошибку
в определении `t*`.

**Что останется открытым после N5.** O8 (перенос с `PsiMode` на `Psi_m`),
O3–O5, O12 в остальной части (итерация предела, `hSep`), O1–O2.
После N5 фраза «`t_N → t*`» перестанет быть качественной: для модовой
суммы будет число, а не стрелка.

### N6. Классификация делимости `2m | Deff m` (расширение 154 на все `m`)

**Точная гипотеза.** Пусть `Deff m = (Dm m)/(card (V4 m))` —
эффективное число из 154 (для нечётных `m` доказано `Deff m = A_m²`
с нечётным `A_m`). Тогда множество `{m : 2m | Deff m}` описывается
явно через 2-адическую арифметику чисел Пелля `x_m, y_m`:
(а) формула для `card (V4 m)` при всех `m` (ядро `H_m mod 4` —
конечный 2-адический расчёт, обобщающий доказанный случай нечётных `m`,
где ядро — ровно константы); (б) критерий делимости `2m | Deff m`
в терминах `v₂` и делителей `m`. Для всякого `m` с `2m ∤ Deff m`
заключение 154 (`2m − B_m^sym ≥ m/Deff > 0`) следует немедленно
из уже доказанного `sym_bound_of_not_dvd`.

**Почему не тривиально.** Случай нечётных `m` использует, что ядро
`H_m mod 4` — константы, откуда `card V4 = 4` и нечётность `A_m`.
При чётных `m` ядро может быть больше, и `Deff` может терять
нечётность; нужен полный 2-адический анализ матрицы `H_m`
(её записей через `x_m, y_m`) и явный подсчёт ядра. Это конечная
арифметика, но не перебор: критерий должен работать для всех `m`,
а не только для проверенных. Ценность: 154 — это второй момент
(парная статистика), а не формальность: граница `B_m^sym < 2m`
есть нетривиальное утверждение о парной сумме, и её расширение
на все `m` — настоящий шаг к микроскопической статистике второго
порядка.

**Чем может быть убита (численный тест).** Вычислить `Deff(m) mod 2m`
для `m ≤ 200` (чистая целочисленная арифметика, дёшево) и
сопоставить с предсказанным критерием. Два исхода, оба информативны:
(1) критерий подтверждается и множество `{2m | Deff}` пусто или
мало — тогда 154 распространяется почти на все `m` даром;
(2) находится `m` с `2m | Deff m` — тогда для этого `m` аргумент
154 принципиально не работает, и нужен другой метод (это не провал
программы, а точная граница метода; зафиксировать такой `m`
как контрпример к наивному обобщению). Известная точка: `m = 6`
уже покрыта (`Deff 6 = 4900`, `12 ∤ 4900`).

**Что останется открытым после N6.** Всё остальное: 154 — только
второй момент при фиксированном `m`; O9–O12, O1–O2 не затрагиваются.
Но «граница 154 для всех `m`» перестанет быть списком случаев.

### N7. Отождествление конечного `Fix m` с тором `Fix_m` (Γ-эквивариантно)

**Точная гипотеза.** Пусть торовая модель — множество неподвижных
точек торального эндоморфизма, заданного `H_m` (точное определение
— из `band_limited_kick_bridge.md`, локально недоступного; первый шаг —
выписать его дословно из main). Тогда отображение
`y ↦ (y_j / D_m mod 1)_j` задаёт биекцию конечного ядра
`Fix m = {y : ZMod m → ZMod D_m : H_m y = 0}` на тор `Fix_m`,
эквивариантную относительно действия `Γ` (перестановка координат
с обеих сторон), и переводящую конечные модовые суммы
`S_k(ξ) = Σ_j e(k ξ_j)` с `ξ_j = (ξ.1 j).val / D_m` в торовальные
модовые суммы источника. В частности, мощности совпадают, и
Γ-орбиты соответствуют друг другу биективно.

**Почему не тривиально.** В дереве конечная модель уже используется
как «сама» торовая (`fixEquivQuot`, `phihatFix`), но биекция с тором
не доказана: нужно показать, что ядро mod `D_m` в точности
поднимается в тор и что действие Γ на подъёме совпадает с
перестановкой координат. Нетривиальность — в обращении с кручением:
ядро эндоморфизма тора — конечная группа порядка `|det H_m|`,
а конечное ядро mod `D_m` — объект другой природы; их отождествление
требует явного изоморфизма `(1/D_m)ℤ/ℤ`-решетки, а не общей ссылки
на «конечную модель». Без N7 все результаты на `Fix m` (152conc,
154bridge) формально относятся к конечной модели, а не к граничным
объектам.

**Чем может быть убита (численный тест).** Для `m = 3..9` вычислить
`|Fix m|` прямым перебором ядра и сравнить с торовальным числом
неподвижных точек `|det H_m|`-типа из источника; проверить
Γ-эквивариантность на представителях орбит (образ орбиты = орбита
образа). Несовпадение мощностей или неэквивариантность убивает
заявленную биекцию (а не только её доказательство) и означает,
что конечная модель — не то же самое, что тор, и нуждается
в поправке (например, факторе `V4` или другом кручении).

**Что останется открытым после N7.** O3–O5 (аналитика), O9–O12, O1–O2.
Но после N7 исчезает оговорка «тор ↔ конечное не формализовано»
из заголовков: результаты 152/154 станут результатами о граничных
объектах, а не о модели.

## 4. Порядок работы и численные тесты как гипотезы

Рекомендуемый порядок (по соотношению ценности и риска):

1. **N1** — сначала сверка определения `ν` с источником, затем подсчёт
   остатка и явная константа; численный тест — дискрепансия × `X`
   для `m = 2..7`.
2. **N6** — сначала дешёвый перебор `Deff(m) mod 2m` до 200; критерий
   формулировать после таблицы, а не до неё.
3. **N2** — сначала таблица `X_m, D_m, d_m, gp m` до 20; абстрактная
   лемма не зависит от таблицы и может идти параллельно.
4. **N5** — короткая количественная надстройка над 149Props; тест —
   запас неравенства на случайных `c`.
5. **N3** — тождества Ньютона (теорема) + сертификат `[CA]`;
   тест — replay волокон для `m = 8, 9, 10` с оценкой стоимости заранее.
6. **N4** — определение `J0` интегралом, (iii) через Римана–Лебега,
   (iv) как замена переменной; тест — `scipy` + Монте-Карло.
7. **N7** — после выписки торовального определения из main;
   тест — мощности и эквивариантность для `m = 3..9`.

Общее правило для всех тестов: положительный численный результат
НЕ повышает статус теоремы с «гипотезы» до «доказанной»; отрицательный
(контрпример) — убивает гипотезу в заявленной форме и должен быть
зафиксирован как таковой, а не обойдён переформулировкой без явного
указания, что именно изменилось. Ложные посылки, уже зафиксированные
в программе (`hcollapse`, `hEquidist` в форме моста при `m = 1`,
σ-подход для 157(a)), не должны возрождаться в новых формулировках
под другими именами: каждая новая теорема в разделе 3 явно указывает,
какую ложную посылку она обходит и как.
