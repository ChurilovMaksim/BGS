# Новые принципы для замороженного отображения: кандидаты фазы А

Статус документа: **это не теоремы**. Это пять кандидатных принципов
(фаза А программы: широкий поиск метода). Каждый из них сформулирован
так, чтобы его можно было убить численным тестом за минуты, и для
каждого честно сказано, что останется недоказанным, даже если тест
пройдёт. В main ничего из этого не попадает без фазы Б: последовательной
Lean-проверки на свежей базе.

## Обозначения (сверены с тестовыми копиями проекта, а не взяты на веру)

- `H_m = 6I − C − Cᵀ` (циклический сдвиг), `D_m = det H_m`,
  `X_m = adjugate H_m`, `Q_m(n) = nᵀ X_m n`.
- Числа Пелля из `LineBDerand`: `x₀=1, y₀=0`,
  `x_{n+1}=3x_n+8y_n`, `y_{n+1}=x_n+3y_n`, `D_m = 2(x_m−1)`,
  `gp m = (x_m−1)/gcd(x_m−1, y_m)`.
- Таблица, проверенная в проекте и пересчитанная здесь:
  `D = 4, 32, 196, 1152, 6724, 39200, 228484, 1331712` при `m = 1..8`;
  `gp = 2, 8, 14, 48, 82, 280, 478, 1632` при `m = 1..8`.
- `t_N` — модульный обратный `D_m⁻¹ mod N`, делённый на `N`;
  `t* = t_N − 1/(N·D_m) = k/D_m`, где `k = (D_m·r − 1)/N`,
  `r = D_m⁻¹ mod N`. Для всех делителей `e ∣ D_m` выполнено
  `N·k ≡ −1 (mod e)` — это уже доказано в `LineDPhaseLemma`.
- `PsiMode c Q t = ∑_{n,n'} c n n' · exp(2πi·t·2(Qn − Qn'))`.
- `Fix_m = {y : ZMod m → ZMod D_m ∣ H_m y = 0}`, `card Fix_m = D_m`;
  `Γ` — диэдральная группа порядка `2m`, действующая перестановкой
  координат: `r: j ↦ j+i`, `s: j ↦ i−j`.
- `Btup m ĝ ν = ‖Ztup m ĝ ν‖²` — профиль по кортежам;
  `nuAvgUnits B = (∑_{u ∈ (ZMod g')ˣ} B u)/φ(g')` — среднее только
  по единицам; окно — `(X, 2X]`, отфильтрованное условием
  `gcd(N, D_m) = 1`; `ν_N` — обратный к `N` по модулю `g'`,
  то есть `ν_N · N = 1` в `ZMod g'`.

## Принцип 1. Пеллев подъём фазы: от таблицы `m = 3..9` к любому `m`

**Кандидат.** Пусть `d_m = D_m / gp m`. Тогда для любого `m ≥ 3`
и любого целочисленного вектора `n` выполнено `d_m ∣ 2·Q_m(n)`,
а значит, для допустимых `N₁, N₂` (взаимно простых с `D_m`):

- если `N₁ ≡ N₂ [MOD gp m]`, то `PsiMode(t*(N₁)) = PsiMode(t*(N₂))`;
- если `N₁ + N₂ ≡ 0 [MOD gp m]` и `c` симметрична
  (`c n n' = c n' n`), то то же равенство верно для пары
  `t*(N₁), −t*(N₂)` (минус-случай, как в `PhaseLemma`).

Ключевой шаг, который делает это не таблицей, а принципом:
`d_m = 2·gcd(x_m − 1, y_m)`. Это тождество следует из определений
`D_m = 2(x_m−1)` и `gp m = (x_m−1)/gcd(x_m−1, y_m)`.
А замкнутая форма из `LineBDerand`,
`X_m[i][j] = y_m·x_{|i−j|} − (D_m/2)·y_{|i−j|}` при `i ≠ j`
и `X_m[i][i] = y_m`, даёт `d_m ∣ 2X_m[i][j]` сразу:
`d_m ∣ 2y_m` (так как `gcd(x_m−1, y_m) ∣ y_m`) и `d_m ∣ D_m`.
Отсюда `d_m ∣ 2Q_m(n)` суммированием, а дальше работает уже
доказанная фазовая лемма: `(t₁ ∓ t₂)·2ΔQ ∈ ℤ`.

**Простейший нетривиальный случай.** `m = 3`: `D = 196`, `gp = 14`,
`d = 14`. `N₁ = 1, N₂ = 15`: `k = −1, 13`, разность `t*` равна
`−1/14 ∉ ℤ` — коллапса `t*` нет, и тем не менее кандидат утверждает
равенство модовых сумм, потому что `k₁ − k₂ = −14` делится на `14`,
а `14 ∣ 2Q₃(n)`.

**Почему это ново.** `PhaseLemma` доказывает финалы только для
`m = 3..9` и только через `decide`-таблицу значений `dOf`.
Здесь таблица заменяется одним тождеством для `gcd` и замкнутой
формой `X_m`. Если это проходит, фазовый шаг перестаёт быть
конечным перебором и становится структурой, привязанной к
последовательности Пелля.

**Тест, который может убить (минуты, уже частично проделан).**
На чистом Python, целые числа, без Lean: для `m = 3..12` построить
`X_m` по формуле Деранда, проверить `H_m·X_m = D_m·I` и
`d_m ∣ 2X_m[i][j]` для всех `i, j`, а также `D_m/gp m = d_m`.
Результат прогона: **всё верно для `m = 3..12`**
(например, `m = 10`: `D = 45239072`, `gp = 9512`, `d = 4756`;
`m = 12`: `D = 1536796800`, `gp = 55440`, `d = 27720`).
Убийственный исход: любое `m`, где `H_m·X_m ≠ D_m·I` или
`d_m ∤ 2X_m[i][j]` — тогда замкнутая форма не есть адъюгат
или `gcd`-тождество неверно в этой нормировке.

**Что останется недоказанным, даже если тест пройдёт.**
(а) Общее `lemmaQ`: `H_m·X_m = D_m·I` для всех `m` в Lean —
в проекте оно есть только поточечно (`decide` до `m = 12`),
а общий вывод из рекуррент Пелля ещё не доказан.
(б) Отождествление `Psi_m = PsiMode c (Qform ∘ v)` — аналитический
слой 149 (`hTrace`, `hAvg`, `hPair`), к фазе отношения не имеющий.
(в) Симметрия `c` для минус-случая.

**Зафиксированный тупик.** Проверялась чётностная стратификация
(«для нечётных `m` делимость сильнее, чем для чётных»):
по формуле Деранда `d_m ∣ 2X_m[i][j]` верно и для чётных, и для
нечётных `m = 3..12` без различия. Как отдельный принцип чётность
не выжила; в работу она не идёт.

## Принцип 2. Полный блок и обратный вычет: `hEquidistUnits` как теория групп, а не анализ

**Кандидат.** Окно `(X, 2X]` с условием `gcd(N, D_m) = 1`
разбивается на последовательные блоки длины `D_m` плюс остаток
длиной `< D_m`. Среднее `Btup(ν_N)` по каждому полному блоку
**точно равно** `nuAvgUnits`, а не приближённо. Отсюда среднее
по окну отличается от `nuAvgUnits` не более чем вкладом остатка:
порядка `(D_m / card окна) · sup Btup`, а не за счёт какой-то
аналитической равномерности.

Почему полный блок точен: редукция `(ZMod D_m)ˣ → (ZMod g')ˣ`
при `g' ∣ D_m` — сюръективный гомоморфизм групп, поэтому каждый
единичный вычет встречается одинаковое число раз. А `ν_N` —
это обратный к `N` по модулю `g'`, то есть перестановка единиц,
поэтому подсчёт по `N` и подсчёт по `ν_N` дают одно и то же.
Численно, для полного периода `1..D_m`:
`m = 3`: каждая единица встречается ровно 14 раз;
`m = 4`: ровно 24 раза; `m = 5`: ровно 82 раза;
`m = 6`: ровно 140 раз — во всех случаях это ровно `D_m/gp m`.

**Простейший нетривиальный случай.** `m = 3`, `X = 1000`:
в окне 428 допустимых `N`, обратные вычеты по модулю 14 —
только единицы `{1, 3, 5, 9, 11, 13}`, по 71–72 раза каждый
(`χ²` против равномерного ≈ 0,0). Неединичных вычетов — ноль,
и это не статистика, а следствие `gp ∣ D`: из `gcd(N, D) = 1`
следует `gcd(N, gp) = 1`.

**Почему это ново.** В мосте `hEquidistUnits` стоит как открытая
гипотеза с константой `D/X`. Принцип 2 говорит, что её трудная
часть — иллюзия: нет никакой «равномерности по единицам»,
которую надо доказывать анализом; есть точное групповое
равенство на полном блоке и элементарная оценка остатка.
Это также объясняет, почему старая форма с усреднением по всем
вычетам была ложна при `m = 1` (контрпример моста:
`B₀ = 4, B₁ = 0`, зазор 2): окно вообще никогда не видит
неединиц, поэтому таргет по всем вычетам был не тем объектом.

**Тест, который может убить (минуты).** Для `m = 3, 4, 5, 6`:
перечислить `N = 1..D_m` с `gcd(N, D_m) = 1`, посчитать
`ν_N = N⁻¹ mod gp m` и проверить, что каждый единичный вычет
встречается одинаковое число раз. Затем для окна `X = 100, 1000,
10000` проверить, что неединичных вычетов ноль и что среднее
по окну сходится к среднему по полному блоку. Убийственный
исход: единица, встретившаяся другое число раз в полном периоде,
или неединичный вычет в окне — тогда либо `gp ∤ D`, либо
`ν_N` определён не как обратный вычет.

**Что останется недоказанным, даже если тест пройдёт.**
(а) Точная константа моста: оценка через остаток даёт порядок
`D_m²/(φ(D_m)·X)`, а не заявленные `D/X` — множитель
`D_m/φ(D_m)` (для `m = 3` это `196/84 ≈ 2,33`, для `m = 4` — 3)
реален и требует либо ослабления константы моста, либо
дополнительного подсчёта с нижней оценкой `card` окна.
Принцип 2 не доказывает заявленную константу — он показывает,
где именно она не сходится.
(б) Сам `Btup` и его супремум `s₀^{2m}` — это уже закрытая
в мосте часть (`Ztup_norm_le`), а не часть этого принципа.
(в) Связь `Btup(ν_N)` с `‖TrU_N‖²` — отдельный `hence`-шаг
моста с ошибкой `O(1/X)`, сюда не входит.

## Принцип 3. Орбитальная стратификация: волокно — это ровно одна Γ-орбита

**Кандидат.** Для любого `m ≥ 3` каждое волокно мультисеточного
отображения на `Fix_m` — это ровно одна `Γ`-орбита. То есть:
если у двух решений `ξ, ξ' ∈ Fix_m` совпадают мультисеты
`{exp(2πi·y_j/D_m)}` (эквивалентно: совпадают отсортированные
векторы `y`), то `ξ'` получается из `ξ` диэдральной перестановкой
координат, и наоборот. Включение «орбита ⊆ волокно» тривиально
(Γ лишь переставляет координаты); содержание — обратное включение.

**Простейший нетривиальный случай.** `m = 3`, `D = 196`,
`card Fix₃ = 196`. Точный целочисленный перебор (рекуррентность
`y_{i+1} = 6y_i − y_{i−1} mod D`, ядро матрицы `M³ − I` размера
`2×2`) даёт: плохих волокон — ноль, каждое волокно — одна орбита.
Тот же результат проекта для `m = 4, 5, 6, 7` (числа `D`:
1152, 6724, 39200, 228484).

**Почему это ново.** Это превращает шаг `hSep` из поточечной
проверки волокон в структурное утверждение: разделение мод
контролируется одной группой симметрий, а не комбинаторикой
каждого волокна. Если принцип верен, `hSep` в общем виде
сводится к описанию орбит, а не к перебору `Fix_m`
(чей размер растёт экспоненциально с `m`).

**Тест, который может убить.** Расширить точный перебор до
`m = 8` (`D = 1331712`, `|Fix₈| = 1331712`, 16 диэдральных
перестановок): сгруппировать векторы по отсортированному
мультисету и проверить, что каждая группа — одна орбита.
На Python это, честно, уже не «минуты» (миллион векторов длины 8);
корректный kill-тест — на C++ с хэшированием отсортированных
векторов. Убийственный исход: одно волокно, содержащее две
разные орбиты, при любом `m` — принцип мёртв в этой общности,
и `hSep` остаётся поточечным.

**Что останется недоказанным, даже если `m = 8` пройдёт.**
(а) Общий `m`: перебор, даже до `m = 8`, — не доказательство;
нужен структурный аргумент (вероятно, через начальную пару
`(y₀, y_{m−1})` и рекуррентность: мультисет должен восстанавливать
орбиту начальной пары).
(б) Переход от всего `Fix_m` к носителю `φ̂` — в проекте он
уже закрыт инвариантностью носителя (`phihatFix_support_inv`:
полное волокно либо целиком в носителе, либо целиком вне),
но это отдельный шаг, а не следствие принципа.
(в) Сам `hSep` как заключение 152 — волокно-орбита это шаг
`[CA]`, а не вся теорема.

## Принцип 4. Диагональное молчание: `t`-зависимость живёт только в `Q`-невырожденных парах

**Кандидат.** Пусть `c` эрмитова (`c n n' = conj (c n' n)`),
`Q` целочисленна. Разобьём `PsiMode` на две части: `S_deg` —
сумма по парам с `Qn = Qn'`, `S_osc` — по парам с `Qn ≠ Qn'`.
Тогда `S_deg` вещественна и **не зависит от `t`**, а значит
`Im PsiMode = Im S_osc`, и вся `t`-зависимость (то есть всё,
что может дать наклон/рампу форм-фактора) сидит только
в `Q`-невырожденных парах. Заметьте: молчат не только
индексные диагонали `n = n'`, но и пары `n ≠ n'` с `Qn = Qn'` —
это сильнее, чем утверждение 157(a) о вещественности
индексной диагонали.

**Простейший нетривиальный случай.** Игрушечная модель:
`Q = [0, 1, 1, 3]`, случайная эрмитова `c`. Прогон даёт
`S_deg = −2,891964` при `t = 0; 0,13; 0,5; 1,7` (мнимая часть
`0`, зависимость от `t` — ноль), а `PsiMode` вещественна
при всех `t` и равна `S_deg + S_osc`.

**Почему это ново.** 149Props доказывает вещественность
`PsiMode` при эрмитовом `c`, а 157(a) — вещественность
индексной диагонали при `hdiagReal`. Принцип 4 объединяет их
в правило отбора: он говорит, какие именно пары **не могут**
внести вклад в `t`-зависимость, и тем самым переносит всю
тяжесть вопроса с «посчитать диагональ» на «оценить
`Q`-невырожденные пары». Для замороженного отображения это
означает: рампа, если она есть, должна читаться по парам
с разными значениями формы `X_m`, а не по всем парам вообще.

**Тест, который может убить (минуты).** Случайные эрмитовы
`c` и случайные целочисленные `Q` (включая вырожденные
значения): проверить `Im PsiMode = 0` с точностью `10⁻¹²`
и `S_deg(t₁) = S_deg(t₂)` для нескольких `t`. Убийственный
исход: ненулевая мнимая часть при эрмитовом `c` — это
означило бы ошибку в самом определении `PsiMode`
(фаза `2(Qn − Qn')`, а не `Qn − Qn'`), а не тонкую математику;
а зависимость `S_deg` от `t` невозможна алгебраически,
поскольку при `Qn = Qn'` фаза равна 1. Честно: этот тест
проверяет алгебру разложения, а не физику системы.

**Что останется недоказанным, даже если тест пройдёт.**
(а) Главное: эрмитовость истинных усреднённых ковариаций
`c` — это `hAvg + hEconj`, аналитический слой 149, открытый.
Без него принцип — условное утверждение о модовой сумме.
(б) Величина `S_osc` и её предел по `N` — принцип говорит
только, где `t`-зависимость **может** быть, но не то, что она
равна RMT-рампе.
(в) Отождествление `Psi_m` с `PsiMode` — снова слой 149.

## Принцип 5. Замороженное время: замена `t_N` на `t*` с явной липшицевой ошибкой

**Кандидат.** Для конечного (или суммируемого с весом)
набора мод выполнено

`|PsiMode(t_N) − PsiMode(t*)| ≤ L / N`,
`L = (2π / D_m) · ∑_{n,n'} |c n n'| · 2|Qn − Qn'|`,

поскольку `t_N − t* = 1/(N·D_m)` точно, а производная
`PsiMode` по `t` ограничена суммой модулей. В сочетании
с принципом 1 это даёт предельное утверждение по классам
вычетов: вдоль `N ≡ r [MOD gp m]` величина `PsiMode(t*(N))`
постоянна, а `PsiMode(t_N)` стремится к этой константе
со скоростью `O(1/N)`.

**Простейший нетривиальный случай.** Та же игрушечная модель,
`D = 196`, `t_N = r/N`, `r = D⁻¹ mod N`, `t* = t_N − 1/(N·D)`:
`N = 5`: разность `2,1·10⁻²` при границе `44`;
`N = 17`: `3,6·10⁻²` при границе `13`;
`N = 101`: `3,0·10⁻³` при границе `2,2`.
Граница грубая (в сотни раз больше разности), но она явная
и убывает как `1/N` — этого достаточно для предельного шага,
а точность здесь не нужна.

**Почему это ново.** В проекте `N`-шаг для 152-full числился
открытым именно потому, что ложный коллапс закрывал путь
«`t*` зависит только от вычета». Принцип 5 размыкает узел
с другой стороны: не нужно, чтобы `t_N` сам зависел только
от вычета; достаточно, чтобы `t_N` был на расстоянии `1/(ND)`
от объекта, который от вычета зависит (принцип 1), а модовая
сумма была липшицевой. Это заменяет точное тождество
приближением с контролируемой ошибкой — стандартный приём,
который здесь почему-то не был выделен в отдельный принцип.

**Тест, который может убить (минуты).** На игрушечной модели
с любыми ограниченными `c, Q`: проверить неравенство
для `N = 5..200` (взаимно простых с `D`). Убийственный исход:
разность, превышающая границу, — ошибка в константе
(`2π`, двойка из `2ΔQ` или `1/D`). На истинной системе тест
неприменим напрямую: нужны настоящие `c, Q` и оценка
`∑ |c|·|ΔQ|`.

**Что останется недоказанным, даже если тест пройдёт.**
(а) Суммируемость с весом для бесконечного набора мод
(в мосте `ι = Fin m → ℤ` бесконечно): конечная липшицева
оценка требует `∑ |c|·|ΔQ| < ∞`, а это аналитическое условие,
а не формальность.
(б) Отождествление `Psi_m` с `PsiMode` и симметрия `c`
для минус-классов (см. принципы 1 и 4).
(в) Переход от предела по классам вычетов к пределу по всем
`N`: классы дают `φ(gp)` разных констант, а не одну; сведение
их в одну RMT-константу — это уже содержание микроскопической
BGS, а не этого принципа.

## Итоговая таблица: что каждый принцип закрывает, а что нет

| Принцип | Закрывает, если доказан | Не закрывает |
|---|---|---|
| 1. Пеллев подъём фазы | Фазовый шаг для всех `m`, без `decide`-таблиц | `lemmaQ` в общем виде; отождествление `Psi_m = PsiMode`; симметрию `c` |
| 2. Полный блок | `hEquidistUnits` как групповое равенство + остаток | Точную константу `D/X` моста; связь `Btup` с `‖TrU‖²` |
| 3. Орбитальная стратификация | Шаг `[CA]` для `hSep` как структуру орбит | Общий `m` без перебора; полный `hSep` |
| 4. Диагональное молчание | Где может жить `t`-зависимость `PsiMode` | Эрмитовость истинных `c`; величину рампы |
| 5. Замороженное время | `N`-шаг по классам вычетов с ошибкой `O(1/N)` | Суммируемость с весом; единую RMT-константу |

Ни один из пяти, даже все вместе, **не доказывает** центральную
микроскопическую BGS и не доказывает RMT-универсальность для
замороженного отображения. Вместе они, если пройдут фазу Б,
убирают три ложных/застрявших места проекта (коллапс `t*`,
среднее по всем вычетам, поточечный `hSep`) и заменяют их
проверяемыми структурами: последовательностью Пелля, группой
единиц, диэдральными орбитами, `Q`-разложением и липшицевой
заменой времени. Это и есть тематикообразующий сдвиг, который
можно честно заявить: не «BGS решена», а «три препятствия
заменены структурами, у каждой из которых есть kill-тест».
