# BGS: проверенные результаты 10 октября 2026 года

Читайте сначала research_results.md. Подробные доказательства находятся
в deterministic_ramp.md, collision_resummation.md, torus_contraction.md,
compact_groups.md и coherence_form_factor.md. Независимый аудит,
исправленная ошибка и отвергнутые усиления — в audit_notes.md.

Основные результаты: ведущий ramp для явно заданного Fourier-семейства
до n=o(N^(1/8)); точная первая нелинейная поправка с остатком
(n!)²/N^(3/2); острая оценка усреднения по максимальному тору. Полная BGS
не доказана; предпосылки и границы каждого результата указаны отдельно.

## Воспроизведение

Нужны Python 3, NumPy и компилятор C++20. Из этой папки запустите:

```bash
python run_checks.py
python run_collision_checks.py
```

Первая команда проверяет представления, третий форм-фактор и Haar-контроли;
вторая — модульные ранги, точные occupation- и partition-суммы, поправки.
Программы запускаются последовательно с лимитом 45 секунд на подпроцесс.
Временные C++-бинарные файлы создаются вне этой папки и удаляются.

Файлы *_results.json содержат вычисленные значения; *_manifest.json —
команды, версии, области проверки и SHA-256. *.log сохраняют вывод.
Это legacy v1 evidence, без общего сертификата ресурсных лимитов.

exact_phase_controls.wl и partition_coefficients.wl — полные программы,
выполненные в Wolfram Language 15.0.1; *_wolfram_results.json сохраняют
исходные ответы ядра. DimensionBound.lean — некомпилированный исходник
арифметической части; он не формализует всю теорему или BGS.

Эта папка создана отдельно от репозитория BGS. Перед будущим внесением
результатов нужно заново сверить состояние репозитория, которое параллельно
редактировалось другим агентом. Планов и обещаний решения в кодовой базе нет.
