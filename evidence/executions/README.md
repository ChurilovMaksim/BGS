# Execution evidence

New execution/build manifests belong here unless a scientific subproject has a
stronger immutable historical path convention.

Legacy execution records remain at their original paths, including
`evidence/fixed_map_publication/`, `evidence/recovery_20260920/`, and
`evidence/recovery_20260921/`. They are indexed by `evidence/index.json`
instead of being moved, because path identity is part of their provenance.

Do not infer theorem status from execution success. See
`../provenance.md` and `../index.json`.
