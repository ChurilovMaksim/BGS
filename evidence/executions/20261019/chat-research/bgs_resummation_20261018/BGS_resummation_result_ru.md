# BGS: конечные примитивы и точное суммирование двух секторов

Результат исследовательского продолжения 18–19 октября 2026 года. Получены авторские доказательства структурной теоремы для всех порядков и двух пределов на масштабе времени порядка размерности. **Полная гипотеза BGS не доказана.** Новые результаты относятся к специальному вспомогательному фазовому ансамблю, а не ко всем хаотическим системам. Независимой рецензии и установленного приоритета нет.

## Точная область

Пусть \(p\) — нечётное простое, \(N=p^{2d}\), \(\Omega\) — невырожденная кососимметрическая форма на \(\mathbb F_p^{2d}\),

\[
S_{xy}=N^{-1/2}e^{2\pi i\Omega(x,y)/p},\qquad U=DS,
\]

где элементы диагонали \(D\) независимы и равномерны на окружности. Ранее было получено точное конечное разложение

\[
\frac{\mathbb E|\operatorname{Tr}U^m|^2}{m}
=1+\sum_{h=1}^{m-1}b_h(m;p)N^{-h}.
\]

Порядок отдельного слагаемого равен \(h=c+s\), где \(c\) — коразмерность разбиения столкновений, \(2s\) — ранг сжатой кососимметрической формы. Минимальное ядро оставляет активные вершины и все нетривиальные блоки столкновений. Пусть \(e\) — число общих ориентированных рёбер двух циклов в этом ядре.

## 1. Теорема для всех порядков: конечные примитивы

Инцидентностная факторизация формы даёт

\[
\boxed{e\le2h.}
\]

Введём дефект \(\delta=2h-e\). После локального сокращения компонент \(K_{2,2}\) и точного удаления двух нейтральных типов — компонент \(K_{2,4}\) с суммарным весом \(+1/2\) и пассивных пар с весом \(-1/2\) — при любом фиксированном \(\delta\ge1\) остаётся примитив с

\[
\boxed{j_{\mathrm{prim}}\le2\delta,
\qquad q_{\mathrm{prim}}\le16\delta.}
\]

Ключ к доказательству — ранговая цена соединения разных компонент: если кластер содержит \(k\) компонент формы, то

\[
c_C-(g-s)\ge k-1.
\]

Чётность разреза исходного цикла делает дефект каждого кластера целочисленным. Для кластера порядка \(j\) получается \(j\le\delta_i+1\). После удаления нулевых дефектов кластеров не больше \(\delta\), что доказывает границу.

Для каждого фиксированного дефекта вся неограниченная сумма по порядку теперь восстанавливается из конечного числа примитивных полиномов. Выписаны две точные формы восстановления: формальная производящая функция и гауссово рациональное представление. Полное доказательство: [neutral_peeling_ru.md](neutral_peeling_ru.md).

## 2. Два бесконечных сектора просуммированы при 0<τ<1

Обозначим через \(b_h^{[\delta]}\) точную часть коэффициента, определённую условием \(2h-e=\delta\), и положим

\[
R_\delta(m,N)=\sum_{h\ge1}b_h^{[\delta]}(m)N^{-h}.
\]

В этих суммах при каждом конечном \(m\) лишь конечное число ненулевых слагаемых. Для \(m/N\to\tau\in(0,1)\) доказано

\[
\boxed{R_0(m,N)\longrightarrow
\frac12\left(\frac1{\sqrt{1+4\tau}}-1\right),}
\]

\[
\boxed{R_1(m,N)\longrightarrow
\frac{\tau}{\sqrt{1+4\tau}}
-\frac{35\tau^2}{12(1+4\tau)^{3/2}}.}
\]

Первоначальный метод давал только \(\tau<1/4\). Новое доказательство использует точную матрицу-компаньон \(5\times5\), а не продолжение предельного степенного ряда. Её характеристический полином

\[
q_y(\lambda)=\lambda^5-\lambda^4+y(\lambda^3+\lambda^2+\lambda+1)
\]

удовлетворяет доказанной оценке \(|\lambda|<1+y\) для всех \(y>0\). Пять шагов точной рекурсии Шура дают целочисленный сертификат этой оценки. При \(y=X^2/N\), \(X\) с плотностью \(e^{-x^2}/\sqrt\pi\), максимальный сектор имеет точное представление

\[
R_0(m,N)=\frac12\left(\mathbb E\operatorname{Tr}C_{X^2/N}^{\,m}-1\right).
\]

Первый дефект также выражается рационально через тот же знаменатель. Оценка корней и контроль гауссова хвоста позволяют строго перейти к пределу на всём указанном интервале. Доказательства: [incidence_resummation_ru.md](incidence_resummation_ru.md), [first_defect_resummation_ru.md](first_defect_resummation_ru.md), [companion_resummation_ru.md](companion_resummation_ru.md).

## 4. Что осталось для решения

Сумма двух найденных пределов начинается с \(-23\tau^2/12\). Она не равна полной поправке: сектора \(\delta\ge2\) должны дать существенную компенсацию. Конечность примитивов при каждом фиксированном дефекте ещё не контролирует их количество и веса при растущем дефекте.

На этом маршруте нужно найти общие тождества сокращения примитивов — например, достаточные нули полиномов при \(z=1\) — и оценить сумму по неограниченному дефекту. После этого всё ещё потребуется отдельный перенос от фазового ансамбля к исходной фиксированной хаотической семье и полная совместная иерархия, а не только второй момент следа.

Дополнительно исправлена область старого теста с вращением двух портов: он не даёт контрпример к утверждению с равномерно выбранной парой. Проверка литературы: [literature_check_ru.md](literature_check_ru.md).
