# Барьер почленного оценивания точного фазового полинома

18 октября 2026. Авторское доказательство; самопроверка, приоритет не установлен.

Этот результат относится к **точной круговой фазовой модели**, а не к её гауссовской мажоранте. Обозначения — в signed_trace_formula_ru.md.

## Утверждение

Пусть $C_{m,h}(p)$ — коэффициенты точного полинома

\[
 V_m(N;p)=\sum_{h=0}^{m-1}C_{m,h}(p)N^{-h}.
\]

Тогда для всех $m\ge1$ крайний коэффициент универсален по нечётному $p$:

\[
 C_{m,m-1}(p)=\kappa_m,\qquad
 |\kappa_m|\ge\frac{m!(m-1)!}{2^{m-1}}. \tag{1}
\]

Следовательно,

\[
 \sum_{h=0}^{m-1}|C_{m,h}(p)|N^{-h}
 \ge\frac{m!(m-1)!}{(2N)^{m-1}}. \tag{2}
\]

При $m=\lceil c\sqrt N\rceil$, $c>e\sqrt2$, правая часть экспоненциально велика:

\[
 \log\frac{m!(m-1)!}{(2N)^{m-1}}
 =2c\sqrt N\log\frac{c}{e\sqrt2}+O(\log N). \tag{3}
\]

Между тем физическая унитарность даёт $V_m\le N^2$ для всех $m,N$. Таким образом, даже точные физические коэффициенты, оценённые отдельно по модулю, дают экспоненциально неверный масштаб уже при времени порядка $\sqrt N$. Это не опровержение RMT: необходимое сокращение происходит между порядками точного полинома.

## Доказательство

Из $tF''+F'=F$ для $F(t)=\sum_{n\ge0}t^n/(n!)^2$ выводится

\[
 \frac{F'}F=\sum_{n\ge0}(-1)^nk_nt^n,\qquad
 k_0=1,\quad
 k_n=\frac1{n+1}\sum_{i+j=n-1}k_ik_j>0.
\]

Индукцией $k_n\ge2^{-n}$: если оценка верна для меньших индексов, то сумма содержит $n$ слагаемых, каждое не меньше $2^{-(n-1)}$, и

\[
 k_n\ge\frac n{n+1}\,2^{-(n-1)}\ge2^{-n}.
\]

Так как $a_m=(m-1)!(-1)^{m-1}k_{m-1}$, формула крайнего коэффициента $\kappa_m=m!a_m$ доказывает (1). Следствия (2), (3) следуют из неотрицательности абсолютной суммы и формулы Стирлинга.

**Граница вывода.** Этот барьер запрещает конкретный способ оценки — полное применение неравенства треугольника к коэффициентам. Он не запрещает точное группирование, интегральное представление с сохранёнными сокращениями или иной метод. Из исчезновения первых двух поправок нельзя сделать вывод о контроле всей суммы.
