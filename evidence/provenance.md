# Evidence provenance

Every promoted evidence object now resolves to a maintained producer in the
current tree. CI does not fall back to a historical archive path.

| Evidence | Current interpretation | Maintained producer / validator |
|---|---|---|
| `certificates/second_moment_reduction.json` | exact finite fixed-`K` Cayley certificate | `computations/verification/mixed_cayley_energy.py`; regenerated byte-for-structure in CI |
| `certificates/fourth_moment_factorization.json` | exact finite pair-key/fourth-moment regression | `computations/cpp/fourth_moment_pair_key_verifier.cpp`; Python anchors in `current_regression.py` |
| `certificates/twisted_jacobi_scalar_formula.json` | finite floating-point implementation cross-check | `computations/verification/twisted_jacobi_regression.py` |
| `certificates/twisted_jacobi_moments.json` | finite preserved q-curve regression | `computations/verification/twisted_jacobi_regression.py`; reference hashes checked before use |
| `certificates/cayley_exception_k23.json` | exact finite non-uniformity witness | `computations/cpp/cayley_energy_verifier.cpp`, Python regression and Lean `CayleyEnergy.lean` |
| `numerical/goe_spacing.json` | descriptive finite spacing diagnostic | `computations/analysis/spectral_diagnostics.py spacing` |
| `numerical/matched_window_count_variance.json` | descriptive matched-GOE forward-window diagnostic | `computations/analysis/spectral_diagnostics.py window` |

The reference q-curves live only under `evidence/reference/r82/`; their SHA-256
digests are pinned in `twisted_jacobi_regression.py`.

Historical producer names remain recoverable from Git history, but they are no
longer part of the active provenance chain.
