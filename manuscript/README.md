`BGS_unified.tex` is the single maintained publication entry point on `main`.

The files in `unified_sections/` are source segments of that one manuscript. Some long sections are split into sequential `*_partN.tex` files solely to preserve exact recovered bytes while retaining later corrections already present in `main`; the parts are non-overlapping and are included in order by `BGS_unified.tex`.

The six `unified_sections/return_*.tex` chapters are generated from their
maintained Markdown proofs by
`../computations/maintenance/sync_return_sections.py`. The fixed-map frontier
and finite-orbit resonance chapters are likewise generated by
`../computations/maintenance/sync_fixed_map_section.py` and
`../computations/maintenance/sync_finite_orbit_section.py`, respectively.
Their source hashes and rendering are checked with `--check`; edit the
authoritative Markdown and regenerate the chapter. Other included sections
are directly maintained TeX. New return-law equation tags carry a `Ret.`
prefix to distinguish them from older article tags.

Build with:

```sh
python ../computations/maintenance/build_unified_manuscript.py --output-dir ../build/unified-paper
```

or from the repository root:

```sh
python computations/maintenance/build_unified_manuscript.py --output-dir build/unified-paper
```

current publication surface. The one retained standalone
`finite_orbit_note.tex` is a historical execution input named in
`../evidence/20260922/run_manifest.json`; it is not included in the

articles remain recoverable from Git history.
