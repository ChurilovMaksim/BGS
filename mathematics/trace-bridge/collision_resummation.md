## 1. Точная формула вместо положительной верхней оценки

Пусть U — произвольная плоская унитарная матрица, |U_vw|=N^(−1/2),
D — независимые равномерные диагональные фазы, T=DU. Для слова длины n
запишем a(x)=N^(n/2)∏_j U_(x_j,x_(j+1)), |a(x)|=1. Если f(x)=∏_v m_v!,
точное фазовое среднее представляется как

\[
 M_n=N^{-n}\sum_x\sum_{\pi\in S_n}
       \frac{a(x)\overline{a(x_\pi)}}{f(x)}. \tag{1}
\]

Это проверяется occupation-группировкой: сумма по π при фиксированном x
равна f(x) conjugate(A_m), и f(x) в знаменателе сокращается.

Определим рациональные числа α_s формальным степенным рядом

\[
 \log\left(\sum_{m=0}^{\infty}\frac{z^m}{(m!)^2}\right)
       =\sum_{s=1}^{\infty}\alpha_s\frac{z^s}{s!}. \tag{2}
\]

Начальные значения: α₁=1, α₂=−1/2, α₃=2/3, α₄=−11/8.
Для разбиения τ множества {1,…,n} положим
c(τ)=∏_(B∈τ) α_(|B|). Экспоненциальная формула для разбиений даёт
Σ_(τ разбиение [m])c(τ)=1/m!. Поэтому для каждого occupation-разбиения
ker x

\[
 \frac1{f(x)}=\sum_{\tau\le\ker x}c(\tau). \tag{3}
\]

Условие τ≤ker x означает, что x постоянно на каждом блоке τ. Подстановка
(3) в (1) даёт конечное точное тождество

\[
 M_n=\sum_{\pi\in S_n}\sum_{\tau\in\mathcal P_n}c(\tau)
       N^{-n}\sum_{x:\tau\le\ker x}a(x)\overline{a(x_\pi)}. \tag{4}
\]

Уже первый correction имеет коэффициент −1/2, а не −1: отрицательные
слагаемые здесь существенны. Формула (4) сохраняет те сокращения, которые
положительная оценка S−M≤ΣS_ab теряет. Это тождество использует конечные
суммы; вопрос сходимости бесконечного ряда (2) не возникает.

## 2. Ранг и степень каждого слагаемого

Для U_xy=N^(−1/2)ω^(x^T B y), x,y∈F_p^d, p нечётно, условие τ
отождествляет n−|τ|=h векторных переменных. Оно даёт множитель N^(−h),
а действие становится квадратичной формой на |τ| свободных векторах.
Это точная гауссова сумма после отождествления — без исключения
совпадений между различными блоками τ.

Для B=B₀⊕I_t, N=p^c L, L=p^t, t кратно четырём, нормированная сумма
Γ_p каждой симметричной скалярной формы ранга R удовлетворяет именно
Γ_p^4=p^(−2R), а не только |Γ_p|^4=p^(−2R). Действительно, одномерная
сумма g(a)=Σ_u ω^(au²) равна χ(a)g(1), где χ — квадратичный характер;
conjugate(g(1))=χ(−1)g(1), |g(1)|²=p, откуда g(1)^4=p².
Диагонализация формы даёт заявленную четвёртую степень, включая фазу.
Поэтому вся формула (4) — конечный полином по
x=L^(−1/2): слагаемое (π,τ) имеет степень 2h+R, а коэффициент равен
c(τ)p^(−ch) умноженному на точную core-гауссову сумму.

Это способ вычислять все collision-поправки при фиксированном n. Ограничение
t≡0 mod 4 относится только к этому удобному вещественному полиному.
Тождество (4) действует без него.

## 3. Две разновидности разности циклов ранга два

Для симметричного семейства B=I_d обозначим A=Adj(C_n)−Adj(C_π).
Выберите A_uv=s≠0. Главный блок [[0,s],[s,0]] невырожден. При ранге два
его Schur complement нулевой, и из A_ii=0 следует A_iu A_iv=0 для
каждой i (используется обратимость 2). Активная вершина имеет ровно
одну ненулевую связь с u,v. Это разбивает вершины на две группы:
внутри группы все элементы нулевые, между группами — ненулевые.
Поэтому граф носителя A — полный двудольный K_(a,b), а форма гиперболична.

Все ненулевые элементы A равны ±1; фиксация одной строки и одного
столбца показывает, что знаки факторизуются как ε_i δ_j. Каждая активная
вершина имеет одинаковое число положительных и отрицательных рёбер:
оба исходных цикла имеют степень два. Поэтому a,b∈{2,4}, а в каждой
доле половина знаков положительна, половина отрицательна.

Случай K_(4,4) невозможен: положительные рёбра содержат два замкнутых
цикла K_(2,2). Эти циклы уже используют всю старую степень своих вершин
и не могут быть частью одного исходного гамильтонова цикла.

Остаются только:

* K_(2,2): удаление двух несмежных рёбер и разворот одного из двух путей.
  Число различных неориентированных циклов — a_n=n(n−3)/2.
* K_(2,4): обмен местами двух вершин старого цикла, находящихся на
  циклическом расстоянии не менее трёх. Число — b_n=n(n−5)/2 при n≥5
  (при n=5 оно нулевое).

Каждый цикл имеет 2n перестановочных представлений. Формы обоих типов
гиперболичны, поэтому их полная нормированная гауссова сумма равна 1/N
для любого d, а не только по подпоследовательности t≡0 mod 4.

## 4. Сокращение кубического по n вклада

При фиксированном n≥5 из (4) вклад порядка 1/N может поступать только:
от h=0,R=2 либо от h=1,R=0. Формы ранга один при h=0 отсутствуют;
слагаемые h≥2 ограничены O_n(N^(−2)), остальные h=0 —
O_n(N^(−3/2)), а остальные h=1 — O_n(N^(−3/2)).

При h=0,R=2 два типа выше дают

\[
 \frac{2n(a_n+b_n)}N. \tag{5}
\]

При h=1 коэффициент α₂=−1/2. Для каждого из 2n диэдральных порядков
любая пара отождествлений имеет R=0: всего 2n binom(n,2) таких слагаемых.
У K_(2,2) форма обнуляется ровно при двух отождествлениях, поскольку она
пропорциональна (z_a−z_b)(z_c−z_d). У K_(2,4) — ровно при одном:
равенстве двух центров. Второй линейный множитель содержит четыре
ненулевых коэффициента, поэтому не является разностью двух координат.
Иных обнулений нет: форма ранга больше двух не может обнулиться при
одном ограничении коразмерности один.

Общий вклад h=1,R=0 равен

\[
 -\frac{n\binom n2+n(2a_n+b_n)}N. \tag{6}
\]

Сумма (5) и (6) равна

\[
 \frac{n[b_n-\binom n2]}N=-\frac{2n^2}N. \tag{7}
\]

Таким образом, для каждого фиксированного n≥5, любого фиксированного
нечётного простого p и N=p^d→∞,

\[
 \boxed{\displaystyle
\mathbb E_D|\operatorname{Tr}(D U_{I_d})^n|^2
 =2n-\frac{2n^2}{N}+O_n(N^{-3/2}).} \tag{8}
\]

Остаток равномерный по всем нечётным простым p; ниже дана явная константа.
Нельзя читать O_n как оценку, независимую от растущего n. Тем не менее
точное сокращение O(n³/N) до −2n²/N показывает конкретный механизм,
которого положительная мажоранта не видит. Исключения малых времён:
n=3 даёт −9/N, n=4 — −24/N вместо коэффициента в (8).

## 5. Явный остаток и растущие времена для поправки

Из (4) сразу следует |остаток|≤C_n N^(−3/2), где
C_n=n! Σ_(τ∈P_n)|c(τ)|. Коэффициенты α_s допускают простую оценку.
Пусть F(z)=Σ z^m/(m!)², b(z)=zF'(z)/F(z)=Σ_(k≥1)b_k z^k.
Тождество zF''+F'=F даёт

\[
 zb'(z)+b(z)^2=z,\qquad
 b_1=1,\quad b_k=-\frac1k\sum_{i=1}^{k-1}b_i b_{k-i}. \tag{9}
\]

Индукция показывает b_k=(−1)^(k−1)β_k с 0<β_k≤1:
β_k=k^(−1)Σβ_iβ_(k−i)≤(k−1)/k. Из (2)
α_k=(k−1)! b_k, поэтому |α_k|≤(k−1)!.
Для каждого разбиения произведение (|B|−1)! считает способы задать
циклический порядок внутри его блоков. Сумма этих произведений по всем
разбиениям равна n!, числу перестановок, разложенных на циклы. Отсюда

\[
 C_n\le(n!)^2,\qquad
 \boxed{\displaystyle
 \left|M_n-2n+\frac{2n^2}{N}\right|
       \le\frac{(n!)^2}{N^{3/2}}\quad(n\ge5).} \tag{10}
\]

Оценка (10) действует для каждого n≥5 и N=p^d; факториальная константа
прямо показывает её практическую границу. В частности, при n→∞ и
n log n≤(1/4) log N,

\[
 M_n=2n-\frac{2n^2}{N}+o\left(\frac{n^2}{N}\right). \tag{11}
\]

Действительно, (n!)²≤n^(2n)≤N^(1/2), и остаток в (10)
не превосходит 1/N; его отношение к n²/N не больше 1/n².
Более точное достаточное условие — (n!)²/(n²√N)→0.
Таким образом, сама нелинейная поправка,
а не только ведущий ramp, контролируется на растущем логарифмическом
участке. Это не заменяет теорему о ведущем ramp до n=o(N^(1/8))
и не достигает n~N.
