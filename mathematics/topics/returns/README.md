# Arithmetic return laws

Recurrence, parity and return-law theorems apply at their stated arithmetic subsequences, regularity and perturbation scales. A global return law does not determine unfolded local statistics.

## Current theorem capsules

- **[General hyperbolic maps](../../general_cat_return_laws.md)** — Theorems quantify the map, symbol regularity, selected dimensions and scaled replica amplitude.
- **[Periodic-point comparison](../../periodic_point_trace_comparison.md)** — Classical CLT inputs and finite-time quantum comparison are stated separately.
- **[Necessary local-limit conditions](../../return_trace_obstruction.md)** — Short returns constrain ergodic local limits and conditional intensities; density-dependent unfolding changes the question.
