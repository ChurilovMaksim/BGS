# Resonance, cohomology and regularity

The corpus separates oriented and signed frequency orbits, finite support from infinite orbit families, and linear transport from the nonlinear frozen dynamics.

## Current theorem capsules

- **[Finite-orbit rigidity](../../resonance-cohomology/finite_orbit_resonance_rigidity.md)** — The quantified finite-orbit support condition cannot be removed by a bare truncation argument.
- **[Analytic transfer](../../resonance-cohomology/analytic_coboundary_regularization.md)** — Analytic cohomological regularity is a distinct theorem from positivity for every analytic observable.
- **[Stable generic regimes](../../resonance-cohomology/resonance_wiener_stability.md)** — Open/generic positivity and norm-dependent stability do not settle all-member nondegeneracy.
