# Pell, echoes and harmonic transitions

Pell arithmetic produces exact recurrence structures and controlled perturbative models. Quantum kick amplitude and classical coupling must be distinguished in every theorem.

## Current theorem capsules

- **[Cohomological normal forms](../../pell/pell_floquet_normal_form.md)** — Normal forms have specified norms, time windows and perturbation scales.
- **[Harmonic return law](../../pell/pell_harmonic_returns.md)** — A law for powers of a return operator at fixed replica order does not extend automatically to Heisenberg replicas.
- **[Microscopic obstruction](../../pell/pell_microscopic_clustering.md)** — Use each counterexample only within its stated arithmetic and scaling regime.
