# Cayley arithmetic and finite-field geometry

Finite-field pair keys, energy reductions, curve bounds, resultant support and arithmetic trace laws form a separate programme. Each proof retains its prime, subgroup-size and noncentral-row restrictions.

## Current theorem capsules

- **[Energy reduction](../../cayley-arithmetic/cayley_additive_energy.md)** — Pair-key multiplicities reduce to additive energy of the Cayley image.
- **[Uniform and dense bounds](../../cayley-arithmetic/cayley_curve_uniform.md)** — The curve theorem gives K^(8/3)+K^4/p; the mixed-Weil branch controls the centered error by O(pK). External theorem hypotheses are load-bearing.
- **[Coherent elliptic spikes](../../cayley-arithmetic/offoff_elliptic_spike_theorem.md)** — The reducible-fiber contribution must be retained; removing it from a variance target is invalid.

## Suggested reading sequence

[1. fourth moment reduction](../../cayley-arithmetic/fourth_moment_reduction.md) → [2. cayley additive energy](../../cayley-arithmetic/cayley_additive_energy.md) → [3. cayley curve uniform](../../cayley-arithmetic/cayley_curve_uniform.md) → [4. cayley fourier hybrid](../../cayley-arithmetic/cayley_fourier_hybrid.md) → [5. offoff elliptic spike theorem](../../cayley-arithmetic/offoff_elliptic_spike_theorem.md)

## Remaining boundary

The sparse centered K^(2+o(1)) energy target remains open. Arithmetic averaging is not a fixed-matrix microscopic law.
