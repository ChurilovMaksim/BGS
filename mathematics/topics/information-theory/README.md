# Identifiability and information theory

These are separate mathematical applications. Observation model, photon-moment constraint, aperture, rank and measurement access determine the conclusion.

## Current theorem capsules

- **[Finite-shell identifiability](../../information-theory/holomorphic_shell_identifiability.md)** — Uniqueness and stable recovery are different questions; finite rank and complete shell data remain explicit.
- **[Aperture minimax laws](../../information-theory/coherent_aperture_minimax.md)** — Binary coherent tests and censored/full heterodyne have distinct proofs; no lower bound is transferred to arbitrary measurements.
- **[Noisy bosonic reconstruction](../../information-theory/bosonic_information_limits.md)** — Fixed strictly noisy channels and vanishing-noise transitions have different scopes.
