# Signed paths, occupations and encounters

Rooted cyclic histories preserve the Weyl and action phases that positive intensity estimates discard. Occupation classes, signed encounters, equal-edge sectors and rotation classes each remove only their specified family. Repeated words must be counted by the number of distinct rotations.

Given the actual intensity flatness and singular-gap inputs, the rotational class satisfies an absolutely summable $D_m-m$ bound. Its weighted limit is the unbroken linear ramp. The off-rotation class must therefore contribute $-\int_1^2(t-1)w(t)\,dt$, which is strictly negative for the fixed band-two test. A proof making that entire class vanish would miss the plateau. The complete signed complementary class remains open.
