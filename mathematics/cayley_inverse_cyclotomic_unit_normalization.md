# Cyclotomic-unit normalization of the inverse row

**Status: EXACT for the centred-root unit normalization, the edge unit equation, the multi-edge ideal normal form, and both fixed-weight Laurent reductions; FINITE-REGRESSION for the displayed split controls; OPEN for a simultaneous sparse-congruence theorem strong enough to bound large-prime cross-class multiplicity.**

This note refines the inverse-row localization at the level of individual centred roots.  The earlier notes remove a universal factor `tau-2` from each zero pair sum.  In fact the same factor can be removed from **each centred root separately**, and the remaining factor is a cyclotomic unit.

The consequence is a low-complexity unit-equation model for every inverse multiplicity event.  A second consequence, sharper for sparse-congruence work, is that a simultaneous `d`-edge event admits a normal form consisting entirely of Laurent relations of coefficient `l1`-weight at most eight.

## 1. Setup

Let `K=2m+1` be an odd prime, let `zeta` be a primitive `K`-th root, and put

```text
t_a=zeta^a+zeta^(-a),
tau=t_1,
L^+=Q(tau),
O^+=Z[tau].
```

For `0<=a<=m`, define

```text
v_0=0,
v_a=(t_a-2)/(tau-2),   a!=0.                            (1)
```

Choose the primitive `2K`-th root `y` used in
`cayley_inverse_structural_associates.md`, and define

```text
eta_n=(y^n-y^(-n))/(y-y^(-1)).                           (2)
```

Then

```text
v_a=eta_a^2.                                             (3)
```

The valid inverse trace classes are `[a]!=[1]`.

## 2. Every valid centred root is a ramified scalar times a unit

Define

```text
lambda_a=v_a-1.                                          (4)
```

The elementary `q`-integer identity

```text
eta_a^2-eta_(a-1) eta_(a+1)=1                            (5)
```

follows directly from `S_n=y^n-y^(-n)` by expanding both sides after multiplication by `S_1^2`.  Hence

```text
lambda_a=eta_(a-1) eta_(a+1).                            (6)
```

### Theorem 1 (centred-root unit normalization)

For every valid trace class `a!=1`,

```text
lambda_a in O^+*                                         (7)
```

is a real cyclotomic unit, and the centred inverse root satisfies

```text
x_a=t_a-tau=(tau-2) lambda_a.                            (8)
```

### Proof

Equation (8) is immediate from (1):

```text
t_a-tau=(t_a-2)-(tau-2)=(tau-2)(v_a-1).
```

For valid `a!=1`, neither `a-1` nor `a+1` is zero modulo `K` in the maintained real index range.  For `a=0`, `eta_(-1)=-1` and `eta_1=1`.  Thus both factors in (6) are cyclotomic units, proving (7). `□`

The invalid class `a=1` is exactly the one for which `lambda_1=0`; its removal is therefore intrinsic in this normalization.

At a split prime ideal `q|p` with `p!=K`, the factor `tau-2` is a unit because its rational norm is `K`.  Therefore all inverse zero-sum questions may be studied on the unit set

```text
U_K={lambda_a : [a]!=[1]}.                               (9)
```

## 3. Every reduced edge is a sum of two units

For a valid unordered edge `e={a,b}`, the maintained reduced edge element is

```text
w_(a,b)=2-v_a-v_b.                                       (10)
```

Using (4),

```text
w_(a,b)=-(lambda_a+lambda_b).                            (11)
```

Fix an orientation `(a,b)` and define the edge ratio

```text
R_(a,b)=lambda_a/lambda_b in O^+*.                       (12)
```

Then

```text
w_(a,b)=-lambda_b (1+R_(a,b)).                           (13)
```

Swapping the orientation replaces `R` by `R^-1`, and

```text
1+R^-1=R^-1(1+R),
```

so the principal ideal generated by `1+R` is orientation independent.

### Corollary 2 (unit-equation form of one inverse edge)

For every split prime ideal `q` away from `K`,

```text
q | w_(a,b)
iff
R_(a,b) == -1 mod q.                                     (14)
```

Equivalently,

```text
(w_(a,b))=(1+R_(a,b))                                    (15)
```

as fractional/principal ideals after multiplication by the unit `-lambda_b`.

Thus one inverse zero edge is exactly a cyclotomic-unit congruence to `-1`.

## 4. Multi-edge unit-congruence normal form

Let `e_i=(a_i,b_i)`, `1<=i<=d`, be oriented valid edges, and write

```text
R_i=R_(a_i,b_i).
```

Because every `lambda_(b_i)` is a unit, (13) gives

```text
(w_(e_1),...,w_(e_d))
 =(1+R_1,...,1+R_d).                                     (16)
```

For `i>=2`,

```text
(1+R_i)-(1+R_1)=R_i-R_1
                 =R_1(R_i/R_1-1),                       (17)
```

and `R_1` is a unit.

### Theorem 3 (unit-congruence normal form)

For every `d>=1`,

```text
(w_(e_1),...,w_(e_d))
 = (1+R_1,
    R_2/R_1-1,
    ...,
    R_d/R_1-1)                                           (18)
```

up to multiplication of generators by units.

Consequently a prime ideal `q` contains all `d` edge generators if and only if

```text
R_1 == -1 mod q,
R_i/R_1 == 1 mod q,   i=2,...,d.                         (19)
```

This separates a `d`-edge event into one sign equation and `d-1` equality equations among cyclotomic units.  It is especially useful for the characteristic-zero associate quotient, but it is not the sparsest Laurent presentation; Section 5 gives a sharper one.

## 5. Weight-eight trace normal form

There is a direct form that avoids clearing products of cyclotomic units.  From the definition of `v_a`,

```text
-(tau-2) w_(a,b)=t_a+t_b-2tau.                           (20)
```

Define

```text
P_(a,b)=t_a+t_b-2tau.                                    (21)
```

Since `N(tau-2)=K`, multiplication by `tau-2` is a unit at every prime ideal away from `K`.  Therefore

```text
q | w_(a,b)
iff
P_(a,b)==0 mod q                                         (22)
```

for every split `q|p`, `p!=K`.

In the full cyclotomic coordinate `zeta`,

```text
P_(a,b)(zeta)
 =zeta^a+zeta^(-a)+zeta^b+zeta^(-b)
  -2zeta-2zeta^(-1).                                    (23)
```

Thus `P_(a,b)` has coefficient `l1`-weight exactly eight and support size at most six.

For `d` edges `e_1,...,e_d`, elementary row operations give

```text
(P_(e_1),...,P_(e_d))
 =(P_(e_1),
   P_(e_2)-P_(e_1),
   ...,
   P_(e_d)-P_(e_1)).                                    (24)
```

For `e=(a,b)` and `f=(c,d)`, the difference is

```text
Q_(e,f)(zeta)
 =zeta^a+zeta^(-a)+zeta^b+zeta^(-b)
  -zeta^c-zeta^(-c)-zeta^d-zeta^(-d).                   (25)
```

It has coefficient `l1`-weight at most eight and support size at most eight; if the eight exponents are distinct its collected coefficients are exactly `+-1`.

### Theorem 4 (simultaneous weight-eight encoding)

Away from `K`, a simultaneous `d`-edge inverse event at one split embedding is equivalent to the vanishing of

```text
one Laurent relation P_(e_1) of l1-weight 8,
d-1 Laurent relations Q_(e_i,e_1) of l1-weight <=8.      (26)
```

All are evaluated at the same primitive `K`-th root in the residue field.  The weight bound is independent of both `K` and `d` on each individual generator.

For the multiplicity-six threshold, three zero edges therefore give a **three-generator weight-eight system**, rather than one weight-eight plus two weight-thirty-two equations.

## 6. Supplementary unit-ratio Laurent form

The unit-congruence normalization remains useful because it records the quotient between edges and therefore interacts directly with characteristic-zero association.

Put

```text
S_n=y^n-y^(-n),
D=S_1.
```

From (6),

```text
lambda_a=S_(a-1) S_(a+1) / D^2.                         (27)
```

For one edge `e=(a,b)`, clearing the unit denominator in `1+R_e` gives

```text
A_e(y)
 =S_(a-1)S_(a+1)+S_(b-1)S_(b+1).                        (28)
```

Each product of two `S`-terms expands into four signed Laurent monomial occurrences.  Therefore `A_e` has coefficient `l1`-weight at most eight, and hence support size at most eight.  Equal exponents may merge, so collected coefficients need not be `+-1`.

For two oriented edges `e=(a,b)`, `f=(c,d)`, clearing the unit denominator in `R_e/R_f-1` gives

```text
B_(e,f)(y)
 =S_(a-1)S_(a+1)S_(d-1)S_(d+1)
  -S_(b-1)S_(b+1)S_(c-1)S_(c+1).                        (29)
```

Its coefficient `l1`-weight is at most thirty-two.  This `8/32` unit-ratio encoding is weaker in raw sparsity than Theorem 4 but exposes the quotient unit `R_e/R_f`, which the direct trace form hides.

In particular

```text
(w_e,w_f)=(1+R_e, R_f/R_e-1).                            (30)
```

Thus every cross-class contraction from
`cayley_inverse_associate_quotient.md` can also be studied as the simultaneous arithmetic of

```text
1 + one cyclotomic unit,
one cyclotomic unit - 1.                                  (31)
```

## 7. Finite exact controls and an adversarial warning

`computations/verification/cayley_inverse_cyclotomic_unit_normalization.py` checks both normal forms on exact split anchors.

The calibrated **cross-class** event

```text
K=59, p=21713,
zero edges (8,26), (9,10)
```

has `R_e=R_f=-1 mod p` in one embedding.  Both direct edge relations have support `6`, weight `8`; their difference has support `8`, weight `8`; and all three vanish at the same primitive `K`-th root.

The characteristic-zero associate controls

```text
K=31, p=1303,
K=89, p=143207231
```

satisfy the same finite-field sign equations, as they must.  The much larger structural example

```text
K=229, p=966684838398077
```

is retained as an adversarial sparse-relation control: for either structural zero edge, the corresponding weight-eight relation has **no nonempty proper vanishing submultiset** in the supporting residue field.  Thus a single small-weight relation can be indecomposable modulo a very large split prime even when `K` is far larger than the weight.

That finite fact is not an asymptotic theorem.  Its role is to forbid the naive inference

```text
small relation weight  =>  small conductor K
```

in the split positive-characteristic setting.

## 8. Research target exposed by the normalization

For `I_-1>=6`, choose three zero edges.  The strongest present sparse encoding is the three-generator weight-eight system from Theorem 4.  If characteristic-zero associate classes have size at most two, at least two of these edges lie in different associate classes, so any closure theorem must exploit **simultaneous** sparse congruences, not merely classify one relation in isolation.

The literature on vanishing sums remains relevant but must be applied with care.  Work of Dvornicich--Zannier treats roots-of-unity relations modulo a prime, and later work uses strong special classifications modulo `2`; neither should be silently transferred to the present split-prime system without checking its exact hypotheses.  The `K=229` indecomposable weight-eight control above is an explicit guardrail.

A high-value next theorem would bound split primes for which two or three nonassociate trace relations of the form (23)--(25) share the same primitive `K`-th root modulo `p`.  Equivalently, this is a sparse common-root / sparse-gcd problem after quotienting the characteristic-zero associate families.

This unit/trace model concerns only the inverse ratio.  Full Cayley-energy and microscopic BGS closure remain downstream problems.
