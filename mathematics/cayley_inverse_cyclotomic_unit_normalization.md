# Cyclotomic-unit normalization of the inverse row

**Status: EXACT for the centred-root unit normalization, the edge unit equation, the multi-edge ideal normal form, and the fixed-sparsity Laurent reduction; FINITE-REGRESSION for the displayed split controls; OPEN for a sparse-congruence theorem strong enough to bound large-prime cross-class multiplicity.**

This note refines the inverse-row localization at the level of individual centred roots.  The earlier notes remove a universal factor `tau-2` from each zero pair sum.  In fact the same factor can be removed from **each centred root separately**, and the remaining factor is a cyclotomic unit.

The consequence is a low-complexity unit-equation model for every inverse multiplicity event.

## 1. Setup

Let `K=2m+1` be an odd prime, let `zeta` be a primitive `K`-th root, and put

```text
t_a=zeta^a+zeta^(-a),
tau=t_1,
L^+=Q(tau),
O^+=Z[tau].
```

For `0<=a<=m`, define

```text
v_0=0,
v_a=(t_a-2)/(tau-2),   a!=0.                            (1)
```

Choose the primitive `2K`-th root `y` used in
`cayley_inverse_structural_associates.md`, and define

```text
eta_n=(y^n-y^(-n))/(y-y^(-1)).                           (2)
```

Then

```text
v_a=eta_a^2.                                             (3)
```

The valid inverse trace classes are `[a]!=[1]`.

## 2. Every valid centred root is a ramified scalar times a unit

Define

```text
lambda_a=v_a-1.                                          (4)
```

The elementary `q`-integer identity

```text
eta_a^2-eta_(a-1) eta_(a+1)=1                            (5)
```

follows directly from `S_n=y^n-y^(-n)` by expanding both sides after multiplication by `S_1^2`.  Hence

```text
lambda_a=eta_(a-1) eta_(a+1).                            (6)
```

### Theorem 1 (centred-root unit normalization)

For every valid trace class `a!=1`,

```text
lambda_a in O^+*                                         (7)
```

is a real cyclotomic unit, and the centred inverse root satisfies

```text
x_a=t_a-tau=(tau-2) lambda_a.                            (8)
```

### Proof

Equation (8) is immediate from (1):

```text
t_a-tau=(t_a-2)-(tau-2)=(tau-2)(v_a-1).
```

For valid `a!=1`, neither `a-1` nor `a+1` is zero modulo `K` in the maintained real index range.  For `a=0`, `eta_(-1)=-1` and `eta_1=1`.  Thus both factors in (6) are cyclotomic units, proving (7). `□`

The invalid class `a=1` is exactly the one for which `lambda_1=0`; its removal is therefore intrinsic in this normalization.

At a split prime ideal `q|p` with `p!=K`, the factor `tau-2` is a unit because its rational norm is `K`.  Therefore all inverse zero-sum questions may be studied on the unit set

```text
U_K={lambda_a : [a]!=[1]}.                               (9)
```

## 3. Every reduced edge is a sum of two units

For a valid unordered edge `e={a,b}`, the maintained reduced edge element is

```text
w_(a,b)=2-v_a-v_b.                                       (10)
```

Using (4),

```text
w_(a,b)=-(lambda_a+lambda_b).                            (11)
```

Fix an orientation `(a,b)` and define the edge ratio

```text
R_(a,b)=lambda_a/lambda_b in O^+*.                       (12)
```

Then

```text
w_(a,b)=-lambda_b (1+R_(a,b)).                           (13)
```

Swapping the orientation replaces `R` by `R^-1`, and

```text
1+R^-1=R^-1(1+R),
```

so the principal ideal generated by `1+R` is orientation independent.

### Corollary 2 (unit-equation form of one inverse edge)

For every split prime ideal `q` away from `K`,

```text
q | w_(a,b)
iff
R_(a,b) == -1 mod q.                                     (14)
```

Equivalently,

```text
(w_(a,b))=(1+R_(a,b))                                    (15)
```

as fractional/principal ideals after multiplication by the unit `-lambda_b`.

Thus one inverse zero edge is exactly a cyclotomic-unit congruence to `-1`.

## 4. Multi-edge ideal normal form

Let `e_i=(a_i,b_i)`, `1<=i<=d`, be oriented valid edges, and write

```text
R_i=R_(a_i,b_i).
```

Because every `lambda_(b_i)` is a unit, (13) gives

```text
(w_(e_1),...,w_(e_d))
 =(1+R_1,...,1+R_d).                                     (16)
```

For `i>=2`,

```text
(1+R_i)-(1+R_1)=R_i-R_1
                 =R_1(R_i/R_1-1),                       (17)
```

and `R_1` is a unit.

### Theorem 3 (unit-congruence normal form)

For every `d>=1`,

```text
(w_(e_1),...,w_(e_d))
 = (1+R_1,
    R_2/R_1-1,
    ...,
    R_d/R_1-1)                                           (18)
```

up to multiplication of generators by units.

Consequently a prime ideal `q` contains all `d` edge generators if and only if

```text
R_1 == -1 mod q,
R_i/R_1 == 1 mod q,   i=2,...,d.                         (19)
```

This separates a `d`-edge event into one sign equation and `d-1` equality equations among cyclotomic units.

For the new multiplicity-six threshold `d=3`, the local ideal is therefore generated by

```text
1+R_1,
R_2/R_1-1,
R_3/R_1-1.                                               (20)
```

## 5. Fixed-sparsity Laurent congruences

Put

```text
S_n=y^n-y^(-n),
D=S_1.
```

From (6),

```text
lambda_a=S_(a-1) S_(a+1) / D^2.                         (21)
```

Hence for one edge `e=(a,b)`, clearing the unit denominator in `1+R_e` gives

```text
A_e(y)
 =S_(a-1)S_(a+1)+S_(b-1)S_(b+1).                        (22)
```

Each product of two `S`-terms has four Laurent monomials.  Therefore `A_e` has at most **eight** Laurent monomials, each with coefficient `+-1` before possible cancellation.

For two oriented edges

```text
e=(a,b),
f=(c,d),
```

clearing the unit denominator in `R_e/R_f-1` gives

```text
B_(e,f)(y)
 =S_(a-1)S_(a+1)S_(d-1)S_(d+1)
  -S_(b-1)S_(b+1)S_(c-1)S_(c+1).                        (23)
```

Each product of four `S`-terms has sixteen Laurent monomials, so `B_(e,f)` has at most **thirty-two** Laurent monomials with coefficients `+-1` before cancellation.

### Corollary 4 (bounded-sparsity encoding of inverse multiplicity)

At a split prime `p==1 mod K`, choose a `2K`-th root `y` reducing the characteristic-zero root.  A `d`-edge inverse event is equivalent to the simultaneous vanishing modulo the same embedding prime of

```text
one Laurent polynomial with <=8 monomials,
d-1 Laurent polynomials with <=32 monomials each.         (24)
```

The sparsity bound is independent of `K`.

This is a substantially smaller arithmetic object than the full Sylvester determinants or global norm products.  It does **not** itself give a prime-size bound: sparse root-of-unity congruences in positive characteristic require a separate theorem with carefully verified hypotheses.

## 6. Relation to characteristic-zero edge association

If two reduced edge elements are associates, then the principal ideals

```text
(1+R_e), (1+R_f)
```

coincide.  This does not require `R_e=R_f` in characteristic zero; the `K=89` structural pair is a useful warning against that stronger claim.

For arbitrary edges, however, Theorem 3 gives the exact two-edge ideal identity

```text
(w_e,w_f)=(1+R_e, R_f/R_e-1).                            (25)
```

Thus every cross-class contraction from
`cayley_inverse_associate_quotient.md` can be studied as the simultaneous arithmetic of

```text
1 + one cyclotomic unit,
one cyclotomic unit - 1.                                  (26)
```

For three edges, two independent unit-difference congruences appear.

This is the natural point at which results on sparse vanishing sums of roots of unity or `S`-unit congruences may become relevant.  No external theorem is invoked here; exact applicability has to be checked before importing such a result.

## 8. Research target exposed by the normalization

For `I_-1>=6`, choose three zero edges.  After the unit normalization, the event is governed by one `<=8`-term and two `<=32`-term congruences in a `2K`-th root of unity.

A high-value next theorem would classify or bound large split primes supporting such systems **after quotienting the characteristic-zero associate families**.  Any use of a Conway--Jones, Mann, Dvornicich--Zannier, or related finite-characteristic vanishing-sum theorem must verify its exact minimality, coefficient, residue-characteristic, and order hypotheses against (22)--(23); the existence of the known structural large-prime examples forbids a naive application.

This unit model concerns only the inverse ratio.  Full Cayley-energy and microscopic BGS closure remain downstream problems.
