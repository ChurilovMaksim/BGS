# Mathematics

This directory contains the **authoritative current mathematical narrative**.
It is intentionally small. Historical drafts, failed proof routes, exploratory
calculations and superseded formulations belong in `record/`, not here.

## Reading order

1. [`results.md`](results.md) — claim ledger for the active mathematical surface.
2. [`fourth_moment_reduction.md`](fourth_moment_reduction.md) — exact pair-key reduction and Fourier identities.
3. [`cayley_additive_energy.md`](cayley_additive_energy.md) — the exact mixed term, fixed-`K` cyclotomic exceptional primes, and the `K=23` obstruction.
4. [`elliptic_pencil.md`](elliptic_pencil.md) — the off/off elliptic-family route, explicitly marked as a theorem draft where proof obligations remain.
5. [`earlier_foundations.md`](earlier_foundations.md) — useful earlier finite/formal results that survived the reconstruction audit, with their actual scope.
6. [`open_questions.md`](open_questions.md) — only genuinely open mathematical obligations.

Evidence levels are deliberately separated:

- **EXACT** — an algebraic identity with a complete derivation in the current text;
- **FINITE-CERTIFICATE** — a machine/exhaustive statement at specified finite parameters;
- **NUMERICAL** — floating-point evidence only;
- **DRAFT** — a proof route with named unresolved obligations;
- **HISTORICAL** — useful provenance, not part of the current proof.

The repository-wide status source is `record/claim_ledger.md`.
