# Roadmap

## A. Freeze the trustworthy base

Maintain the R82 reproduction, exact `k=2` identity check and independent Theorem-II check as regression tests. Keep archived inputs immutable.

## B. Reconstruct M1 from the exact expansion

Fix Fourier conventions, derive the full twist-pair expansion, retain all cross terms, prove degeneracy exclusions and state the asymptotic regime before estimating.

## C. Build falsifiers around the claimed rate

Use designs that separate `N`, `K` and sector-dimension effects. Add explicit plots/tables only after the scripts that generate them are reproducible from the active tree.

## D. Reconnect downstream theory only after B

Only after a valid vanishing remainder is established should higher layers, local-law assembly, manuscript claims or rank-2 generalisation inherit the result.
