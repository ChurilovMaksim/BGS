## Что остаётся до полного BGS (в порядке)

0. **Кросс-члены k=4 (переоткрыто R108)**: единственная новая оценка,
   требуемая слоем k=4 — Bound на Cross = m⁴E_c − E_unc − Σ_nontriv
   (89–99.99% поправки). Рамка: профили косет-стратов; измеренный закон
   (18 дизайнов, K ∈ [11,307]) — в data/referee/r108d_ksweep.json.
   Прямое измерение rel₄·m ≈ 2.0–2.3 (спад 1/m) — нужная локальному
   закону скорость уже измерена точно.

1. **M3: smooth-density + ESY-сборка** — литературный шаблон (Erdős–Schlein–Yau), адаптированный к детерминированным арифметическим матрицам. Входы: моменты (Catalan), rel₄ ≈ 2.1/m (измерено). Оценка: 1–2 недели записи, 0 новых механизмов (после п.0).

2. **M4d: rank-2 Вейль-поправка (Hecke-ядро с перекрёстным сдвигом)** — единственный шаг, где может появиться новая математика. The genuine rank-2 kernel has the shift s = (x2, x1) (the cross coupling) — the sums over x1,x2 then factor through a 2-dimensional character variety, genus ≥ 2, bound ~ 8√N. This step closes G0.

3. **Ретракции и каскады**: R91-A (c_s формула) — закрыта, R96.6 (δ-огибающая) — ослаблена, R93.2/R95.2/M1 (δ = o(1)) — RETRACTED в R108 (неверное число N=3571 + кросс-члены), артефакты обновлены.

## Путь к премиальному уровню

G0 механизм найден: **H-связка + разложение по твистам + плоскость + Вейль на фибрах** — это общий шаблон, переносимый между рангами. Доказано:
- rank 1 (cat map): точные слои (симметрия, моменты, арксинус, k=2) + k=4 идентичность/плоскость/Вейль
- rank 2 (Sp₄ диагональ): точная плоскость, ковариация, секторная структура

**Честная оценка после R108**: полное решение BGS не достигнуто. Слой k=4 переоткрыт: кросс-члены между твист-парами (89–99.99% поправки) — единственный недостающий вход, и это по-настоящему новая оценка (коррелированные суммы по косет-стратам). Измеренный закон rel₄ ≈ 2.1/m по 18+ дизайнам — сильное численное основание для локального закона, но аналитический вход ещё нужно доказать. Уровень при завершении: прочный результат в арифметическом хаосе (CMP / Duke-уровень при удаче), с линией на Sp(2g).

## Немедленный следующий шаг

Атаковать **остаток кросс-член-оценки** — теперь в разложенной форме (R108f):
δ = δ_explicit (диагональный артефакт, замкнутая форма — выписать и сверить
на всех 16 дизайнах) + δ_remainder (измерено ≤ 0.3% при K ≥ 40, спад ~K⁻³;
аналитически открыто). Параллельно: M3-сборка условно на
|Rem| = O(E_unc/m⁴·K^{−3/2}), с точной калибровкой rel₄ ≈ 2.2/m.
