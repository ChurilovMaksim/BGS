# Самостоятельная оставшаяся задача: микроскопическая универсальность фиксированной квантовой карты

Статус: открытая задача. Нижеследующий критерий достаточен для полного локального Sine_2-предела данной детерминированной семьи. Это не доказательство BGS для всех хаотических систем.

## 1. Точная модель
Для каждого нечётного N>=3 положить e_N(t)=exp(2*pi*i*t/N); индексы x,y принадлежат Z/NZ. Обратные 2^{-1},8^{-1} берутся по модулю N.
(T_N(a,b)psi)(x)=e_N(b*(x+2^{-1}a))*psi(x+a).
(M_N)_{xy}=N^{-1/2}e_N(-8^{-1}(3x^2-2xy+3y^2)).
tau=10^{-80} фиксировано, U_N=exp(i*tau*N*A_N)M_N.
A_N — Weyl-квантование f-1/10 по правилу exp(2*pi*i*(kq+lp)) -> T_N(l,k), где
r(q)=(1-cos(14*pi*q))(1+cos(2*pi*q)),
f(q,p)=cos(14*pi*q)+r(q)/10+r(q)sin(2*pi*q)/100
       +r(q)cos(2*pi*p-alpha_0)/100,
exp(i*alpha_0)=(-3+4i)/5.
q,p принадлежат R/Z. A_N эрмитова. Использовать именно указанную модульную фазовую конвенцию.

Пусть exp(2*pi*i*theta_{j,N}), j=1,...,N, — собственные значения U_N с кратностями. Единственная случайность: alpha равномерна на [0,1).
Xi_{N,alpha}=sum_{j=1}^N sum_{ell in Z} delta_{N(theta_{j,N}-alpha+ell)}.
Требуется слабая сходимость распределений этих локально конечных точечных мер к стационарному детерминантному процессу Sine_2 с ядром K(x,y)=sin(pi(x-y))/(pi(x-y)), K(x,x)=1.

## 2. Конкретная достаточная задача H_diag
Для каждого фиксированного k>=2 и каждой вещественной функции b класса Schwartz с 0<=b, sup b<1 и bhat in C_c^infty(R) доказать Delta_{k,N}(b)->0 по ВСЕМ нечётным N.
Конвенция: bhat(xi)=integral_R b(x)exp(-2*pi*i*xi*x)dx.
b_N(t)=sum_{ell in Z}b(N(t+ell)).
D_U(m_1,...,m_k)=sum_{j_1,...,j_k попарно различны}
 exp(2*pi*i*sum_a m_a theta_{j_a,N}).
M^U_{k,N}(b)=(1/k!)integral_0^1 sum_{j_1,...,j_k попарно различны}
 product_a b_N(theta_{j_a,N}-alpha)dalpha
 =1/(k!*N^k) sum_{m in Z^k:sum_a m_a=0}
 product_a bhat(m_a/N) D_U(m).
M^CUE_{k,N}(b) — математическое ожидание той же величины для Haar-случайной V in U(N).
Delta_{k,N}(b)=M^U_{k,N}(b)-M^CUE_{k,N}(b).

Полоса Фурье произвольна, но фиксируется до N->infinity. Нужны все фиксированные k, а не только k=2. Модуль ставится ПОСЛЕ полной знакопеременной суммы; оценка суммы модулей не является требуемым механизмом сокращения.

Для вычисления без диагонализации:
p_n=Tr(U_N^n), p_0=N, p_{-n}=conjugate(p_n);
D_U(m)=sum_{pi — разбиение {1,...,k}}
 [product_{B in pi}(-1)^(|B|-1)(|B|-1)!]
 product_{B in pi}p_{sum_{a in B}m_a}.
Точный CUE-эталон: M^CUE_{k,N}(b)=e_k(T),
T_{ij}=N^{-1}bhat((i-j)/N), 0<=i,j<N,
где e_k — элементарная симметрическая функция собственных значений.
T положительно полуопределена; Tr(T)=H=integral b; 0<=e_k(T)<=H^k/k!.

## 3. Почему это действительно завершает локальную задачу
В репозитории получено условное замыкание через функционалы Лапласа (TRACE-086). Для f>=0, f in C_c^infty, положить h=1-exp(-f), H=integral h. Существуют неотрицательные Schwartz-приближения b_B с компактной гладкой поддержкой преобразования Фурье, sup b_B<1, integral b_B=H и ||h-b_B||_1->0.
Для фиксированного нечётного J>=3 и достаточно большого N:
|E_alpha exp(-<f,Xi_N>)-E_CUE exp(-<f,Xi_N^CUE>)|
 <=2||h-b_B||_1+sum_{k=2}^J|Delta_{k,N}(b_B)|+H^J/J!.
Сначала N->infinity при фиксированных B,J; затем J,B->infinity. Дополнительная гипотеза равномерности по всем k не требуется. Следует проверить это замыкание по источнику, но недоказанный модельный шаг — именно H_diag.

## 4. Границы результата и запрещённые подмены
Не заменять tau на tau_N->0. Не усреднять по N, силе толчка или независимым случайным фазам. Не ограничиваться простыми N либо удобной подпоследовательностью. Если используется случайная вспомогательная модель, доказать перенос именно Delta для исходного U_N с ошибкой o(1).
Классическое перемешивание, скалярный коммутант, диагональное приближение, конечный WKB-порядок, малые N и конечные Lean-леммы сами по себе не доказывают H_diag. Парная корреляция сама по себе не определяет весь процесс.
Главная нерешённая трудность — когерентные сокращения квантовых следов при временах порядка N, включая переход от ramp к plateau; нельзя предполагать их под именем декорреляции.
Полезный отдельный парный ориентир:
N^{-2}sum_{m>=1}exp(-2*s*m/N)|Tr U_N^m|^2
 ->(1-exp(-2*s))/(4*s^2), для каждого фиксированного s>0.
Даже доказательство этого ориентира не заменяет всех порядков H_diag; его хвосты требуют самостоятельного контроля.

Нужен полный строгий аргумент H_diag для указанной семьи либо строгое опровержение для этой же семьи: фиксированные k,b, epsilon>0 и бесконечная нечётная последовательность с |Delta|>=epsilon. Контрпример для произвольных спектров или другой случайной модели не решает задачу. Не выдавать очередную эквивалентную редукцию за доказательство.
Решение H_diag даёт конкретную детерминированную теорему универсальности; распространение на общий корректно определённый класс хаотических систем остаётся отдельной задачей.
