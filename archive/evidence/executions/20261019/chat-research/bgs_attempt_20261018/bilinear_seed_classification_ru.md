# Классификация всех фиксированных следов для билинейных Fourier-семейств

18 октября 2026. Продолжение доказательства из secular_hierarchy_ru.md.
Авторское доказательство с самопроверкой; независимого рецензирования нет.
Это вычисленный глобальный закон для целого семейства, не решение BGS.

## 1. Семейство и его допустимость

Пусть p — нечётное простое, b>=1 фиксировано, A принадлежит GL_b(F_p),
d>=1, N=p^(bd). Для x,y из F_p^(bd) положим

    A_d=I_d tensor A,
    S_(xy)=N^(-1/2) omega^(x^T A_d y),
    U=D S,

где D имеет независимые равномерные фазы. Матрица S детерминирована.
Ортогональность характеров и обратимость A дают унитарность S. Всегда
P=J и max P=1/N.

Если r=rank_Fp(A-A^T), то

    ||B||=p^(-dr/2)=N^(-r/(2b)).                         (16)

Доказательство: B_(xy)=N^(-1)omega^(x^T(A_d-A_d^T)y);
(BB*)_(xz)=N^(-1)1_{(A_d-A_d^T)^T(x-z)=0}. Последняя матрица состоит
из постоянных блоков по смежным классам ядра; её наибольшее собственное
значение равно p^(-dr). Если A несимметрична, r>=2, и ||B||<=1/3
при всех p>=3,d>=1. Такие семейства удовлетворяют исходным трём
условиям с C0=1 и rho_*=1/3. Симметрический случай имеет B=J и
исходной задаче **не допускается**; он служит контрольным сравнением.

## 2. Полная классификация предельных законов

Пишем t_m=Tr U^m. Все Z,Z_m ниже независимы и стандартно комплексно
гауссовские. При N->infinity, с фиксированным b, каждый фиксированный
вектор следов имеет следующий совместный предел во всех смешанных моментах:

| Условие на A | Предел t_1,t_2,t_3,... | Допустимость исходного B-зазора |
| --- | --- | --- |
| A^T=-A | Z,Z^2,sqrt(3)Z_3,sqrt(4)Z_4,... | Да |
| A^T=A | Z_1,sqrt(2)Z_2,sqrt(6)Z_3,sqrt(8)Z_4,... | Нет: ||B||=1 |
| A^T не равно ни A, ни -A | Z_1,sqrt(2)Z_2,sqrt(3)Z_3,sqrt(4)Z_4,... | Да |

В последней строке получен полный совместный гауссовский закон всех
фиксированных следов с унитарными дисперсиями m. Он не утверждается для
произвольной детерминированной унитарной матрицы с плоскими элементами.

## 3. Доказательство и количественная оценка

Используем ту же фазовую проекцию и оценку коллизий, что в §2 основного
доказательства. Для двух перестановок sigma,tau на L позициях положим

    R=P_sigma-P_tau,
    Q=R tensor A+R^T tensor A^T.

В каждой из d независимых координатных копий полная фаза равна
x^T Q x/2. Нормированная квадратичная сумма

    gamma_p(Q)=p^(-bL) sum_(x in F_p^(bL)) omega^(x^T Q x/2)

удовлетворяет

    gamma_p(0)=1,
    |gamma_p(Q)|=p^(-rank(Q)/2).                         (17)

Элементарное доказательство модуля: в квадрате модуля заменить пару
аргументов на x,x+h. Среднее по x есть индикатор Qh=0; на этом ядре
h^T Qh=0. Получается |gamma_p(Q)|^2=p^(-rank Q).
В частности, отдельные конечномерные суммы могут быть комплексными;
заменять gamma_p(Q) одним положительным модулем нельзя.

После d копий модуль ненулевого рангового слагаемого не превосходит
N^(-1/(2b)). Поэтому при равных суммарных длинах L>=1

    |момент_N-число нулевых сигнатур|
       <=L! [binom(L,2)/N+N^(-1/(2b))].                 (18)

При неравных длинах момент равен нулю точно. Граница (18) равномерна по
p,d,A при фиксированном b. Ни независимости рёбер S, ни случайной A здесь
нет. Осталось точно вычислить нулевые сигнатуры.

### Несимметрическое нескосимметрическое A

Матрицы A и A^T линейно независимы над F_p. Действительно, из A^T=cA
следовало бы c^2=1, а в нечётном поле это c=1 или c=-1. Поэтому Q=0
эквивалентно R=0, то есть tau=sigma. Нулевые сигнатуры существуют, только
если r_m=s_m для всех m. Число биекций, сопрягающих заданную перестановку
с ней, равно product_m m^(r_m)r_m!. Это в точности смешанные моменты
независимых sqrt(m)Z_m.

### Симметрическое A

Здесь Q=(R+R^T) tensor A. Нулевая сигнатура означает
P_sigma+P_sigma^T=P_tau+P_tau^T. Записи этих матриц лежат в {0,1,2},
так что при нечётном p равенство совпадает с целочисленным. Они определяют
неориентированный набор циклов: петли и двухциклы однозначны, каждый цикл
длины >=3 допускает ровно две ориентации. Типы r и s потому должны
совпадать, а число нулевых биекций равно

    [product_m m^(r_m)r_m!] 2^(sum_(m>=3)r_m).

Это даёт независимые гауссовские координаты с дисперсиями 1,2,6,8,10,...
Случай не назван хааровским ортогональным законом: первые две дисперсии
такого отождествления не допускают, а исходный B-зазор здесь отсутствует.

### Кососимметрическое A

Здесь Q=(R-R^T) tensor A. Нулевые сигнатуры — прежнее равенство
A_sigma=A_tau. Свободно перепариваются только одно- и двухциклы;
длинные ориентированные циклы фиксированы. Получаем (1)--(3) основного
доказательства. Любая невырожденная кососимметрическая форма приводится
заменой координат к стандартной симплектической. В этой строке оценка
ошибки усиливается до O_L(1/N); в симметрической — до O_L(N^(-1/2)).

Во всех случаях переход от смешанных моментов к распределению обоснован
моментной определённостью гауссовских либо квадратично-гауссовских
предельных координат, как в основном доказательстве.

## 4. Характеристические многочлены: три вычисленных ряда

Для предельных вторых моментов характеристических коэффициентов C_k
производящие функции равны

    generic:       sum C_k t^k =1/(1-t),
    symmetric:     sum C_k t^k =exp(-t-t^2/2)/(1-t)^2,
    antisymmetric: sum C_k t^k =
       exp[t/(1+t)-t-t^2/2]/[(1-t)sqrt(1-t^2)].            (19)

Все равенства — в |t|<1 для рядов коэффициентных пределов. Первая и вторая
формулы следуют из независимых гауссовских логарифмических коэффициентов;
третья доказана в основном файле.

Физические характеристические многочлены сходятся как случайные
аналитические функции на |z|<exp(-1/2) к экспонентам соответствующих
гауссовских или квадратично-гауссовских рядов. В этом же диске сходятся
их вторые моменты. Доказательство общего безопасного радиуса одинаково:

    c_(N,k)=E|det[omega^(X_i^T A_d X_j)]|^2/k!
            <=k^k/k!<=e^k.

При повторе X_i определитель нулевой; плоская модульная структура не
изменена. Никакого переноса (19) к z=exp(-s/N) эта оценка не даёт.

## 5. Проверка и исправление вычислительной реализации

verify_bilinear_seeds_v2.py проверяет нулевые квадратичные сигнатуры
для всех пар разбиений L=0..6 и всех трёх типов при p=3,b=2. Отдельно
строятся полные фазовые многочлены следов при N=9 для трёх типов и при
N=27 для трёхмерного несимметрического образца. Проверяется B-ранг,
а симметрический образец правильно отвергается как недопустимый.

Первый запуск seed_run/ завершился ошибкой проверяющего кода: он требовал,
чтобы все конечные смешанные моменты были рациональными вещественными.
Это условие верно для использованного симплектического случая, но неверно
для общих квадратичных сумм. Исходный код и журнал сохранены неизменными.
Версия v2 хранит точные комплексные циклотомические коэффициенты и проходит
проверки. Математическое доказательство использует только модуль (17)
для ненулевых рангов и не опирается на ошибочное требование первой версии.

Ни одна строка этой классификации не доказывает закон двухканального
пропускания. Полная локальная задача и исходная BGS остаются открытыми.
