# Точная знакопеременная формула для круговых фаз

Дата: 18 октября 2026. Статус: авторское доказательство и вычислительная самопроверка; независимой рецензии нет. Приоритет не установлен.

## Модель и область утверждения

Пусть $p$ — нечётное простое, $d\ge1$, $N=p^{2d}$, $V=\mathbb F_p^{2d}$, $\Omega$ — стандартная невырожденная симплектическая форма. Положим

\[
 S_{xy}=N^{-1/2}\exp(2\pi i\Omega(x,y)/p),\qquad
 U=DS,
\]

где диагональные элементы $D$ независимы и равномерны на единичной окружности. Все ожидания ниже берутся по $D$. Это специальное семейство квантовых карт, а не все системы из гипотезы BGS.

Фурье-ортогональность даёт $S^*=S$, $S^2=I$. Для $P_{xy}=|S_{xy}|^2$ имеем $P=J$. Для $B_{xy}=S_{xy}\overline{S_{yx}}$ имеем $\|B\|=N^{-1/2}<1$. Таким образом, модель проходит исходные классический и обратный канальные тесты; это само по себе не доказывает локальную спектральную универсальность.

## 1. Точное устранение избыточных спариваний

Обозначим

\[
 F(t)=\sum_{n\ge0}\frac{t^n}{(n!)^2},\qquad
 a_n=n![t^n]\log F(t),\qquad \kappa_n=n!a_n.
\]

Ряд используется формально; сходимость не требуется. Первые значения:

\[
 a_1=1,\quad a_2=-\tfrac12,\quad a_3=\tfrac23,
 \quad a_4=-\tfrac{11}{8};
\]
\[
 (\kappa_1,\ldots,\kappa_8)
 =(1,-1,4,-33,456,-9460,274800,-10643745).
\]

Для списка $I=(x_1,\ldots,x_L)\in V^L$ пусть $\alpha_v=\#\{i:x_i=v\}$, $h(I)=\prod_v\alpha_v!$. Если $\Pi$ — разбиение множества $[L]$, обозначим

\[
 a_\Pi=\prod_{C\in\Pi}a_{|C|},\qquad
 \mathbf 1_\Pi(I)=\mathbf 1\{x_i=x_j\text{ при }i,j\in C\in\Pi\}.
\]

Тогда поточечно, включая все повторения индексов,

\[
 \boxed{\displaystyle
 \frac1{h(I)}=\sum_{\Pi\in\mathcal P([L])}a_\Pi\mathbf 1_\Pi(I).}
 \tag{1}
\]

Доказательство. Допустимые разбиения $\Pi$ независимо разбивают каждую группу равных индексов. Для группы размера $n$ сумма весов разбиений равна

\[
 n![t^n]\exp\!\left(\sum_{j\ge1}\frac{a_jt^j}{j!}\right)
 =n![t^n]F(t)=\frac1{n!}.
\]

Умножение по группам даёт (1).

## 2. Формула смешанного следового момента

Пусть $r=(r_1,r_2,\ldots)$, $s=(s_1,s_2,\ldots)$ — конечные наборы неотрицательных целых чисел,

\[
 X_r=\prod_{m\ge1}(\operatorname{Tr}U^m)^{r_m},\quad
 \sum_m mr_m=\sum_m ms_m=L,\quad
 z_s=\prod_m m^{s_m}s_m!.
\]

Выберем перестановку $\sigma\in\mathfrak S_L$ циклового типа $r$. Для перестановки $\eta$ определим матрицу $P_\eta$ условием $(P_\eta)_{ij}=\mathbf1\{j=\eta(i)\}$, и

\[
 A_\eta=P_\eta-P_\eta^{\mathsf T},\qquad K_\tau=A_\sigma-A_\tau.
\]

Пусть $H_\Pi$ — матрица принадлежности блокам разбиения $\Pi$, размера $L\times|\Pi|$. Все ранги далее вычисляются над $\mathbb F_p$. Имеет место **конечная точная формула**

\[
 \boxed{\displaystyle
 \mathbb E X_r\overline{X_s}
 =z_s\sum_{\tau:\,\operatorname{type}(\tau)=s}
   \sum_{\Pi\in\mathcal P([L])}
   a_\Pi\,
   N^{-\{L-|\Pi|+\frac12\operatorname{rank}(H_\Pi^{\mathsf T}K_\tau H_\Pi)\}}.}
 \tag{2}
\]

Если полные длины различны, момент равен нулю по инвариантности $D\mapsto e^{i\theta}D$.

Доказательство (2). После раскрытия следов усреднение фаз оставляет в точности пары списков с одинаковыми числами вхождений. Для фиксированных таких списков число биекций между совпадающими вхождениями равно $h(I)$. Поэтому сумму по биекциям нужно умножить на $1/h(I)$, а не заменить этим числом единицу. При переписывании биекции как сопряжения передовой перестановки каждый $\tau$ заданного типа встречается $z_s$ раз. Подставляем (1).

При условии $\mathbf1_\Pi(I)=1$ остаётся $b=|\Pi|$ свободных векторов $y_j\in V$. В симплектических координатах фазовый показатель имеет вид

\[
 \sum_{\ell=1}^d q_\ell^{\mathsf T}
 (H_\Pi^{\mathsf T}K_\tau H_\Pi)p_\ell.
\]

Сумма по каждой паре $q_\ell,p_\ell\in\mathbb F_p^b$ равна $p^{2b-\operatorname{rank}}$ по ортогональности характеров. Общая нормировка $N^{-L}$ даёт (2). Матрица кососимметрична, её ранг чётен; дополнительных знаков Гауссовой суммы нет.

**Существенное отличие от положительной гауссовской мажоранты:** веса $a_\Pi$ знакопеременны. Удаление всех разбиений, кроме дискретного, меняет физическую фазовую модель.

## 3. Точный полином дисперсии и крайний коэффициент

Для одной $m$-циклической $\sigma$ формула (2) даёт

\[
 V_m(N;p):=\mathbb E|\operatorname{Tr}U^m|^2
 =m\sum_{\tau:\,m\text{-цикл}}\sum_\Pi
 a_\Pi N^{-\{m-|\Pi|+\operatorname{rank}(H_\Pi^{\mathsf T}K_\tau H_\Pi)/2\}}.
 \tag{3}
\]

При фиксированных $p,m$ это полином от $N^{-1}$ степени $m-1$. Действительно, $K_\tau\mathbf1=0$, поэтому сжатая матрица также убивает $\mathbf1$. При $b\ge2$ её ранг не больше $2\lfloor(b-1)/2\rfloor$, и степень не больше $m-2$. Степень $m-1$ даёт только разбиение с единственным блоком. Её коэффициент равен

\[
 m(m-1)!a_m=\kappa_m.
\]

При $m\ge3$ свободный коэффициент равен $m$: при дискретном разбиении равенство $A_\tau=A_\sigma$ однозначно восстанавливает ориентированный $m$-цикл. Особые низкие степени также даются (3): $V_1=1$, $V_2=2-N^{-1}$.

Например, для любого нечётного $p$,

\[
 V_3=3-\frac6N+\frac4{N^2},\qquad
 V_4=4-\frac4N+\frac{34}{N^2}-\frac{33}{N^3}.
\]

Для $p=5$,

\[
 V_8=8+\frac8N+\frac{56}{N^2}-\frac{4840}{N^3}
 +\frac{22468}{N^4}+\frac{2302172}{N^5}
 +\frac{8323874}{N^6}-\frac{10643745}{N^7}.
\]

Зависимость от характеристики существенна; полином нельзя без проверки переносить с $p=5$ на $p=3$.

## 4. Контроль абсолютных весов и его предел

Положим $F'/F=\sum_{n\ge0}h_nt^n$. Из $tF''+F'=F$ получаем

\[
 h_0=1,\qquad
 h_n=-\frac1{n+1}\sum_{i+j=n-1}h_ih_j.
\]

Следовательно, знаки $h_n$ чередуются, а $ |h_n|\le1$ по индукции. Поэтому $ |a_n|=|(n-1)!h_{n-1}|\le(n-1)!$. Экспоненциальная формула для циклов перестановки даёт

\[
 \sum_\Pi |a_\Pi|u^{L-|\Pi|}
 \le\prod_{j=0}^{L-1}(1+ju),\qquad u\ge0. \tag{4}
\]

Более локально, если $K$ имеет ранг $2g$ и ровно $q$ ненулевых строк, то

\[
 \sum_\Pi |a_\Pi|
 N^{-\{L-|\Pi|+\operatorname{rank}(H_\Pi^{\mathsf T}KH_\Pi)/2\}}
 \le \frac{q!}{N^g}\prod_{j=q}^{L-1}(1+j/N). \tag{5}
\]

Чтобы доказать (5), для разбиения обозначим $c_C=q-\#\{\text{блоки, встречающие активные вершины}\}$. Ограничение формы на подпространство с $c_C$ независимыми равенствами снижает её ранг не более чем на $2c_C$. Заменяем $ |a_C|$ на $(|C|-1)!$, то есть считаем перестановки по их циклам. Сначала произвольно переставляем $q$ активных вершин ($q!$ вариантов), затем вставляем каждую из остальных. Новый отдельный цикл имеет вес 1; вставка в любую из $j$ позиций существующих циклов имеет вес $N^{-1}$. Получается правая часть (5).

Для $q=0$ произведение начинается с $j=0$. Оценка (5) относится к одному $K$. Факториал $q!\le(8g)!$ мешает суммировать её по всем рангам на времени Гейзенберга. Поэтому (2), (4), (5) **не являются доказательством BGS или оценки при $m\asymp N$**.

## 5. Воспроизводимость

`signed_contract_v2.json`, `signed_rank.cpp`, `verify_signed_rank.py`, `verify_signed_rank_v2.py`, `signed_run_v2/` фиксируют 28 точных полиномов и 5 510 016 вычислений ранга. Проверены 67 типов разбиения чисел вхождений и девять физических фазовых сумм при $N=9,25$. Все коэффициенты проверяются в точной арифметике.

Первый запуск `signed_run/` завершился ошибкой Python из-за перехода пустой суммы во `float`. Исправление сделано отдельным `verify_signed_rank_v2.py`; исходный неудачный запуск сохранён. Успех вычислений проверяет перечисленные конечные случаи, а общие утверждения опираются на доказательство выше.
