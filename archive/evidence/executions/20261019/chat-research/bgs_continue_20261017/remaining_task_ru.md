# Оставшаяся самостоятельная задача: идентификация двухканального закона

Цель — доказательство или допустимый асимптотический контрпример следующему
утверждению. Это самостоятельная подзадача программы BGS; её решение само
по себе не объявляется решением BGS для всех хаотических систем.

Пусть S_N — детерминированная унитарная матрица N на N. Обозначим
P_ij=|S_ij|^2, J=11*/N, B_ij=S_ij conjugate(S_ji). Для фиксированных C0 и
rho_*<1, не зависящих от N, предположим

    max P_ij<=C0/N,
    ||P-J||op<=1/100,
    ||B||op<=rho_*.

Выберите равномерно упорядоченные два внешних порта A, остальные E закройте
независимыми равномерными фазами Z. Положите

    F_N(Z)=S_AA+S_AE(I-ZS_EE)^(-1)Z S_EA,
    T_N=|F_(N,12)|^2.

Требуется доказать T_N=>Uniform[0,1] с этими кванторами, либо построить
семейство по бесконечной подпоследовательности размеров, удовлетворяющее всем
трём ограничениям, и ограниченную непрерывную f, для которой

    limsup |E f(T_N)-integral_0^1 f(t)dt|>0.

Имеющиеся рабочие результаты, которые можно использовать с явными ссылками:

1. Полный гауссовский вход G на ЛЮБОМ u_N->infinity, u_N/N->0, включая
   диагонали и обратные направления. Его доказательство пока сохраняет
   именованные локальные проектные входы; при их использовании итог следует
   пометить условным, если всё замыкание не перепроверено самостоятельно.
2. Из G/условия ранга R следует TV-компактность каждого фиксированного уровня.
3. Положительная конечная путевая вероятность Q_(N,K)(k,alpha) из произведений
   f_b^k g_b^(K-k) имеет k-маргиналь binom(K,k)E[T^k(1-T)^(K-k)].
4. При TV-компактности для ЛЮБОГО K_N->infinity доказано

    W1(law_(Q)(k/K_N,|alpha|/[K_N(N-2)]),law(T_N,J_N))->0,
    J_N=(N-2)^-1 sum_e tau_e |v_e^*F_N e_b|^2,

   где источник b равномерен. Это верно для всего часа, не только для
   конечного набора отметок. При K_N=o(log N) можно оставить конечное окно
   (1-delta)log N/log log N < |alpha| <= N log N, с целыми границами
   из доказательства.

Конкретный конечный эквивалент цели при G: положить

    K_N=floor((log N)^(2/3)),
    L_-=floor((1-delta)log N/log log N), L_+=floor(N log N),
    p_(N,k)= [sum_(L_-<|alpha|<=L_+) Q_(N,K_N)(k,alpha)]
              / [sum_(j, L_-<|alpha|<=L_+) Q_(N,K_N)(j,alpha)].

Доказать e_N=(1/2)sum_(k=0)^K_N |p_(N,k)-1/(K_N+1)|->0.
Ни e_N, ни даже E T_N->1/2 в общем классе пока не оценены.

Нельзя подставлять вместо неизвестного тока хааровский эталон. В эталоне
J_N имеет не вырожденный предел 1/Gamma(3,1), независимый от равномерного T.
Условная изотропия направлений полости для исходных S_N не доказана.
Конечномерная гауссовость сырых элементов не обосновывает CLT суммы по
растущему числу совпадающих эндогенных индексов. Классическая поглощающая
цепь не совпадает с квантовыми весами. Фиксированный размер, неунитарная iid
модель, глобальные следы или ансамбль с ||B||=1 не дают контрпример задаче.

Новая полезная цель для продолжения: вывести непосредственно из точной
фазовой согласованности и исходных ограничений условную характеристику полости,
достаточную для равномерной T-маргинали, либо оценить e_N без такого усиления.
Порядок пределов тензорного параметра и полного положительного часа уже закрыт
в uniform_heisenberg_path_current.md при явно записанном входе [TC].
