# BGS: исследовательский проход 17 октября 2026 года

Полная гипотеза BGS остаётся открытой. Репозиторий BGS не редактировался.
Все новые доказательства, вычисления и замечания находятся вне него.
Это авторская работа с самопроверкой; независимой рецензии и формальной
сертификации новых результатов нет.

## Главное изменение

Вспомогательная теорема о случайном Schur-исключении усилена:
нижний порог, зависящий от log N, устранён. При прежних начальных условиях
max |S_N,ij|²<=C0/N и ||P_N-J||<=1/100, P_N=|S_N|², получен гауссовский предел
конечного числа случайно выбранных элементов при

    u_N -> infinity, u_N/N -> 0,

без дополнительного ограничения u_N>=log(N)^c. Весь конечный главный
блок требует также первоначального фиксированного разрыва в канале
обратных переходов. Для гладких ограниченных тестов непересекающихся
элементов ошибка имеет порядок

    (u_N/N)^(1/4)+u_N^(-1/8).

Ключевой шаг: высокие Schatten-моменты считают текущую размерность каждого
приращения, а защищённые метки заменяют объединение по N исходным меткам
объединением по u реально оставшимся. Вероятность выхода до уровня m
оценивается через C_A m^(-A), равномерно по N>=m, для достаточно большого m.

Полное доказательство: [dimension_uniform_feedback.md](dimension_uniform_feedback.md).
Имена и версии локальных математических входов закреплены в proof_inputs.json;
вердикт самопроверки условен именно относительно этих входов.
Предыдущее доказательство с используемыми тождествами ковариаций вложено
в inputs/deep_feedback_gaussian_20261016.md без изменения его содержания.

## Другие выполненные шаги

1. [Точное спектральное усреднение и ограниченные отношения компонент](transmission_spectral_averaging.md).
   Закон двухканального пропускания стремится к Uniform[0,1] тогда и только
   тогда, когда соответствующее ограниченное отношение интенсивностей
   стремится к Beta(1,2). Получена явная оценка через W1 типичного
   эмпирического распределения интенсивностей собственного вектора.
   Сходимость этих интенсивностей для нужного фазового ансамбля ещё не доказана.
2. [Препятствие для сравнения высоких степеней](high_power_moment_barrier.md).
   Положительный экспоненциальный наклон по числу повторений рёбер
   концентрируется на редких самопереходах. Построен ограниченный круговой
   закон элементов с точным совпадением гауссовских моментов вплоть до любого
   заданного конечного порядка, но экспоненциально большим вторым моментом
   Tr Z^m при m/N->alpha. Это контрпример к такому iid-сравнению; матрицы
   в конструкции не обязаны быть унитарными.
3. [Самопроверка](self_review.md) фиксирует зависимости, границы утверждений,
   независимые расчёты малых случаев и первый незакрытый переход.

## Проверки и воспроизводимость

Три успешных запуска используют точную целую/рациональную арифметику;
SymPy нужен только для вычетов и рациональных матричных тождеств.
Случайного моделирования в этих проверках нет. Несколько отдельно помеченных
десятичных оценок в проверке высоких степеней служат иллюстрациями.

| Запуск | Содержание |
|---|---|
| transmission_run_v2 | 50 проверок вычетов/смесей, 9 замыканий и производных, 20 Schur-тождеств, 9 нормировок |
| high_power_run | 11 886 слов, 782 таблицы рёбер, 6 полных ориентированных клик, точные проверки наклона |
| dimension_uniform_run | 16 адаптированных некоммутирующих траекторий; 4 244 префикса; 133 первых выхода; 64 рациональных Schur-перехода |

Первая попытка transmission_run сохранена как неудачный запуск: исправлена
ошибка выбора целочисленного домена многочленов при сдвиге на рациональное
число. Она не считается подтверждением результата. Актуальные успешные
результаты закреплены контрактами и контрольными суммами в своих папках.

Для воспроизведения из этой папки: Python 3.12, SymPy 1.14.0 для первой
команды; остальные используют стандартную библиотеку.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 verify_transmission_bridge.py reproduced_transmission.json
PYTHONDONTWRITEBYTECODE=1 python3 verify_high_power_barrier.py reproduced_high_power.json
PYTHONDONTWRITEBYTECODE=1 python3 verify_dimension_uniform.py reproduced_dimension_uniform.json
```

Конечные вычисления проверяют свои конкретные тождества и диапазоны,
но не заменяют аналитическое доказательство асимптотики. repo_integrity.json
содержит сравнение всех 716 файлов BGS с исходными контрольными суммами.

## Оставшийся барьер

Следующий существенный переход — от любого расходящегося числа каналов
к фиксированному числу каналов и совместному закону с радиальной производной.
Новый результат не разрешает подставить u=2 в асимптотику u->infinity.
Другой точный путь требует доказать сформулированный закон интенсивностей
собственных векторов. Затем остаются микроскопическая иерархия и снятие
фазового усреднения для исходного фиксированного оператора.

Приоритетный следующий тест: классификация предельных согласованных
конечноканальных законов с фазовой стационарностью и полученной
равномерной большой-размерностной оценкой. Уникальность хааровского закона
из этих свойств здесь не доказана. Эта задача сохранена открытой, а не
объявлена следствием гауссовских фиксированных блоков.
