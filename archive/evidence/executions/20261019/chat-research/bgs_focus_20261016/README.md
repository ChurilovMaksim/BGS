# BGS: отдельный исследовательский проход, 16 октября 2026

Репозиторий BGS оставлен без изменений. Новые доказательства и расчёты
находятся только в этом отдельном пакете. Работа выполнена без субагентов.

Получено доказательство следующего вспомогательного результата, условное
на ранее зафиксированных точных леммах TRACE-073, TRACE-077 и TRACE-080.
Самопроверка завершена; независимой рецензии нового доказательства нет.
Мировая новизна не установлена. Полное решение BGS не получено.

Пусть начальная детерминированная унитарная матрица удовлетворяет
max|S_ij|²<=C0/N, |||S|²-J||<=1/100, а норма канала
B_ij=S_ij conjugate(S_ji) ограничена фиксированным rho_*<1.
При последовательном исключении случайных координат со свежими
независимыми круговыми фазами, для
log(2N)^(4+kappa)<=u=o(N), любой фиксированный случайно выбранный главный
подблок sqrt(u)S_u имеет предел из независимых стандартных комплексных
гауссовых элементов. Включены диагонали и обе стороны каждой пары;
сходятся все фиксированные смешанные моменты.

После добавления независимых фаз на оставшихся координатах также получен
совместный гауссов предел следов фиксированных степеней с дисперсиями
1,2,3,... . Степени, растущие вместе с размерностью, не охвачены.

Ключевой точный механизм: ковариационное ядро

    C_(ij),(kl)=sum_e S_ie S_ej conjugate(S_ke S_el)

является ортогональным проектором ранга v. Матричное неравенство
Фридмана улучшает вероятность исключительного события до O_A(N^-A).
Обратные пары контролируются отдельным сжимающимся Green-оператором;
диагональные ковариации восстанавливаются из внедиагональных моментов.

Открытая следующая задача: закон двухканального пропускания
|(S_2)12|² и его совместный закон с радиальной производной. Для Haar U(2)
это равномерное распределение на [0,1]; универсальность этого закона
из указанных детерминированных начальных условий здесь не доказана.
У любой унитарной 2x2 матрицы канал B имеет собственное значение 1,
поэтому использованный малый Green-оператор нельзя продолжить до неё.
Переход к фиксированному физическому оператору также остаётся открытым.

Содержимое:

- deep_feedback_gaussian.md — полное рабочее доказательство и границы;
- self_review.md — самопроверка, зависимости и точная область проверки;
- feedback_covariance_check.py и feedback_extension_check.py — точные
  проверки над Q(i) и исчерпывающие проверки указанных конечных диапазонов;
- two_channel_probe.py — ограниченный численный поиск контрпримеров
  следующей гипотезе; расчёт не является её доказательством;
- три каталога *_run — исходные результаты, ограничения ресурсов и хеши;
- proof_input_hashes.json — фиксация используемой версии текстов;
- repo_integrity.json — сравнение репозитория до и после прохода.

Воспроизведение точных проверок из этой папки:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 feedback_covariance_check.py exact_result.json
PYTHONDONTWRITEBYTECODE=1 python3 feedback_extension_check.py extension_result.json
```

Для дополнительного численного опыта требуется NumPy 2.3.5:

```bash
OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1 python3 two_channel_probe.py probe_result.json
```

Малые численные размерности не удостоверяют асимптотические оценки.
Симметричный Fourier-контроль нарушает гипотезу о канале обращения;
его результаты выделены отдельно. Ранее известная конструкция
симплектической инволюции явно отнесена к соответствующему тексту проекта.
