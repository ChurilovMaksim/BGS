# Несимметрические билинейные образцы: степенное гауссовское окно

18 октября 2026. Новое авторское доказательство и самопроверка; внешней
рецензии и установления литературного приоритета нет.

## Утверждение

Фиксируем b, выбираем нечётное простое p и A in GL_b(F_p), причём
A^T!=A и A^T!=-A. При d>=1, N=p^(bd), V=F_p^(bd), A_d=I_d tensor A
положим S_xy=N^(-1/2) omega^(x^T A_d y), U=D S с исходными независимыми
равномерными круговыми фазами D. Матрица S детерминирована и унитарна.

Как проверено в предыдущем checkpoint, P=J, max P=1/N,
||B||=p^(-d rank(A-A^T)/2)<=1/3. Невырожденный несимметрический образец
потому допустим в исходной задаче. b фиксирована; p,d,A могут меняться.

Для L>=2 положим

    y=b L^3 N^(-1/(2b))<1,
    A_0=y/(1-y), B_0=binom(L,2)/N,
    W_0=B_0(1+A_0)+8y(1+y)/(1-y)^3,
    E_0=A_0+W_0.                                       (G1)

Для любых двух продуктов следов X_a,X_c с положительными длинами,
одинаковой суммой L и центральизаторами z_a,z_c (определение как
в основном файле) имеем

    | E_D X_a conjugate(X_c)/sqrt(z_a z_c)
                           -1_{a,c одного циклового типа} |<=E_0.
                                                               (G2)

При разных суммах момент равен нулю точно. При L=1 момент |t_1|^2 равен 1.

Следовательно для любого фиксированного числа попарно различных длин
m_(j,N)>=1 с max_j m_(j,N)=o(N^(1/(6b))) нормированные следы
t_(m_(j,N))/sqrt(m_(j,N)) сходятся совместно, во всех фиксированных
смешанных моментах, к независимым CN(0,1). Также

    det(I-zU) => exp[-sum_(m>=1) Z_m z^m/sqrt(m)]         (G3)

в Hol(|z|<1). Это сходимость по распределению; сходимость вторых моментов
самих определителей на всём диске не утверждается. Ни G2, ни G3 не дают
двухканального закона или микроскопической BGS.

## Доказательство с учётом комплексных гауссовских сумм

Для R=P_sigma-P_tau на L позициях положим

    Q=R tensor A+R^T tensor A^T.

Матрица Q симметрична размера bL. При гауссовской замене диагональных
переменных отдельный член Вика равен gamma_p(Q)^d, где

    gamma_p(Q)=E_(x uniform F_p^(bL)) omega^(x^T Q x/2),
    gamma_p(0)=1, |gamma_p(Q)|=p^(-rank Q/2).            (G4)

Последнее равенство следует интегрированием разности квадратов по x,x+h.
Ненулевые члены могут иметь комплексный знак: положительными они здесь
не объявляются. Все оценки ниже используют неравенство треугольника.

Поскольку A,A^T линейно независимы, Q=0 эквивалентно R=0, то есть
tau=sigma. Линейная независимость следует из A^T=cA => c^2=1; нечётная
характеристика и исключение A^T=+/-A устраняют оба случая. Это верно
в том числе для одно- и двухциклов, в отличие от кососимметрического случая.

Каждая скалярная строка Q касается не более четырёх вершинных блоков:
двух из R и двух из R^T. Если rank Q=r, объединение блочных носителей r
базисных строк имеет размер <=4r. Симметрия Q даёт такое же ограничение
на число ненулевых вершинных строк-блоков. Нулевая строка-блок Q
вынуждает нулевую строку R: для внедиагональных блоков это следует из
независимости A,A^T, для диагонального блока — из A+A^T!=0.
Следовательно tau(i)=sigma(i) вне <=4r вершин.

Используем более точный подсчёт. Любая симметричная матрица ранга r
в нечётной характеристике имеет невырожденный главный минор порядка r.
Это доказывается последовательным исключением диагональных блоков 1x1
либо, когда диагональ нулевая, невырожденных блоков 2x2. Если I — его
скалярные позиции, то Q=Q_(:,I) Q_(I,I)^(-1) Q_(I,:), так что r строк
полностью определяют Q. Для каждой скалярной строки достаточно задать
tau(v) и tau^(-1)(v) её вершинного блока v: не более L^2 вариантов.
Отображение tau->Q инъективно по независимости A,A^T. Следовательно

    #{tau: rank Q=r}<=binom(bL,r)L^(2r)<=(bL^3)^r.

Нулевой ранг даёт единственную tau=sigma. Модуль суммы ненулевых
рангов после d координатных копий потому <=

    sum_(r>=1) [bL^3 N^(-1/(2b))]^r=A_0.               (G5)

При отождествлении двух вершинных переменных ограничение имеет коразмерность
b. Ранг Q падает не более чем на 2b. Если хотя бы один из двух вершинных
блоков изолирован, ранг не меняется. При q<=4r активных блоках возможно
падение лишь для <=binom(q,2)<=8r^2 пар. Поэтому модуль суммы с одним
индикатором совпадения не превосходит

    [binom(L,2)/N+8r^2] N^(-r/(2b)).                    (G6)

Для r<2b здесь используется N^(-1)<=N^(-r/(2b)); для r>=2b — возможное
падение на 2b и обязательный множитель 1/N от совпадения. Никакой
оценки модуля комплексной фазы снизу не требуется.

Суммирование (G6) с (G5) даёт W_0, поскольку
8 sum_(r>=1) r^2 y^r=8y(1+y)/(1-y)^3.
Коэффициентное сравнение круговых и гауссовских норм и взвешенное
неравенство Коши—Буняковского для смешанных моментов в точности такие же,
как в §§3,5 основного файла. Они доказывают (G2).

Переход к распределению растущих следов проводится методом моментов;
при фиксированной степени момента L=o(N^(1/(6b))) и E_0=o(1).
Для (G3) берём H_N=floor((N^(1/(2b))/(2b))^(1/3)). Из верхней гауссовской
оценки E|t_m|^2<=2m при m<=H_N. Хвост за H_N ограничен унитарностью:
N rho^(H_N+1)/[(H_N+1)(1-rho)]->0 для любого фиксированного rho<1.
Конечные коэффициенты имеют уже вычисленный независимый гауссовский
предел. Это даёт сходимость логарифмов, затем экспонент, на всём открытом
единичном диске прямым контролем хвоста.

## Границы переноса

При A^T=-A сохраняется исключительный второй след, и применим основной
симплектический результат с лучшим показателем 1/5. При A^T=A нулевая
сигнатура уже допускает развороты циклов; данный подсчёт к ней не
применяется, а исходный B-зазор отсутствует. b, растущая с N, также не
включена в формулировку. Показатель 1/(6b) не заявляется оптимальным.
