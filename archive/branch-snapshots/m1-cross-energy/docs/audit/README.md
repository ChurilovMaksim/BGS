# Audit directory

This directory contains current repository-level review records. The authoritative mathematical status is still root `STATUS.md`.

- `full_repository_sync_2026-09-03.md` — full structural/semantic synchronization report.
- `FILE_INVENTORY_SUMMARY.json` — compact inventory counts; regenerate the path-level inventory with `code/maintenance/audit_inventory.py`.
- `PRODUCER_PATH_MAP.md` — historical producer-name resolution without rewriting provenance.
- `CLAIM_STATUS_MAP.md` — compact current interpretation of load-bearing and exploratory routes.
- `HISTORY_ENCODING_REPAIR.json` — verified encoding-repair method/checksums for the preserved full historical ledger.
- `EXECUTION_MATRIX.md` — what was actually executed in the audit environment and what was unavailable/unfinished.

Older repository surgery/model-review records remain under `docs/review/`.
