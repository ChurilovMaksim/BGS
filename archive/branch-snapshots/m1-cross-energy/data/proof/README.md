# Historical proof-oriented outputs

This directory name is historical.  Its files are a mixture of exact finite-design checks, exploratory numerical evidence, failed proof routes, and old run summaries.  Nothing here becomes a theorem merely because the file says `PROVEN` or `PASS`.

Current canonical certificates are in `results/verified/`.  Current claim status is in root `STATUS.md`.

Key boundaries: `h3_k4_factorization.json` and `sigma4_second_moment.json` contain useful finite exact content at stated designs but not general asymptotic theorems; `cycle2_toy_subweyl.json` and `cycle3_trace_fluctuation.json` are exploratory; `word_trace_proof.json` is incomplete; M1 killer-test files are numerical evidence whose old theorem-level interpretation is superseded.
