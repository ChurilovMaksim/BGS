# Rank-2 / Sp4 research outputs

This directory preserves the rank-2 continuation as a research corpus.

The strongest current content is a collection of **exact finite-design identities**, mainly at `N=53`: diagonal identity, coset flatness, coset-sector structure, hyperbolic period-4 structure, and a negative result for a naive product kernel.  These are useful calibration points and should not be discarded.

They do not prove uniform rank-2 flatness, a higher-genus Weil estimate, M4d, or general BGS.  Files about `G0`, edge mass, and trace fluctuations are numerical/experimental unless a separate analytic proof is supplied.  Root `STATUS.md` controls any stronger claim.
