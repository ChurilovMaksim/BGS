# Archive

This directory is intentionally separated from the active research surface.

- `legacy-workspace/` is the preserved pre-restructure corpus: old code, data, papers, reviews, negative results and mistakes.  It is provenance, not current truth.
- `rebuild-records/` preserves the 2026-09-03 repository-audit records that led to the human restructure.
- `retracted-results/` contains current-era quarantined numerical artifacts whose raw values are worth retaining but whose old interpretation is invalid.

Do not repair or rewrite raw files inside `legacy-workspace/`; promote a result into the active tree under a descriptive new name after rechecking it.
