# Prior-source lead; no new theorem dependency

Primary source: Dubi Kelmer, *On matrix elements for the quantized cat map modulo prime powers*, arXiv:0802.3237v2 (18 September 2008), https://arxiv.org/pdf/0802.3237.

Verified locators: Lemma3.2 (printed p10) proves multiplicity-freeness for the inert torus, using trace orthogonality; Section3.2 and Theorem1 give diagonal Hecke matrix elements; Proposition4.1 gives prime-power stationary-phase formulas. This supplies prior provenance for the inert multiplicity-free mechanism. Our exact cyclic-generator/CRT distribution remains separately proved.

The unresolved size-seven compressions also need off-diagonal entries between cubic-related torus characters. The cited diagonal formula alone does not provide that matrix. No external theorem has been silently imported into the accepted actual-model proofs, and no novelty assertion is made for the underlying multiplicity-free fact.
